## §0 — ORIENTATION

### §0.1 What This File Is

This is the **body-side circuit diagram** — a unified map of the physical
infrastructure through which body-based therapies produce their effects.

Human-Predictive-Drive Core-Hardware maps the brain's architecture (4 zones by PFC accessibility).
This file maps the body's architecture (9 systems by signal processing depth).

Together they form a complete signal path: body infrastructure (this file) →
brain processing (Human-Predictive-Drive Core-Hardware) → mechanisms and effects (Core-Therapy-
Architecture).

### §0.2 What This File Is NOT

- **Not therapy mechanisms.** HOW therapies leverage this infrastructure
  → Core-Therapy-Architecture.md
- **Not individual system detail.** Full system descriptions → Track A files
  (A01-A09)
- **Not cross-therapy patterns.** Which therapies activate which systems
  → Track C files (C01-C05)
- **Not brain-side processing.** What happens after signals reach the brain
  → Track D files (D01-D05) and Human-Predictive-Drive

This file shows WHAT EXISTS and WHERE — the hardware that all therapeutic
processes run on.

### §0.3 Organizing Principle

Human-Predictive-Drive Core-Hardware organizes by **PFC-reach gradient** (Zone A → Zone D: from
PFC itself to beyond PFC reach).

This file organizes by **signal processing depth** — from body surface to
brain, tracking how deep each signal travels before producing therapeutic
effect. This is the INVERSE perspective: Human-Predictive-Drive looks outward from PFC; Body-Signal-Architecture
looks inward from skin.

```
Human-Predictive-Drive Core-Hardware:     PFC ────────→ Zone D (outward from brain)
Core-Body-Architecture: Skin ────────→ Brain (inward from body)

They MEET at the body-brain boundary:
  Body-Signal-Architecture's "deepest reach" = Human-Predictive-Drive's "Zone D" = the SAME territory
  described from opposite directions.
```

### §0.4 The Central Architectural Finding

The body's 9 signaling systems are NOT 9 independent channels. They form
ONE INTEGRATED NETWORK where any physical stimulus activates MULTIPLE systems
simultaneously. No therapy engages only one system. The architecture is a
network, not a switchboard. 🟡

### §1.2 Key Architectural Principles

**Principle 1: Simultaneous multi-system activation.** No therapy activates
only one system. The minimum: ANY physical contact activates A01 (detection) +
A02 (autonomic response) + A06 (local chemical release). Most therapies
activate 5-7 systems at MODERATE or above (C01 matrix data). 🟢

**Principle 2: The network is depth-stratified.** Signals DON'T travel through
all 9 systems sequentially. They activate different systems at different
DEPTHS simultaneously:
- Surface contact → A01 detects, A03 transmits, A04/A05/A06 respond LOCALLY
- Spinal relay → A07 routes, gate control engages
- Brainstem → A02 autonomic shift begins
- Each depth layer operates on a DIFFERENT timescale 🟡

**Principle 3: Many therapeutic effects stay LOCAL.** Human-Predictive-Drive's Gap 2 (Blackbox-
Map §3) assumes signals traverse from body to brain. Body-Signal-Architecture reveals: many therapy
signals NEVER reach the brain. Axon reflex, HO-1, mechanotransduction, endocannabinoid system
activation — all produce therapeutic effects within Levels 0-1, below spinal
cord. The driver layer is not just a transit zone; it IS therapeutic territory
(D01 §5.2 "Gap 2 partial dissolution"). 🟡

**Principle 4: Mechanical dominance.** 14 of 15 body therapies in Track B use
mechanical stimulus as primary input. Only B08 (moxibustion) is purely thermal.
The body's therapeutic infrastructure is overwhelmingly a MECHANOTRANSDUCTION
network. 🟢

### §2.3 Timing — Speed Gradient

The 9 systems operate at different speeds. A single therapy session activates
multiple timescales simultaneously.

```
TIMESCALE        SYSTEMS INVOLVED         MECHANISM EXAMPLES
──────────────── ──────────────────────── ──────────────────────────────────
MILLISECONDS     A01 (reflex arc)         Gate control (Aβ → dorsal horn)
                 A08 (proprioceptive)     Somatovisceral reflex
                                          HVLA proprioceptive burst

SECONDS          A01 (axon reflex)        CGRP/SP local release
                 A03 (mechanotrans.)      Integrin-FAK signaling
                 A04 (vasomotor)          Lewis response, NO release

MINUTES          A02 (autonomic shift)    Parasympathetic engagement
                 A06 (chemical release)   Adenosine, endocannabinoid system, opioid release
                 A05 (acute immune)       Mast cell degranulation

HOURS            A04 (HO-1 cascade)       Macrophage → CO + biliverdin
                 A05 (cytokine shift)     Anti-inflammatory cascade
                 A06 (endocrine)          Cortisol modulation (HPA)

DAYS-WEEKS       A03 (fascial remodel)    Collagen reorganization
                 A05 (immune training)    M1→M2 polarization sustained
                 A08 (motor learning)     Neural pattern compilation
```

**Parallel processing principle:** A single needle insertion simultaneously
triggers: gate control (ms), axon reflex (sec), adenosine release (min),
immune response (hr), and — if repeated — neuroplastic changes (wk-mo).
These are NOT sequential; they run on PARALLEL timescales. This is why
therapy dose-response is not ONE curve but MULTIPLE simultaneous curves
at different timescales. 🟡

**Three key stimulus principles:**

"dose" — it switches which systems activate (D03 §5.2):

```

65-110N  Descending modulation (PAG opioid)   → E₁ Evaluative
>110N    Full cascade all layers              → All simultaneously
```
🟡

**Style = configurable activation.** Self-generated movement (B15/B16) is the
ONLY stimulus type where the Track A activation profile is user-configurable.
Different yoga styles target different primary systems: Yin=A03, Restorative
=A02, Vinyasa=A04+A08, Kundalini=A02+A06 (C01 §3.2.7). 🟡

## §3 — SYSTEM INTERACTION MAP

The 9 systems do not operate independently. Therapeutic stimuli trigger
CASCADES across systems. Five primary interaction pathways:

### §3.1 Detection → Response Cascade

```
A01 PNS (detects) ──→ A02 ANS (autonomic shift)
                  ──→ A06 Chemical (NT/hormone release)
                  ──→ A07 Convergence (routes to target organ)

Example: Needle at ST36 → A01 detects penetration → A02 vagal shift via
PROKR2 neurons → A06 enkephalin release → A07 routes signal via L4-L5
dermatome to GI tract.
```

### §3.2 Transmission → Amplification Cascade

```
A03 Fascia (transmits force) ──→ A05 Immune (neurogenic inflammation)
                              ──→ A04 Vascular (local blood flow change)
                              ──→ A06 Chemical (endocannabinoid system at depth threshold)

Example: Deep tissue massage → A03 mechanotransduction (FAK/ERK) → A05
mast cell activation → A04 vasodilation (CGRP, NO) → A06 AEA ↑168% via
fascial CB1/CB2 at >40-65N threshold.
```

### §3.3 Microtrauma → Repair Cascade

```
A04 Vascular (capillary disruption) ──→ A05 Immune (macrophage phagocytosis)
                                    ──→ A06 Chemical (HO-1 → CO + biliverdin)

Example: Cupping marks → A04 capillary extravasation → A05 macrophage CD163
→ A06 HO-1 cascade → cytoprotective products. Force direction irrelevant;
force CONSEQUENCE (capillary disruption) determines pathway.
ONLY B07 cupping + B09 gua sha.
```

### §3.4 Movement → Multi-System Cascade

```
A08 MSK (proprioception) ──→ A01 PNS (afferent feedback)
                          ──→ A02 ANS (via breathing = Zone D Bridge)
                          ──→ A05 Immune (myokine IL-6 anti-inflammatory)
                          ──→ A04 Vascular (exercise hemodynamics)
                          ──→ A06 Chemical (exercise eCB)

Example: Tai Chi slow movement → A08 continuous proprioceptive input +
A02 coordinated slow breathing (4-channel Zone D Bridge) + A05 myokine
release + A04 respiratory pump + A06 exercise eCB. ONLY active therapies
(B15/B16) engage this full cascade.
```

### §3.5 Convergence — The Multi-System Node

```
A09 Composite ◄── A01 (neural substrate)
              ◄── A03 (fascial planes — 80% acupoints)
              ◄── A04 (vascular density)
              ◄── A05 (immune cell concentration)
              ◄── A06 (chemical receptor density: PROKR2)
              ◄── A07 (dermatome-viscerotome overlap)

Acupoints are NOT single-system structures. They are MULTI-SYSTEM
CONVERGENCE NODES where 4-6 systems overlap anatomically (A09 assessment).
PROKR2 molecular marker (Liu 2021 Nature) confirms at least one
measurable molecular basis. 🟢/🟡
```

## §4 — SYSTEM PROFILES

Each system's role in the integrated network. For full detail → Track A files.

### §4.1 A01 — Peripheral Nervous System (DETECTION)

**Network role:** Universal signal detector. All 5 PNS mechanisms (gate
control, descending modulation, axon reflex, somatovisceral reflex,
purinergic) are engaged by body therapy. CT afferents (1-10 cm/s, hairy skin
only) = affective touch pathway → posterior insula (interoceptive cortex).
Reaches Level 0-2. Referenced by ALL 15 Track B therapies.
→ A01-Peripheral-Nervous-System.md

### §4.2 A02 — Autonomic Nervous System (REGULATION)

**Network role:** Autonomic effector and the ZONE D BRIDGE. Parasympathetic
shift = universal response to safe therapeutic touch. Breathing = ONLY
voluntary access point (4-channel bridge: autonomic + circulatory +
neuroimmune + chemical). B16 reveals bridge is BIDIRECTIONAL (calming
pranayama + activating Kapalabhati). PROKR2 intensity-dependent autonomic
pathway (Liu 2020/2021). Reaches Level 1-3.
→ A02-Autonomic-Nervous-System.md

### §4.3 A03 — Fascia & Connective Tissue (TRANSMISSION)

**Network role:** Mechanical force transmitter and sensory network. 80% of
acupoints at fascial planes. Mechanotransduction (integrin-FAK-ERK → NF-κB↓).
CB1/CB2 receptors in fascial fibroblasts (Fede 2016) = molecular substrate
for endocannabinoid system pressure threshold. Hundreds of millions of nerve endings = "sensory
megaphone." Primarily Level 0 (local tissue). A03 is DOMINANT system for
deep tissue/MFR therapies (B04).
→ A03-Fascia-Connective-Tissue.md

### §4.4 A04 — Vascular & Lymphatic (DELIVERY & REPAIR)

**Network role:** Circulatory effector and HO-1 repair pathway. NO at
acupoints. HO-1 cascade = PRIMARY mechanism for microtrauma therapies
(B07/B09). Lewis triple response. Respiratory pump (breathing → venous
return). Primarily Level 0. A04 is DOMINANT system for cupping/gua sha
(the ONLY vascular-dominant therapies in Track B).
→ A04-Vascular-Lymphatic.md

### §4.5 A05 — Neuroimmune Interface (AMPLIFICATION)

**Network role:** Signal amplifier and immune modulator. Bidirectional
communication: nervous system ↔ immune system. Vagal anti-inflammatory
pathway (Tracey, cholinergic). Neurogenic inflammation (axon reflex →
CGRP/SP → mast cells → histamine). Myokine pathway (B15/B16 exercise).
Force-immune axis: mechanical force → immune response. Level 0-1 (indirect
to brain via cytokines).
→ A05-Neuroimmune-Interface.md

### §4.6 A06 — Endocrine-Local (MODULATION)

**Network role:** Chemical signal modulator. Six signaling systems relevant
to body therapy: endocannabinoid system (AEA/2-AG, pressure-threshold-dependent), opioid
(frequency-prescribable via EA: 2Hz=enkephalin, 100Hz=dynorphin), adenosine
(24× at needle-fascia interface), oxytocin (CT→PVN pathway), cortisol
(HPA axis, Moyer caveat: between-group d=0.05-0.30), TRPV1 convergence
hub (heat + endocannabinoid system + eicosanoid + opioid sustain). Deepest individual system
reach: Level 0-4 (varies by molecule).
→ A06-Endocrine-Local.md

### §4.7 A07 — Dermatome-Somatotopic Map (ROUTING)

**Network role:** Signal routing system. Determines WHERE therapeutic signals
are delivered based on convergence principles. Dermatome-viscerotome mapping
(Head zones). Head zones = Back-Shu points (1-in-5-billion coincidence odds,
Dorsher). Kim 2017 neurogenic inflammatory spots = dynamic acupoints. Operates
at Level 2 (routing WITHIN Gap 2). Does not generate signals — DIRECTS them.
→ A07-Dermatome-Somatotopic-Map.md

### §4.8 A08 — Muscle, Tendon, Joint (MOVEMENT & POSITION)

**Network role:** Musculoskeletal effector and proprioceptive sensor. Trigger
points (70% trigger point-acupoint overlap). Four Freeman-Wyke joint receptor types.
Gamma loop reset (B10 chiropractic). Joint = SENSORY ORGAN, not passive hinge.
A08 is PRIMARY for chiropractic (B10) and shared PRIMARY with A02 for active
therapies (B15/B16). Level 0-2 (proprioceptive cortex partially).
→ A08-Muscle-Tendon-Joint.md

### §4.9 A09 — Meridian/Composite Substrate (CONVERGENCE)

**Network role:** Multi-system convergence zone identifier. Meridians ≠ single
anatomical channel; they represent zones where multiple systems converge.
PROKR2 molecular marker confirms at least ONE measurable substrate. Seven
candidate substrates assessed. Composite Substrate Assessment: acupoints =
neural + fascial + vascular + immune + chemical overlap. Spans ALL levels.
→ A09-Meridian-Examination.md

## §5 — HARDWARE VARIATION

The body's signaling infrastructure varies between individuals. Four primary
variation domains (from C05 §3.4):

### §5.1 Receptor Density Variation

**CT afferents:** Density varies ~2-3× between individuals. Hairy skin only;
absent from palms, soles. Density decreases with age. Higher density → richer
affective touch pathway → potentially stronger Direct-State touch response. 🟢

**Mechanoreceptors:** Meissner (glabrous) and Pacinian (deep) distribution
varies. Fingertips ~100× density vs. back skin. Clinical relevance for touch-
based therapy unclear. 🟢

### §5.2 Fascial Architecture Variation

**Sex:** Female fascial tissue is thinner with different collagen organization.
ERα expression in fascia → hormone-responsive tissue. 🟢

**Age:** Fascial hydration decreases with age → increased stiffness, reduced
mechanotransduction efficiency. 🟢

**BMI:** Subcutaneous fat thickness affects depth of stimulus reaching deep
fascia → shifts the endocannabinoid system activation threshold (more pressure needed in higher
BMI). 🟡

**CB1/CB2 receptor density:** Fede 2016 confirms fascial expression, but
individual variation not characterized. 🟡

### §5.3 Nerve Distribution Variation

**Dermatomes:** Vary ±1-2 segments between individuals. Exact segmental
targeting (A07 routing) is inherently approximate. 🟢

**PROKR2 expression:** Distribution may vary by individual, affecting which
acupoints activate the vagal-adrenal anti-inflammatory pathway. Unknown. 🔴

**Trigeminal branching:** Anatomical variants in CN V distribution affect
facial therapy precision. 🟢

**ABVN innervation area:** The vagal branch at the ear concha varies in
extent. May affect auricular acupuncture/acupressure effectiveness. 🟡

### §5.4 Autonomic Baseline Variation

**Sympathetic-parasympathetic balance:** Higher baseline sympathetic tone →
greater potential for parasympathetic shift during therapy → larger acute
autonomic response. Paradox: the most stressed patients show the largest
acute ANS changes. 🟡

**Baseline HRV:** Higher baseline HRV = greater autonomic flexibility.
Lower baseline = both more room to improve AND potentially harder to shift. 🟡

### §6.1 What This Architecture Provides

1. **A unified network view** of 9 previously separate system descriptions.
   No single Track A file shows how systems interact; this file does.

2. **Four-dimensional mapping** (depth × region × timing × stimulus) that
   predicts which systems activate for any given therapeutic intervention.

3. **The depth stratification principle** connecting Body-Signal-Architecture's body-side data
   to Human-Predictive-Drive's Zone D framework — showing where each system operates and
   how deep signals travel.

4. **The partial dissolution insight** that many therapy effects stay LOCAL
   (Levels 0-1) without ever reaching the brain — the driver layer IS
   therapeutic territory.

### §6.2 What This Architecture Does NOT Provide

1. **Mechanism of action.** This file shows WHAT infrastructure exists, not
   HOW therapies use it. → Core-Therapy-Architecture.md

2. **Quantitative activation levels.** The C01 matrix uses ordinal levels
   (PRIMARY > STRONG > MODERATE > MINIMAL > NONE), not continuous measures.
   Exact system activation intensities are unknown for all therapies.

3. **Integration rules.** How signals from multiple simultaneously-activated
   systems COMBINE into a coherent therapeutic experience is unknown (D01
   Q2). Parallel processing is established; integration mechanism is not.

4. **Brain-side processing.** What happens to signals after they reach Level 4
   (cortical processing) is Human-Predictive-Drive territory. Body-Signal-Architecture maps body-to-brainstem; Human-Predictive-Drive
   maps brainstem-to-consciousness.

5. **Non-therapy signal processing.** This architecture applies to THERAPY
   signals only. Hunger, injury pain, temperature regulation, and other body
   signals likely use overlapping but non-identical pathways.

### §6.3 Open Architectural Questions

**Q1 (CRITICAL): How do 5+ simultaneously activated systems INTEGRATE?**
A single therapy stimulus activates multiple systems on parallel timescales.
Do they merge at a specific relay point, or does the brain process them as
independent signals? (D01 Q2)

**Q2: Is the depth hierarchy FIXED or PLASTIC?** Can repeated therapy shift
which processing level a signal reaches? (e.g., can repeated acupuncture
cause initially-local signals to recruit higher-level processing?) (D02 Q4)

**Q3: What determines the endocannabinoid system activation threshold precisely?** Estimated at
40-65N but never directly measured. Is it a function of fascial depth, CB1/CB2
density, tissue hydration, or some combination? (C01 §4.6)

**Q4: Does the body region hierarchy hold across stimulus types?** Face > ear
> back > foot was derived primarily from pressure/needle data. Does it hold
for thermal, movement, or microtrauma stimuli? (C04 Q4)

**Q5: Are there undiscovered voluntary access points to Zone D beyond
breathing?** D02 Q1: the Zone D Bridge (breathing) is the only confirmed
voluntary access. Could movement patterns, vocal production, or other
motor outputs provide additional bridges?

## Closing Note

This file maps the body's signaling infrastructure — the physical substrate
through which body-based therapies produce their effects. The 9 systems form
an integrated network organized by depth, region, timing, and stimulus type.

The most important architectural insight: body therapy effects are produced
by MULTI-SYSTEM simultaneous activation across MULTIPLE processing depths,
with many effects staying LOCAL (Levels 0-2) without reaching cortical
awareness. The body's signaling infrastructure is not a passive relay to the
brain — it is an active processing network in its own right.
