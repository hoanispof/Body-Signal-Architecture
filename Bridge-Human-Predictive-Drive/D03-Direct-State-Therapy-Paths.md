## §2 — Human-Predictive-Drive CONCEPT: Direct-State Reward Architecture

### §2.1 Core Distinction

Human-Predictive-Drive identifies two orthogonal types of body-base confirm signal
(Reward-Signal-Architecture.md §1.1):

```
EVALUATIVE REWARD:
  Circuit: Hedonic hotspot (NAcc shell, VP, mOFC)
  Primary signal: μ-opioid
  Requires: 5 Body-Feedback-Preconditions (compiled chunks + body-need gap)
  Learned: YES — quality depends on chunk library
  Examples: food, music, insight, visual beauty
  Mechanism: Input → EVALUATE vs body-need → confirm/reject
  Naltrexone: BLOCKS ✅

DIRECT-STATE REWARD:
  Circuit: Interoceptive / body-state regulation (VARIES)
  Primary signal: VARIES (CT→posterior insula, endocannabinoid system CB1, thermoreceptors)
  Requires: Hardware pathways (minimal compiled chunks)
  Learned: MINIMAL — hardware from birth
  Examples: touch comfort, runner's high, warmth, stretching
  Mechanism: Body activity → state DIRECTLY improves → signal
  Naltrexone: NO EFFECT ⚠️
```

The naltrexone test is Human-Predictive-Drive's key discriminator (§9.1): opioid blocker eliminates
Evaluative Reward (food, music) but leaves Direct-State Reward (touch, exercise)
intact. 🟢 Loseth 2019; 🟢 Fuss 2015 PNAS; 🟢 Mallik 2017.

### §2.2 Three Named Direct-State Modalities

Human-Predictive-Drive identifies three hardware-based reward pathways:

**CT Afferents (Touch)**
- C-tactile unmyelinated fibers in hairy skin
- Optimal velocity: 1-10 cm/s (slow stroking)
- Pathway: CT → lamina I → posterior insula (🟢 Löken 2009)
- Function: affective/pleasant touch (distinct from discriminative Aβ)

**Endocannabinoid CB1 (Exercise)**
- Exercise → systemic eCB release (AEA, 2-AG)
- CB1 receptor activation in multiple tissues
- Naltrexone does NOT reduce exercise euphoria (🟢 Fuss 2015 PNAS)
- Independent of opioid: eCB in exercise ≠ eCB in NAcc hotspot

**Thermoreceptors (Temperature)**
- TRPV1 (>42°C), TRPM8 (<25°C)
- Direct hypothalamic homeostatic regulation
- Naltrexone test: untested (🔴 framework prediction)

### §2.3 E₀→E₃ Complexity Gradient

Direct-State sits BELOW the E₀→E₃ gradient (Reward-Signal-Architecture.md §1.7):

```
  Direct-State     HARDWARE — below compiled/fresh axis
                   (no evaluation = no compilation)
  E₀               PRE-COMPILED by evolution (binary evaluation)
  E₁               COMPILED by individual (shallow)
  E₂               COMPILED by individual (deep)
  E₃               COMPILED expert-level (decades)
```

E₀ is still EVALUATIVE (opioid, template matching) even though it is hardware-
installed. The distinction: Direct-State = no evaluation at all (state change →
signal). E₀ = evaluation exists but is binary and pre-compiled (sweet → opioid).
🟡

### §2.4 Evaluative Gates Direct-State

Evaluative assessment MODULATES Direct-State signal via the posterior-to-anterior
insula gradient (Reward-Signal-Architecture.md §3.1):

```
Step 1: Direct-State arrives at posterior insula (~0-50ms) — RAW
Step 2: Evaluative assessment fires in parallel (~50-200ms)
Step 3: Anterior insula integrates BOTH (~100-300ms)
Step 4: ACC conflict check (~200-400ms)
Step 5: OFC/vmPFC value assignment (~300-500ms)

4 Outcomes:
  Evaluative positive (trusted) → AMPLIFY Direct-State
  Evaluative negative (threat)  → SUPPRESS Direct-State
  Evaluative absent (infant)    → Direct-State RAW
  Evaluative conflicted         → AMBIGUOUS
```

This mechanism applies to body therapy: the SAME Direct-State touch signal is
AMPLIFIED by a trusted therapist and SUPPRESSED in an unsafe context. (Detail
in D04.)

### §2.5 Direct-State = Burnout-Proof (Human-Predictive-Drive Claims)

Human-Predictive-Drive classifies Direct-State as the "evolutionary floor" (§1.4):

- NOT affected by Precondition-2 failure (chunk library empty)
- NOT affected by Precondition-5 cortisol tag
- Likely bypasses VTA → NOT subject to hedonic treadmill
- Resistant to hedonic adaptation (🟢 Brickman & Campbell 1971 applies to
  Evaluative, not Direct-State)
- "Rich or poor, a hug still feels the same"

Therapeutic implication: when Evaluative Reward is exhausted (burnout,
anhedonia), Direct-State Reward remains accessible = "backdoor" past stuck
Evaluative gate. 🟢 Van der Kolk 2014.

### §2.6 Temporal and Decay Properties

Direct-State has distinct temporal characteristics (Reward-Signal-Architecture.md
§5.1-§5.2):

```
ONSET:   Direct-State ~20-100ms (fastest — no evaluation needed)
         E₀ ~100-300ms → E₁ ~200ms-1s → E₂ ~500ms-2s → E₃ ~1-5s

DECAY:   Evaluative = VTA HABITUATION (central, universal)
         Direct-State = RECEPTOR ADAPTATION (peripheral, modality-specific):
           CT dynamic touch: SLOW adaptation (designed for sustained contact)
           CT static touch:  FAST adaptation
           Temperature:      FAST (~5-10 min)
           Exercise eCB:     SLOW (weeks/months)

PREVIEW: Direct-State ~5-15% fidelity (hardware-bound, can't simulate CT)
         E₃ ~60-80% fidelity (purely cortical, fully simulable)
```

Low preview fidelity → Direct-State is resistant to CRAVING (needs actual
experience, not imagination) → resistant to wanting-without-liking. 🟡

### §2.7 Neurochemical Multi-Role Principle

Same molecule, different circuit, different function (§1.5):

```
Endocannabinoid:
  IN NAcc hotspot → opioid-DEPENDENT AMPLIFIER → Evaluative Reward
  IN exercise     → opioid-INDEPENDENT PRIMARY  → Direct-State Reward
  IN fascia (Body-Signal-Architecture) → local CB1/CB2 activation     → Direct-State? (D03 question)

Opioid:
  IN hedonic hotspot → hedonic evaluation         → Evaluative Reward
  IN PAG-NRM         → pain inhibition            → pain modulation (see §4.3)
```

This principle is CRITICAL for D03: the same molecule (eCB, opioid) can serve
Direct-State OR Evaluative function depending on the circuit. Classification
must be by CIRCUIT, not by molecule. 🟡

organizing tools, not empirical data.

**L2.** The Therapy Reward Depth Gradient (§4.2 F2) assumes that E₀→E₃ levels
are SEPARABLE. In biological reality, these layers interact (Evaluative Gates
Direct-State modulates ALL levels simultaneously). The gradient is a conceptual
tool, not a claim about discrete neural modules.

**L3.** Gate control classification as "Direct-State Relief" (§4.2 F3) is
FRAMEWORK SYNTHESIS. Human-Predictive-Drive does not include gate control in its Direct-State
category. The classification is based on meeting 4 criteria (no evaluation,
hardware, non-opioid, from birth) — but Human-Predictive-Drive's criteria are for REWARD, and
whether pain relief constitutes reward is philosophically contested.

**L4.** Body-Signal-Architecture has no LONGITUDINAL Direct-State data. All claims about burnout-
proofness (§5.4) are inferred from receptor physiology, not from multi-year
follow-up of therapy outcomes. The absence of tolerance reports is suggestive
but not confirmatory.

**L5.** The classification applies to the BODY-SIDE mechanism only. Brain-side
processing (how the insula handles Direct-State vs Evaluative signals) is Human-Predictive-Drive's
domain and is not tested by Body-Signal-Architecture data.

**L6.** Individual variation in Direct-State hardware (C05 §3.4.1: CT density,
§3.4.2: CB1/CB2 expression) means the "universal" property of Direct-State is
a POPULATION-LEVEL statement. Individuals with neuropathy, low CT density, or
altered FAAH activity may have substantially reduced Direct-State capacity.

## §8 — OPEN QUESTIONS

**Q1 (CRITICAL): Does naltrexone block gate control analgesia?** 🔴
This would definitively classify gate control as Direct-State (if no block) or
E₀ Evaluative (if blocked). Gate control is the most UNIVERSAL therapy mechanism
(12/16 therapies, C03 §3.2), so its classification determines the reward type of
the entire non-specific floor.

**Q2: Is fascial endocannabinoid system activation (deep pressure CB1/CB2) the SAME Direct-State
reward as exercise endocannabinoid system (systemic CB1)?** 🔴
Both are eCB-mediated, both are non-opioid. But the circuits differ (local
fascial vs systemic). Whether they produce the same subjective reward experience
determines whether deep massage and exercise are interchangeable at the
Direct-State level.

**Q3: Can Direct-State capacity be TRAINED beyond hardware limits?** 🔴
B15/B16 practitioners report increasing enjoyment over time. Is this:
(a) Zone D Bridge becoming more efficient → faster/stronger Direct-State signal?
(b) Motor skills compiling → richer Evaluative (E₁-E₂) reward layer added?
(c) Interoceptive training → better DETECTION of existing Direct-State signal?
Each answer has different implications for D05 (interoception training).

**Q4: What is the MINIMUM Direct-State input required for the non-specific
floor?** 🔴
C02 documents SMD 0.2-0.4 floor. D03 identifies this as Direct-State minimum.
But what is the THRESHOLD input? Does ultra-light touch (<0.5N, lymphatic
only) produce a floor effect? Or does the floor require at least gate control
activation (>5N)? This distinguishes "any contact = Direct-State" from
"gate control threshold = Direct-State onset."

**Q5: Does the Direct-State/Evaluative ratio SHIFT during a therapy session?** 🔴
A massage session typically starts light (CT Direct-State) → goes deep (endocannabinoid system
Direct-State + E₁ opioid) → returns light (CT Direct-State). Does this mean
the reward type OSCILLATES within a session? If so, session design could be
optimized by timing pressure changes to maximize Direct-State engagement
windows.

**Q6: Are there Direct-State DISSONANCE pathways activated by body therapy?** 🔴
Human-Predictive-Drive's Dissonance-Signal-Architecture.md describes Direct-State Dissonance
(hardware pain pathways). Body therapy INTENTIONALLY activates nociceptors
(B01 needling, B04 deep pressure pain). Does therapy produce BOTH Direct-State
Reward (CT, endocannabinoid system) AND Direct-State Dissonance (nociceptor) SIMULTANEOUSLY? If
so, the net signal depends on which dominates — and gate control is the
mechanism that tips the balance.
