# Body-Signal-Architecture

> **Version:** 0.1 | **Started:** 2026-07-28
> **Status:** Phase 0 — Setup complete, ready for Phase 1

## What This Project Is

A systematic investigation into HOW body-based therapies (acupuncture, massage, acupressure, reflexology, cupping, etc.) produce real therapeutic effects.

The central question: **What happens between "stimulus applied to body" and "therapeutic effect"?**

## Relationship to Human-Predictive-Drive

Human-Predictive-Drive (v8.0, ~148,000 lines) describes how the BRAIN processes signals. This project builds the complementary **"Body-Side Sender Architecture"** — what happens IN THE BODY before signals reach the brain. Together they form a complete picture.

This project fills Human-Predictive-Drive's acknowledged Gap 2 ("Driver Layer") from the therapy perspective.

**Human-Predictive-Drive-compatible, not Human-Predictive-Drive-dependent.** This project can be read independently.

## Approach

**Bottom-up, data-first.** Empirical evidence (clinical outcomes, research studies) = primary data. Framework emerges FROM data, not imposed ON data.

## How to Navigate

1. Start with `plan.md` — it contains the full project plan, templates, quality rules, and progress tracker.
2. Track A files (A01-A09) describe body systems.
3. Track B files (B01-B16+) describe individual therapy methods.
4. Track C and D files synthesize across tracks.

## Quality Standards

- Every claim has a source citation
- 3-tier confidence: 🟢 Research | 🟡 Synthesis | 🔴 Hypothesis
- Templates enforced for consistency
- No premature synthesis — patterns only in Track C
- Honest unknowns documented
