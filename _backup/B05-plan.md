### Central Question
```
THE FACE AS SOLE THERAPEUTIC SURFACE — TRIGEMINAL SPECIFICITY:

  Dien Chan is UNIQUE among Track B therapies in TWO ways:

  ① FACE-ONLY therapy:
    → All other Track B therapies work on body (trunk, limbs, back)
    → Dien Chan works EXCLUSIVELY on the face (+ some head/ear)
    → The face = territory of CN V (trigeminal), NOT spinal nerves
    → Different organizational principle entirely

  ② NON-INVASIVE, NON-PENETRATING:
    → No needles (unlike B01, B11)
    → No cups (unlike B07)
    → Uses multireflex tools: rollers, balls, probes
    → Pressure + rolling + tapping on 257 fixed points
    → More similar to acupressure (B02) but FACE-SPECIFIC

  Central mechanism question:
    Can stimulation of 257 facial points, mediated through
    CN V trigeminal branches (V1/V2/V3), produce ORGAN-SPECIFIC
    therapeutic effects via trigeminal-vagal coupling?

  The neuroanatomical SUPPORT:
    → Trigeminal → brainstem → vagal nucleus = PROVEN pathway
    → Diving reflex = PROOF of powerful trigeminal-vagal coupling
    → eTNS = FDA-approved therapy using SAME V1 pathway
    → BUT: eTNS uses electrical stimulation, Dien Chan uses pressure

  The neuroanatomical CHALLENGE:
    → Organ specificity from facial zones is UNPROVEN
    → 30+ projection maps claim organ-level precision
    → Neuroanatomy supports GENERAL parasympathetic shift
    → Whether V1 vs V2 vs V3 stimulation → DIFFERENT organs = 🔴
    → "Onion-skin" pattern in trigeminal nucleus ≠ segmental mapping
```

### Boundary Decisions
```
B05 vs B02 (Acupressure):
  BOTH use pressure on specific points, NO penetration
  B05 = FACE ONLY, via trigeminal nerve
  B02 = BODY (mostly), via spinal nerves + some facial points
  B02 covers facial acupressure BRIEFLY (Yintang, auricular)
  B05 covers the FULL facial reflexology system + its unique maps

B05 vs B06 (Foot Reflexology):
  BOTH are "reflexology" — claim body projection maps
  B05 = face as body map (trigeminal nerve)
  B06 = foot as body map (spinal nerves S1-L5)
  SAME theoretical framework, DIFFERENT nerve territories
  B05 can compare in §7 but NOT duplicate B06 mechanisms

B05 vs B01 (Acupuncture):
  TCM facial acupoints (ST2, GB14, etc.) ≠ Dien Chan points
  Dien Chan uses 257 OWN points, different from TCM system
  Some overlap possible but different theoretical basis
  B05 covers comparison in §7

B05 vs eTNS (external trigeminal nerve stimulation):
  eTNS = electrical stimulation of V1 (supraorbital)
  Dien Chan = mechanical stimulation of V1/V2/V3 (pressure/rolling)
  SAME nerve territory, DIFFERENT stimulus modality
  eTNS = medical device, FDA-approved, well-researched
  Dien Chan = traditional therapy, no regulatory status
  B05 uses eTNS as MECHANISTIC PARALLEL, not as "same therapy"
```
