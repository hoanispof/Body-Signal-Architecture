### Central Question
```
SAME NEEDLE + SAME POINTS (93.3%) + DIFFERENT THEORY:
  → DN targets trigger points via Western biomedical model
  → Acupuncture targets acupoints via TCM or neuroanatomical model
  → Dorsher 2008: 238/255 trigger points (93.3%) correspond to
    classical acupoints; 94% pain indication match

  Key answer from Track A + B01:
    DN = L1-L2 of B01's 6-level model (local tissue + peripheral nerve)
    Acupuncture = L1-L6 (adds segmental, brainstem, cortical, systemic)
    
  3 divergence points:
    1. Scope of theory: muscle-only (NMJ pathology) vs whole-body
    2. Treatment approach: fewer points, shorter, aggressive vs
       many points, longer, gentle
    3. Professional context: PT adjunct (27-150 hrs training) vs
       standalone profession (1,905-4,000 hrs)
    
  Unique dimension: scope-of-practice DEBATE between PT and
  acupuncture professions. 42 US states allow PTs; 3 prohibit.
  This is the ONLY Track B file with a significant sociopolitical layer.
```

### Boundary Decisions
```
B11 vs B01:
  B11 = SAME needle (FDA filiform) targeting TRIGGER POINTS via
        Western biomedical model (motor endplate dysfunction)
  B01 = SAME needle targeting ACUPOINTS via TCM or neuroanatomical model
  93.3% anatomical overlap (Dorsher) → B11 must address this directly
  DIFFERENT: theory, training, point selection method, session approach
  
B11 vs B04 (Deep Tissue/Myofascial Release):
  B11 = INVASIVE (needle penetration into muscle)
  B04 = NON-INVASIVE (manual pressure/stretch of myofascial tissue)
  OVERLAP: both target trigger points, both aim for taut band release
  DISTINCTION: B11 uses needle (LTR, ACh depletion); B04 uses hands
  
B11 vs B02 (Acupressure):
  B02 explicitly identified LTR as LOST mechanism (needle-specific)
  B11 = the modality where LTR is the PRIMARY mechanism
  
Injection therapy (wet needling):
  NOT included in B11 — B11 covers DRY needling only
  Cummings & White 2001: no advantage of injection over dry needle
  Historical context: Travell originally used injections → Lewit 1979
  showed needle alone sufficient → "dry" needling emerged
  
IMS (Gunn's Intramuscular Stimulation):
  INCLUDED in B11 as major variant — same needle, different model
  (radiculopathy/denervation supersensitivity vs trigger point/NMJ dysfunction)
  
FSN (Fu's Subcutaneous Needling):
  INCLUDED in B11 as distinct variant — subcutaneous layer,
  not into muscle, different needle (modified trocar)
```

```
  §4.1: Evidence tiering methodology
```

### S2 — Mechanisms + Variants + Synthesis (§5-§8, §10-§11)
```
→ §5 Proposed Mechanisms (~350 lines):
  §5.1: Traditional explanation — none (Western biomedical from start)
        BUT: Gunn's radiculopathy model vs Travell-Simons trigger point model
  §5.2: Modern mechanisms — 4-level model:
    L1 LOCAL TISSUE:
      ① LTR → mechanical disruption of taut band → sarcomere release
      ② ACh depletion at motor endplate → reduced SEA
      ③ Micro-wound → inflammatory repair cascade (DAMPs, HMGB1)
      ④ Purinergic: ATP release → adenosine → A1 analgesia (Goldman 2010)
      ⑤ Local opioid release (immune cells + keratinocytes)
      ⑥ Shah milieu normalization (pH, SP, CGRP, BK clearance)
    L2 SEGMENTAL:
      ① Gate control (Aδ fibers → dorsal horn inhibition)
      ② Segmental inhibition within myotome
      ③ Dorsal horn neuroplasticity modulation
      ④ IMS paraspinal rationale (Gunn's segmental targeting)
    L3 SUPRASPINAL:
      ① Descending inhibition (PAG/RVM)
      ② DNIC / Conditioned Pain Modulation ("pain inhibits pain")
      ③ Endogenous opioid release
      ④ Central sensitization reversal (widespread hyperalgesia ↓)
    L4 CONNECTIVE TISSUE/FASCIAL:
      ① Collagen winding (Langevin 2001 — shared with acupuncture)
      ② Fibroblast remodeling (Rho/Rac)
      ③ FSN's subcutaneous mechanism
  §5.3: Framework Synthesis — "Different Entry Point, Same Building":
        DN enters at L1-L2 (trigger point → endplate → segment)
        Acupuncture enters at L1-L6 (acupoint → whole system)
```
