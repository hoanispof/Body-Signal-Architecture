## §1. DEFINITION & ORIGIN

### §1.1 Definition

Chiropractic = a healthcare profession focused on diagnosis, treatment,
and prevention of mechanical disorders of the musculoskeletal system,
particularly the spine, through manual adjustment/manipulation.

```
┌─────────────────────────────────────────────────────────────────┐
│  CHIROPRACTIC IN ONE SENTENCE:                                  │
│                                                                 │
│  High-velocity low-amplitude thrust applied to spinal and       │
│  peripheral joints to restore joint mobility and modulate       │
│  neuromuscular function via proprioceptive and nociceptive      │
│  reflex pathways.                                               │
│                                                                 │
│  KEY DISTINCTION IN TRACK B:                                    │
│  The ONLY therapy primarily targeting JOINTS (articular          │
│  structures) rather than soft tissue, skin, or fascia.          │
│  The ONLY therapy where A08 (Muscle-Tendon-Joint) is the        │
│  PRIMARY activated system.                                      │
└─────────────────────────────────────────────────────────────────┘
```

### §1.3 Etymology

  CHIROPRACTIC:
    Greek: χείρ (cheir) = hand + πρᾶξις (praxis) = practice/action
    → "done by hand" / "practiced by hand"
    Coined by: Rev. Samuel Weed (friend of D.D. Palmer), 1896

  ADJUSTMENT (chiropractic-specific term):
    → Preferred term within the profession for HVLA thrust
    → Distinguished from "manipulation" (broader, shared term)
    → Carries theoretical connotation of "correcting" alignment
    → This file uses "SMT" or "HVLA" for the physical technique,
      "adjustment" only when discussing chiropractic-specific concepts

  VIETNAMESE: Nắn chỉnh cột sống
    → Nắn = manipulate/adjust; chỉnh = correct/straighten
    → Cột sống = spinal column
    → Direct descriptive translation (no traditional Vietnamese equivalent)

  OTHER LANGUAGES:
    → Japanese: カイロプラクティック (kairopurakutikku) — transliteration
    → Korean: 카이로프랙틱 (kairopeulaektik) — transliteration
    → Chinese: 脊椎指压治疗 (jǐzhuī zhǐyā zhìliáo) = spinal finger-
      pressure therapy, or 整脊 (zhěngjǐ) = spine-straightening

  NOTE: Unlike acupuncture (针灸) or moxibustion (灸), chiropractic
  has NO traditional Asian terminology — it is a Western-origin practice.
  The transliterations reflect its foreign origin in East Asian contexts.

### §1.6 Bonesetting Traditions — Historical Precursors

  SMT did NOT begin with Palmer. Manual spinal manipulation has
  deep historical roots across cultures:

    → HIPPOCRATES (~400 BCE): described spinal traction and
      manipulation techniques for back deformity
    → GALEN (~150 CE): documented manual spine correction
    → MEDIEVAL EUROPE: "bonesetters" — lay practitioners of
      joint manipulation, often hereditary skill
    → INDONESIA: traditional "urut tulang" (bone massage)
    → CHINA: 推拿 (tuī ná) includes spinal manipulation techniques
      (distinct from acupuncture/moxibustion tradition)
    → MEXICO: "huesero" (bonesetter) tradition
    → NEPAL/INDIA: traditional manipulation practices

  Palmer's contribution was not INVENTING spinal manipulation but
  SYSTEMATIZING it into a profession with a theoretical framework
  (however contested that framework became).

### §2.2 Biomechanics of the HVLA Thrust

```
  THE THRUST SEQUENCE (3 phases):

  Phase 1: POSITIONING (patient setup)
    → Patient positioned to isolate target joint segment
    → Practitioner identifies target vertebra/joint
    → Body positioned to lock adjacent segments

  Phase 2: PRELOAD (take up slack)
    → Gentle pressure applied to target joint
    → Takes joint to END of passive range of motion
    → "Engages the barrier" — joint at physiological limit
    → Periarticular tissues under tension
    → Duration: 0.5-2 seconds typically

  Phase 3: THRUST (the adjustment)
    → Rapid, controlled force application
    → Takes joint BEYOND passive ROM into paraphysiological zone
    → Does NOT exceed anatomical limit (would = injury)
    → Followed by immediate release

  ┌───────────────────────────────────────────────────────────────┐
  │  RANGE OF MOTION ZONES:                                       │
  │                                                               │
  │  ←─ Active ROM ─→←─ Passive ─→←─ Paraphysio ─→← Anatomical │
  │  |               |            |               |    LIMIT     │
  │  Patient can     Examiner     HVLA thrust     Beyond =       │
  │  move            can push     enters here     INJURY         │
  │  voluntarily     further      (therapeutic)                   │
  └───────────────────────────────────────────────────────────────┘
```

  FORCE PARAMETERS (🟢 measured in biomechanical studies):

  ```
  ┌───────────────────────┬───────────────────────────────────────┐
  │ Parameter             │ Typical Values                        │
  ├───────────────────────┼───────────────────────────────────────┤
  │ Peak force            │ 200-600 N (varies by region)          │
  │   Cervical            │   100-200 N (lower — smaller joints)  │
  │   Thoracic            │   200-400 N                           │
  │   Lumbar/SI           │   300-600 N                           │
  │ Thrust duration       │ 100-200 ms (< 0.2 seconds)           │
  │ Preload force         │ 50-150 N (sustained before thrust)    │
  │ Preload duration      │ 500-2000 ms                           │
  │ Thrust amplitude      │ 1-5 mm (LOW amplitude)                │
  │ Rate of force         │ 1000-4000 N/s (HIGH velocity)         │
  │ application           │                                       │
  └───────────────────────┴───────────────────────────────────────┘

  KEY: the defining feature is RATE OF FORCE APPLICATION
  (velocity), not the peak force itself. Many massage
  techniques apply HIGHER total force but much more slowly.
  ```

  🟢 Herzog et al. 1993, 2001 — foundational biomechanical
  measurements of SMT force profiles using force plates and
  accelerometers during actual chiropractic adjustments.

### §2.3 Joint Cavitation

```
┌─────────────────────────────────────────────────────────────────┐
│  THE "CRACK" — JOINT CAVITATION                                 │
│                                                                 │
│  The audible "pop" or "crack" during HVLA is one of the most    │
│  recognized features of chiropractic adjustment.                │
│                                                                 │
│  MECHANISM (🟢):                                                │
│  → Kawchuk et al. 2015 (PLOS ONE) — real-time MRI of MCP       │
│    joint cracking:                                              │
│    • Gas cavity FORMS during joint separation (tribonucleation) │
│    • The "crack" correlates with cavity FORMATION, not collapse │
│    • Overturns prior "bubble collapse" hypothesis               │
│    • Cavity = primarily CO2 in synovial fluid                   │
│                                                                 │
│  ⚠ CAVEAT:                                                     │
│  → Kawchuk study used metacarpophalangeal (finger) joints       │
│  → Spinal facet joints assumed similar mechanism (🟡)           │
│  → Refractory period: ~20 minutes before re-cavitation          │
│    (explains why you can't "crack" again immediately)           │
│                                                                 │
│  CLINICAL SIGNIFICANCE QUESTION:                                │
│  → Does the cavitation CONTRIBUTE to therapeutic effect?        │
│  → Or is it merely an EPIPHENOMENON of joint gapping?           │
│  → Evidence mixed: some studies show similar outcomes            │
│    with and without audible cavitation (🟡)                     │
│  → See §10 Q2 for full analysis                                 │
└─────────────────────────────────────────────────────────────────┘
```

  🟢 Cramer et al. 2011 — cadaver study showing measurable facet
  joint gapping (separation) during SMT, with and without
  cavitation. Joint gapping occurs regardless of "crack."

### §2.5 Mobilization vs Manipulation Spectrum

```
  THE MAITLAND GRADING SYSTEM:

  ┌────────┬────────────────────────────────────────────────────────┐
  │ Grade  │ Description                                            │
  ├────────┼────────────────────────────────────────────────────────┤
  │ I      │ Small amplitude, beginning of range. Gentle oscillation│
  │ II     │ Large amplitude, within range. Rhythmic movement       │
  │ III    │ Large amplitude, reaching end of range                 │
  │ IV     │ Small amplitude, at end of range. Sustained pressure   │
  ├────────┼────────────────────────────────────────────────────────┤
  │ V      │ HVLA THRUST — beyond passive ROM into paraphysiological│
  │        │ zone. THIS is "manipulation" / "adjustment"            │
  └────────┴────────────────────────────────────────────────────────┘

  Grade I-IV = MOBILIZATION (physiotherapy, osteopathy, chiropractic)
    → Slow, rhythmic, within ROM
    → No cavitation expected
    → Activates primarily Type I receptors (slowly adapting)

  Grade V = MANIPULATION (chiropractic, osteopathic HVLA)
    → Fast, single thrust, beyond passive ROM
    → Cavitation expected
    → Activates primarily Type II receptors (rapidly adapting)
    → = The defining technique of chiropractic

  🟡 VELOCITY HYPOTHESIS (framework synthesis):
  The mechanical difference between mobilization and manipulation
  may translate to DIFFERENT neural activation profiles:
    → Type I (Ruffini-like): slowly adapting → responds to
      sustained pressure/position → activated by Grade I-IV
    → Type II (Pacinian-like): RAPIDLY adapting → responds to
      velocity and vibration → PREFERENTIALLY activated by Grade V
    → Different receptor activation → different afferent input →
      potentially different central processing
  This may explain why HVLA sometimes produces effects that
  mobilization does not (or vice versa), despite targeting the
  same joint. See §5.3 and §10 Q1.

  B03 (Massage-General) §2 explicitly marks Grade V as
  "B10 territory" (B03 line 511) — a clear boundary between
  soft tissue mobilization and joint manipulation.
```

### §3.2 Spinal Joint Anatomy — The Therapeutic Target

```
  THE FACET JOINT (ZYGAPOPHYSEAL JOINT) ⭐:

  Primary target of spinal HVLA thrust. This is what distinguishes
  B10 from ALL other Track B therapies — the target is the JOINT
  itself, not the surrounding soft tissue.

  STRUCTURE:
    → Superior articular process of lower vertebra articulates with
      inferior articular process of upper vertebra
    → Synovial joint: cartilage surfaces, synovial membrane,
      joint capsule, synovial fluid
    → Orientation varies by region:
      • Cervical: ~45° coronal → allows rotation + flexion
      • Thoracic: ~60° coronal → limits flexion, allows rotation
      • Lumbar: ~90° sagittal → allows flexion, limits rotation

  INNERVATION (🟢 critical for mechanism):
    → Medial branch of posterior ramus (dorsal ramus)
    → Each facet joint innervated by 2 spinal levels
      (above and below the joint)
    → Contains ALL 4 Freeman-Wyke receptor types (A08 §1.4):
      • Type I (Ruffini-like): joint position, capsule strain
      • Type II (Pacinian-like): joint acceleration, velocity
      • Type III (GTO-like): ligament strain, end-range
      • Type IV (free endings): nociception, inflammation
    → = The joint is a SENSORY ORGAN, not just a mechanical hinge

  ADDITIONAL SPINAL STRUCTURES:
    → Intervertebral disc: fibrocartilage, nucleus pulposus
      • NOT directly targeted by HVLA (no receptor activation)
      • But adjacent disc may experience pressure changes
    → Spinal ligaments: anterior/posterior longitudinal,
      supraspinous, interspinous, ligamentum flavum
      • Contain mechanoreceptors (Type III primarily)
      • Contribute to proprioceptive input during HVLA
    → Paraspinal muscles: multifidus, rotatores, semispinalis
      • Contain muscle spindles (Ia afferents)
      • Crossed by thrust → stretch reflex activation
```

### §3.3 Assessment and Targeting

```
  HOW CHIROPRACTORS SELECT TARGET SEGMENTS:

  ① STATIC PALPATION:
    → Feel for positional asymmetry, tenderness, tissue texture
    → Reliability: 🔴 POOR (Seffinger et al. 2004)
    → Inter-examiner agreement: κ = 0.02-0.39 (chance to fair)

  ② MOTION PALPATION:
    → Feel for restricted vs hypermobile segments during movement
    → Reliability: 🔴 POOR to FAIR (Haneline & Young 2009)
    → κ = 0.10-0.42 (slight to moderate)

  ③ IMAGING (X-ray, MRI):
    → NOT recommended for routine assessment (CCGPP guidelines)
    → Reserved for red flags (fracture, tumor, infection)
    → Historical overuse of X-ray in chiropractic criticized
    → "Subluxation" NOT reliably visible on imaging

  ④ ORTHOPEDIC/NEUROLOGICAL TESTING:
    → Range of motion testing, neurological screening
    → Better reliability than palpation for REGIONAL assessment
    → But: regional, not segmental precision

  ⚠ TARGETING PRECISION — A FUNDAMENTAL CHALLENGE:
    → Can practitioners reliably identify and manipulate a SPECIFIC
      vertebral segment? Evidence is weak (🔴).
    → Ross et al. 2004: thrust often affects multiple segments
    → Beffa & Mathews 2004: cavitation frequently occurs at
      adjacent segment, not the intended target
    → 🟡 This does NOT necessarily invalidate SMT — if the
      mechanism is primarily NEUROPHYSIOLOGICAL (proprioceptive
      barrage → central processing), precise segmental targeting
      may be less critical than the TOTAL afferent input generated
    → But it DOES challenge the subluxation model, which requires
      specific segment identification and correction
    → See §10 Q3
```

  Beyond the spine, chiropractors also adjust:

## §4. DOCUMENTED CLINICAL EFFECTS

### §4.1 Low Back Pain — Strongest Evidence

```
  LBP = the condition with MOST evidence for SMT benefit.
  Also the PRIMARY reason patients seek chiropractic care.

  KEY EVIDENCE:

  🟢 Rubinstein et al. 2019 (Cochrane — chronic LBP):
    → 47 RCTs, n = 9,211
    → SMT vs recommended therapies (exercise, standard medical
      care, physiotherapy):
    → Pain: MD -3.17 (95% CI -5.29 to -1.06) on 0-100 scale
    → Function: SMD -0.25 (95% CI -0.41 to -0.09)
    → = Small, statistically significant, clinically MODEST
    → Evidence quality: MODERATE (Cochrane GRADE)
    → Conclusion: "SMT produces similar effects to recommended
      therapies for chronic low-back pain"

  🟢 Rubinstein et al. 2012 (Cochrane — acute LBP):
    → 20 RCTs
    → SMT vs sham: small, short-term improvement in pain
    → SMT vs other interventions: no significant difference
    → Evidence quality: LOW to MODERATE

  🟢 Paige et al. 2017 (JAMA — acute/subacute LBP):
    → Systematic review + meta-analysis, 26 RCTs
    → SMT associated with "modest improvements in pain and
      function" at up to 6 weeks
    → Pain: MD -9.95 on 0-100 scale (95% CI -15.6 to -4.3)
    → "Clinically meaningful" but small absolute magnitude

  🟢 2017 ACP Guideline (Annals of Internal Medicine):
    → SMT listed among first-line non-pharmacological options
      for acute/subacute LBP
    → Alongside heat, massage, acupuncture

  🟢 2017 Lancet LBP Series:
    → SMT among recommended non-pharmacological options
    → Emphasis: exercise as primary, manual therapy as adjunct

  CLINICAL PROFILE FOR LBP:
    → SHORT-TERM benefit: consistent (🟢)
    → LONG-TERM benefit: unclear (🟡)
    → Superiority over other manual therapies: NOT demonstrated
    → SMT ≈ exercise ≈ standard care for chronic LBP
    → Added value as PART of multimodal approach: plausible (🟡)
```

### §4.2 Neck Pain

```
  SECOND MOST COMMON presentation in chiropractic practice.

  🟢 Gross et al. 2015 (Cochrane — cervical manipulation/mobilization):
    → Multiple RCTs reviewed
    → Moderate evidence: cervical manipulation produces
      short-term pain reduction
    → Combined with exercise: better than either alone
    → Mobilization vs manipulation: similar effects for most
      outcomes (🟡 — supports that VELOCITY may not be
      critical for clinical outcomes, or that different
      mechanisms converge on similar endpoints)

  🟢 Bronfort et al. 2012 (Annals of Internal Medicine):
    → 272 participants, acute/subacute neck pain
    → SMT vs medication (OTC analgesics, NSAIDs, narcotics)
    → SMT more effective than medication at 8, 12, 26, 52 weeks
    → Home exercise also more effective than medication
    → SMT ≈ home exercise (no significant difference between them)

  🟡 Combined cervical-thoracic SMT may produce BETTER outcomes
  than cervical SMT alone, suggesting regional rather than
  segment-specific mechanism.
```

### §4.3 Headache

```
  THREE HEADACHE TYPES studied:

  ① CERVICOGENIC HEADACHE (🟢 moderate evidence):
    → By definition: headache originating from cervical structures
    → SMT produces short-term improvement
    → Jull et al. 2002: SMT + exercise superior to either alone
    → Mechanistically logical: cervical joint dysfunction →
      trigeminocervical nucleus convergence → headache
    → A07 segmental model SUPPORTS this application

  ② TENSION-TYPE HEADACHE (🟡 some evidence):
    → Several RCTs with positive short-term results
    → Castien et al. 2011: manual therapy > usual care
    → But: manual therapy included more than just SMT
    → Mechanism unclear — may be via cervical component or
      via general pain modulation

  ③ MIGRAINE (🔴 weak evidence):
    → Chaibi et al. 2017: 3-arm RCT (SMT vs sham vs control)
    → SMT group: some improvement but NOT significantly better
      than sham SMT
    → Suggests non-specific/placebo effects
    → No clear mechanism for spinal manipulation → migraine
    → Some practitioners claim cervicotrigminal pathway (🔴)

  HIERARCHY: cervicogenic > tension-type > migraine
  Matches mechanistic plausibility: cervicogenic has clear
  cervical origin; tension-type has possible cervical component;
  migraine has no clear spinal mechanism.
```

### §4.4 Other Musculoskeletal Conditions

```
  ① THORACIC SPINE PAIN (🟡):
    → Limited RCTs. Thoracic SMT for thoracic pain: plausible
      but insufficient evidence for strong recommendation.

  ② SHOULDER CONDITIONS (🟡):
    → Shoulder impingement: some positive pilot studies
    → Frozen shoulder: case series only
    → Mechanistically: thoracic/cervical SMT may affect
      shoulder via T1-C5 segmental connection (🟡)
    → Insufficient RCT evidence

  ③ EXTREMITY JOINTS (🔴):
    → Very limited evidence base
    → Shared technique with physiotherapy manipulation
    → No chiropractic-specific evidence advantage

  ④ TEMPOROMANDIBULAR DISORDERS (🟡):
    → Pilot studies: cervical SMT may improve TMD symptoms
    → Trigeminocervical nucleus convergence provides

    → Insufficient evidence for recommendation
```

### §4.5 Non-Musculoskeletal Claims

```
  ⚠ THE MOST CONTROVERSIAL AREA of chiropractic.

  Traditional chiropractic (subluxation-based) claims SMT can
  treat asthma, colic, dysmenorrhea, hypertension, ADHD, ear
  infections, and other visceral/systemic conditions.

  EVIDENCE STATUS:

  🔴 ASTHMA:
    → Balon et al. 1998 (NEJM): RCT, n=91, pediatric asthma
    → Active SMT vs sham: NO significant difference
    → = One of the highest-quality negative trials in chiropractic

  🔴 INFANT COLIC:
    → Dobson et al. 2012: systematic review
    → Some positive studies but ALL had high risk of bias
    → No evidence of specific effect beyond natural resolution

  🔴 HYPERTENSION:
    → Bakris et al. 2007: atlas (C1) adjustment → BP reduction
    → Widely cited BUT: single study, methodological concerns,
      not replicated
    → Goertz et al. 2016: HVLA for hypertension — no effect

  🔴 DYSMENORRHEA:
    → Case reports only, no RCTs

  🟡 POSSIBLE AUTONOMIC EFFECTS:
    → Welch & Boone 2008: sympathoexcitation immediately
      post-SMT (skin conductance, blood pressure changes)
    → Kingston et al. 2014: HRV changes post-SMT
    → These autonomic changes are REAL and measurable
    → BUT: autonomic changes ≠ therapeutic visceral effects
    → Short-term autonomic perturbation does not equal
      disease treatment

  SUMMARY:
    → NO high-quality evidence supports SMT for any non-MSK
      condition (🟢 — this negative finding is well-established)
    → Autonomic responses to SMT ARE real but clinically
      non-significant for organ disease (🟡)
    → Non-MSK claims remain primarily based on subluxation
      theory, which lacks empirical support (§5.1)
```

### §4.6 Maintenance Care

```
  "Maintenance care" = regular SMT visits to PREVENT recurrence,
  even in the absence of current symptoms. Controversial practice.

  🟢 Eklund et al. 2018 (JAMA Network Open):
    → Nordic Maintenance Care Program
    → 328 patients with recurrent LBP
    → Maintenance care (scheduled visits every 1-3 months)
      vs symptom-guided treatment (visit only when symptoms return)
    → Maintenance group: 12.8 fewer days with bothersome LBP
      over 52 weeks
    → = Modest but statistically significant benefit
    → NNT ~7 (to prevent one episode of bothersome LBP)
    → FIRST RCT to show maintenance care benefit

  🟡 MECHANISM QUESTION:
    → Is this a specific SMT maintenance effect?
    → Or a general "check-up" effect (regular attention,
      reassurance, early intervention)?
    → Or a reconditioning effect (the appointment motivates
      continued exercise/care)?
    → Insufficient to distinguish these possibilities

  🔴 DEPENDENCE CONCERN:
    → Some patients receive weekly/biweekly adjustments
      for years without clear clinical indication
    → Financial incentive for continued treatment exists
    → "Once subluxated, always at risk" narrative (§5.1)
      encourages indefinite treatment
    → Evidence does NOT support such frequent long-term care
```

## §5. PROPOSED MECHANISMS

### §5.1 Traditional Theory: Vertebral Subluxation

```
┌─────────────────────────────────────────────────────────────────┐
│  SUBLUXATION THEORY — THE HISTORICAL FOUNDATION                 │
│                                                                 │
│  D.D. Palmer (1910, "The Chiropractor's Adjuster"):             │
│                                                                 │
│  CORE PREMISE:                                                  │
│  ① Vertebral SUBLUXATION = vertebra displaced from its normal   │
│     position (but not fully dislocated)                         │
│  ② This displacement impinges on spinal nerves                  │
│  ③ Impingement interferes with "innate intelligence" (vitalistic│
│     life force flowing through the nervous system)              │
│  ④ Interference causes disease (not just pain — ANY disease)    │
│  ⑤ Chiropractic ADJUSTMENT removes subluxation                  │
│  ⑥ Removing subluxation restores nerve flow → health restored   │
│                                                                 │
│  EVOLVED CONCEPT — Vertebral Subluxation Complex (VSC):         │
│  Modern chiropractic expanded the single-bone concept to a      │
│  multi-component model:                                         │
│    → Kinesiopathology (abnormal motion)                         │
│    → Neuropathophysiology (nerve dysfunction)                   │
│    → Myopathology (muscle dysfunction)                          │
│    → Histopathology (tissue inflammation)                       │
│    → Biochemical changes                                        │
│  = Attempt to bring subluxation into scientific language         │
│  = But still centered on vertebral POSITIONAL dysfunction       │
│    as the PRIMARY cause                                         │
└─────────────────────────────────────────────────────────────────┘

  EVIDENCE STATUS OF SUBLUXATION THEORY:

  🔴 SUBLUXATION AS CAUSE OF DISEASE:
    → No evidence that minor vertebral positional changes
      cause systemic disease
    → Spinal nerves exit through intervertebral foramina with
      significant space — minor positional changes do not
      cause nerve impingement (except in pathological conditions
      like disc herniation, stenosis)
    → "Innate intelligence" = vitalistic concept, not testable

  🔴 SUBLUXATION AS RELIABLY DETECTABLE ENTITY:
    → Palpation reliability: POOR (§3.3)
    → Imaging: no reliable radiographic criteria
    → Seffinger et al. 2004: inter-examiner reliability insufficient
    → No validated diagnostic standard exists

  PROFESSIONAL STATUS STATEMENTS:
    → WFC 2019 (World Federation of Chiropractic):
      Subluxation is a "historical concept" — there is
      "no evidence to support the claim that subluxation
      has clinical significance"
    → General Chiropractic Council (UK):
      Advertising claims that subluxation causes disease
      is not permitted
    → Many chiropractic colleges have removed or de-emphasized
      subluxation from curricula
    → BUT: some institutions and practitioners continue to
      use subluxation as central framework

  ⚠ PARALLEL IN TRACK B:
    → B06 Reflexology: Ingham foot map as "unvalidated but
      therapeutically functional scaffolding" (B06 §5.1)
    → B01 Acupuncture: meridian theory as "coherent descriptive
      framework with limited empirical basis for proposed
      mechanism" (qi flow)
    → Subluxation theory follows same pattern: historical
      framework that ORGANIZED the practice and provided
      clinical scaffolding, even though the proposed mechanism
      (vertebral displacement → nerve interference → disease)
      is not supported by evidence
    → KEY DIFFERENCE: subluxation theory makes STRONGER causal
      claims (vertebral cause of ALL disease) than meridian theory
      or Ingham maps → stronger rejection from evidence-based
      community
```

### §5.2 Modern Evidence-Based Model: Neurophysiological Effects of SMT

```
┌─────────────────────────────────────────────────────────────────┐
│  THE SHIFT: FROM "BONE OUT OF PLACE" TO "NEURAL INPUT"          │
│                                                                 │
│  Modern SMT research has moved FROM:                            │
│    "Adjusting a misaligned vertebra back into place"            │
│  TO:                                                            │
│    "Generating a specific pattern of afferent neural input      │
│     that modulates spinal cord and supraspinal processing"      │
│                                                                 │
│  🟢 Pickar 2002 (Spine Journal) — foundational review:          │
│  "Neurophysiological effects of spinal manipulation"            │
│  → Established that SMT's primary effects are NEURAL,           │
│    not biomechanical correction of position                     │
│  → The JOINT is the INPUT SITE, not the thing being "fixed"     │
│                                                                 │
│  5-LEVEL MECHANISM MODEL (framework synthesis 🟡):              │
│                                                                 │
│  L1 BIOMECHANICAL      — joint gapping, cavitation, adhesion    │
│  L2 PROPRIOCEPTIVE     — spindle reset, joint receptor barrage  │
│  L3 PAIN MODULATION    — gate control, descending inhibition    │
│  L4 AUTONOMIC          — somatoautonomic reflex, HRV changes   │
│  L5 CENTRAL            — sensorimotor processing, cortical      │
│                                                                 │
│  L1 = local, immediate. L5 = central, potentially lasting.      │
│  Each level has different evidence quality and time course.      │
└─────────────────────────────────────────────────────────────────┘
```

### §5.2.1 L1 — Biomechanical Effects (LOCAL)

```
  THE IMMEDIATE MECHANICAL EVENTS:

  ① JOINT GAPPING (🟢):
    → Cramer et al. 2011: HVLA produces measurable separation
      of facet joint surfaces (cadaver study)
    → ~1-3 mm separation during thrust
    → Breaks adhesions? Releases entrapped meniscoid folds?
      🟡 Plausible but not directly demonstrated in vivo

  ② CAVITATION (🟢 occurs, 🟡 significance):
    → Gas cavity formation (Kawchuk 2015)
    → Produces the audible "crack"
    → Does cavitation itself contribute to therapeutic effect?
    → Flynn et al. 2003: similar outcomes with and without
      audible cavitation → suggests cavitation is epiphenomenon
    → But: joint gapping (which produces cavitation) may
      still be mechanistically important even if the gas
      bubble is not

  ③ MENISCOID ENTRAPMENT RELEASE (🟡):
    → Synovial folds (meniscoids) can become entrapped between
      facet joint surfaces during aberrant motion
    → HVLA may release entrapped tissue → immediate pain relief
    → Bogduk & Jull 1985: proposed mechanism
    → Consistent with patient reports of "something moving"
    → But: direct visualization not achieved in vivo

  ④ MUSCLE RELAXATION (🟢):
    → Immediate reduction in paraspinal muscle activity
      (EMG studies)
    → Mechanism: primarily NEURAL (L2), not mechanical
    → Post-thrust muscle tone change = reflex response
    → DeVocht et al. 2005: EMG changes post-SMT

  TIME COURSE: milliseconds to seconds (immediate)
  SIGNIFICANCE: 🟡 MODERATE — mechanical events are REAL but
  may be less important than the NEURAL consequences they trigger
```

### §5.2.2 L2 — Proprioceptive Reset (SPINAL) ⭐

```
  THE CORE NEUROPHYSIOLOGICAL MECHANISM:

  ⭐ THIS IS LIKELY THE PRIMARY THERAPEUTIC MECHANISM OF SMT ⭐

  🟢 Pickar & Wheeler 2001 (animal model):
    → Cat paraspinal muscle spindle recordings during SMT-like thrust
    → HVLA produces a HIGH-FREQUENCY BURST of muscle spindle
      (Ia) afferent firing during the thrust
    → Followed by a period of REDUCED firing rate post-thrust
    → = The thrust "resets" the spindle's baseline firing rate

  🟢 Reed et al. 2014 (cat model):
    → Confirmed spindle firing pattern during SMT
    → Thrust VELOCITY (not force) determined the magnitude
      of spindle response
    → Faster thrust → greater Ia burst → greater post-thrust
      reduction in firing
    → = Direct evidence that VELOCITY matters mechanistically

  PROPOSED CASCADE (🟡 synthesis):
    HVLA thrust
      → Rapid stretch of paraspinal muscles
      → Muscle spindle Ia afferent HIGH-FREQUENCY BURST
      → PLUS joint receptor (Types I-III) activation from
        capsule deformation
      → COMBINED afferent barrage → dorsal horn neurons
      → Two consequences:
        (a) Post-activation depression of Ia firing →
            reduced gamma loop → reduced muscle tone
            (A08 §3.4 gamma loop mechanism)
        (b) Proprioceptive "recalibration" — CNS updates its
            model of joint position/status

  CONNECTION TO A08:
    → Muscle spindle Ia → monosynaptic stretch reflex (A08 §3.1)
    → Golgi tendon organ Ib → autogenic inhibition (A08 §3.2)
    → Joint receptors Types I-III → proprioceptive processing
    → ALL THREE proprioceptor systems activated simultaneously
      by a single HVLA thrust = "proprioceptive barrage"

  THERAPEUTIC IMPLICATION:
    → If the patient has elevated paraspinal muscle tone
      (protective guarding, pain → spasm cycle), the
      proprioceptive reset MAY break the cycle:
      Pain → muscle guarding → restricted motion →
      more pain → more guarding (vicious cycle)
      HVLA → proprioceptive reset → reduced guarding →
      restored motion → less pain
    → 🟡 This cycle-breaking model is plausible but the
      DURATION of reset (minutes? hours? days?) is unclear

  ALPHA-GAMMA COACTIVATION (A08 §2.2):
    → During normal movement: α + γ motor neurons co-fire
    → Sympathetic drive can increase γ tone → elevated
      muscle tone → pain/stiffness
    → HVLA may transiently interrupt α-γ coupling →
      reset to lower baseline
    → 🟡 Proposed mechanism, consistent with animal data
      but not directly measured in humans post-SMT
```

### §5.2.3 L3 — Pain Modulation (SPINAL + SUPRASPINAL)

```
  THREE PAIN MODULATION PATHWAYS:

  ① GATE CONTROL (🟢 — A01 §3.3):
    → HVLA activates Aβ mechanoreceptors in joint capsule,
      ligaments, and periarticular tissue
    → Aβ input → inhibitory interneurons in dorsal horn →
      "closes the gate" on nociceptive C/Aδ input
    → = Immediate pain reduction during and after thrust
    → Duration: minutes to hours
    → SHARED with B03 (massage), B02 (acupressure) — not
      unique to B10

  ② DESCENDING INHIBITION (🟢):
    → 🟢 Plaza-Manzano et al. 2014:
      • SMT → measurable increase in plasma β-endorphin
      • Also: cortisol changes, OPL (opioid peptide level) changes
      • Suggests activation of PAG-RVM descending pathway
        (A01 §3.2)
    → Mechanism: afferent barrage from HVLA → spinal cord →
      ascending to brainstem → PAG activation → descending
      inhibition → dorsal horn analgesia
    → Duration: hours (endorphin half-life)

  ③ DIFFUSE NOXIOUS INHIBITORY CONTROLS (DNIC / CPM) (🟡):
    → HVLA thrust = brief intense mechanical stimulus
    → May activate DNIC (pain-inhibits-pain at remote sites)
    → 🟡 Less certain than for B11 Dry Needling where DNIC
      role is better established (B11 §5.2.3 "Lewit effect")
    → If present, would explain why SMT can reduce pain at
      sites remote from the manipulated segment

  OVERALL PAIN MODULATION PROFILE:
    → Gate control = PRIMARY (immediate, well-established)
    → Descending inhibition = SECONDARY (hours, evidence growing)
    → DNIC = POSSIBLE (uncertain contribution)
    → Multiple overlapping pathways → robust pain reduction
      but difficult to attribute to any single mechanism
```

### §5.2.4 L4 — Autonomic Modulation (SEGMENTAL + SYSTEMIC)

```
  THE SOMATOAUTONOMIC REFLEX PATHWAY:

  🟢 Budgell 2000 — "Reflex effects of subluxation: the
  autonomic nervous system" (foundational review):
    → Somatic afferent stimulation → reflex changes in
      autonomic efferent output → organ function change
    → Sato's work (A07 §3): established somatoautonomic
      reflexes in animal models
    → Spinal manipulation = somatic stimulation at
      PARAVERTEBRAL location → direct proximity to
      sympathetic chain

  MEASURED AUTONOMIC RESPONSES TO SMT (🟢):
    → Welch & Boone 2008:
      • Thoracic SMT → immediate sympathoexcitation
        (increased skin conductance, blood pressure)
      • Cervical SMT → different autonomic pattern
      • Effects are REGION-SPECIFIC → consistent with
        segmental somatoautonomic reflex
    → Kingston et al. 2014:
      • HRV changes post-SMT
      • Shift toward parasympathetic after initial
        sympathetic response
      • = "Sympathoexcitation → parasympathetic rebound" pattern
    → Sampath et al. 2017 (systematic review):
      • Skin sympathetic nerve activity changes post-SMT
      • BUT: inconsistent direction across studies
      • Suggests autonomic response is REAL but not predictable

  CONNECTION TO A02:
    → A02 §3.5: somatoautonomic reflexes documented for
      somatic stimulation → autonomic output
    → A02 §1.2: sympathetic chain = 22 pairs of paravertebral
      ganglia running parallel to vertebral column
    → Spinal SMT = mechanical stimulation DIRECTLY ADJACENT
      to sympathetic chain → anatomically privileged position
      for somatoautonomic reflex activation
    → 🟡 This proximity is UNIQUE to spinal SMT — no other
      Track B therapy applies force this close to the
      sympathetic trunk

  ⚠ CRITICAL DISTINCTION:
    → Autonomic RESPONSES to SMT are measurable (🟢)
    → Autonomic responses producing THERAPEUTIC VISCERAL
      EFFECTS are NOT demonstrated (🔴)
    → Response ≠ Treatment
    → The autonomic perturbation is transient, small, and
      variable — insufficient evidence that it produces
      clinically meaningful organ effects
    → This is WHY non-MSK claims (§4.5) remain unsupported

  CONNECTION TO A07:
    → A07 segmental model: T1-T4 → heart/lungs,
      T5-T9 → GI, T10-L2 → kidneys/reproductive
    → Somatoautonomic reflexes are SEGMENTALLY ORGANIZED
      (Sato et al. 1997)
    → IF SMT at specific thoracic levels could reliably
      modulate specific organ function, the anatomical
      pathway exists (A07 Lamina V convergence)
    → BUT: practical segmental targeting is unreliable (§3.3)
      AND therapeutic visceral effects not demonstrated (§4.5)
    → = Beautiful anatomy, insufficient clinical evidence
```

### §5.2.5 L5 — Central Integration (SUPRASPINAL)

```
  THE MOST RECENT AND SPECULATIVE MECHANISM LEVEL:

  🟢 Haavik & Murphy 2012 (J Electromyogr Kinesiol):
```

```
    → HVLA: burst → Type II receptor → velocity/acceleration
    → Different receptor activation = different afferent input
    → But: clinical outcomes often converge

  🟡 POSSIBLE EXPLANATIONS FOR SIMILAR OUTCOMES:
    ① Different pathways → same endpoint (convergent mechanisms)
    ② Clinical outcome measures too crude to detect differences
    ③ Non-specific effects (context, expectation) dominate both
    ④ The difference is in SPEED of onset, not magnitude
       (HVLA = faster improvement, mobilization = same but slower)

  THIS IS THE MOST IMPORTANT OPEN QUESTION for B10 mechanism
  research. If HVLA and mobilization produce identical outcomes,
  the "velocity-dependent receptor profile" hypothesis is
  clinically irrelevant (even if neurophysiologically real).
```

### §8.2 Contraindications

```
  ABSOLUTE CONTRAINDICATIONS (do NOT manipulate):
    → Fracture at target segment
    → Bone tumor / metastasis at target segment
    → Spinal infection (osteomyelitis, discitis)
    → Vertebrobasilar insufficiency (VBI) signs/symptoms
    → Cauda equina syndrome
    → Severe osteoporosis (high fracture risk)
    → Spinal cord compression
    → Unstable ligamentous injury (e.g., post-trauma)
    → Anticoagulation therapy with INR >3 (bleeding risk)
    → Active inflammatory arthropathy at target segment
      (rheumatoid arthritis with cervical involvement)

  RELATIVE CONTRAINDICATIONS (proceed with caution):
    → Moderate osteoporosis
    → Disc herniation with radiculopathy

    → Elderly patients (reduced bone density, stiff joints)
    → Connective tissue disorders (Ehlers-Danlos, Marfan)
    → Anticoagulation therapy (moderate INR)
    → Post-surgical spine (adjacent to fusion)
    → Pediatric patients (developing skeleton)

  RED FLAGS requiring medical referral before SMT:
    → Progressive neurological deficit
    → Unexplained weight loss
    → History of cancer
    → Fever with back pain
    → Bowel/bladder dysfunction
    → Bilateral leg symptoms
    → Saddle anesthesia
```

## §10. OPEN QUESTIONS

### Q1: HVLA vs Mobilization — Does Velocity Matter? (CRITICAL)

  If Grade I-IV mobilization produces similar clinical outcomes
  to Grade V HVLA manipulation, is the HIGH VELOCITY component
  therapeutically necessary? The velocity-dependent receptor
  profile (§5.3) predicts different neural activation, but
  clinical outcomes converge. Either: (a) different pathways →
  same endpoint, (b) outcome measures too crude, (c) non-specific
  effects dominate both, or (d) velocity affects speed of
  improvement, not magnitude. This is the MOST IMPORTANT question
  for B10 mechanism research.

### Q2: Cavitation — Necessary for Therapeutic Effect?

  Flynn et al. 2003 data suggests similar outcomes with and
  without audible cavitation. If cavitation is not necessary,
  this shifts emphasis entirely to the NEURAL input generated
  by joint gapping and tissue deformation, regardless of gas
  cavity formation. Implications for instrument-assisted
  techniques (Activator) which rarely produce cavitation.

### Q3: Segmental Targeting — Can Practitioners Reliably Target Specific Segments?

  Palpation reliability is POOR (Seffinger 2004, Haneline 2009).
  Cavitation often occurs at adjacent segment (Beffa & Mathews
  2004). If precise targeting is unreliable, does SMT work
  because of REGIONAL (multi-segment) afferent input rather
  than SPECIFIC segmental correction? This would be consistent
  with the Joint-as-Sensory-Organ Model (§5.3) — total
  proprioceptive input matters more than precise segmental
  identity.

### Q4: Dose-Response — Optimal Frequency and Duration

  How many sessions, how often, for how long? Current practice
  varies enormously (1x/week to 3x/week, 4 weeks to indefinite).
  Eklund 2018 suggests maintenance at 1-3 months interval.
  But: the MINIMUM effective dose is unknown. Under-treatment
  and over-treatment boundaries not established.

### Q5: Non-MSK Somatovisceral Effects — Definitive Testing

  The anatomical pathway for somatovisceral effects is well-
  established (A02 somatoautonomic reflex, A07 segmental
  convergence). Autonomic RESPONSES to SMT are measured (Welch
  2008, Kingston 2014). But: no high-quality evidence for
  therapeutic VISCERAL effects. A well-designed, adequately
  powered RCT targeting a specific somatovisceral claim
  (e.g., T5-T9 SMT → measurable GI function change) would
  be definitive — but remains unperformed.

### Q6: Subluxation — Any Measurable Correlate?

  If "subluxation" is reconceptualized as FUNCTIONAL joint
  dysfunction (not positional misalignment), can it be
  reliably measured? If no measurable correlate exists, the
  concept lacks clinical utility regardless of whether a
  physical phenomenon underlies it. Imaging (including
  advanced MRI, CT motion analysis) has not identified a
  reliable biomarker.

### Q7: Sensorimotor Processing Changes — Clinical Significance

  Haavik's work shows SEP changes post-SMT (N30 component).
  But: (a) SEP changes occur after ANY peripheral stimulation,
  (b) clinical significance of these changes is unknown,
  (c) whether changes persist beyond 20 minutes unclear.
  Need studies linking SEP changes to clinical outcomes.

### Q8: Chiropractic vs Sham in Blinding-Optimized Trials

  SMT clinical evidence is limited by blinding challenges.
  Emerging sham protocols (detuned Activator, computer-guided
  positioning) may enable better-blinded trials. If SMT ≈ sham
  in well-blinded trials (as seen in Chaibi 2017 for migraine),
  the specific mechanism contribution may be smaller than
  currently assumed.
