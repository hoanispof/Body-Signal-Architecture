# B14 — Craniosacral Therapy

> **Position:** Track B file #16 — the LAST Track B therapy method.
> TIER 3 (standard 1 session). Position 2.16 in plan.md.
>
> **Central Question:**
> CST claims to detect and correct restrictions in the "craniosacral system"
> using ultra-light touch (~5g). Its foundational claims (cranial bone mobility,
> craniosacral rhythm) are UNSUPPORTED by evidence. Yet some clinical studies
> report positive outcomes. HOW — and through WHAT mechanisms — might this
> therapy produce effects, given that its stated mechanism is implausible?
>
> **Core Insight — Unfounded Premise, Non-Specific Effect Model:**
> 🔴 CST is the clearest case in Track B where the STATED MECHANISM is
> unsupported, yet CLINICAL EFFECTS may partially exist. If real, these
> effects arise from NON-SPECIFIC mechanisms already well-characterized
> by other Track B entries: gentle touch (CT afferents, A01), relaxation
> response (parasympathetic shift, A02), therapeutic context (Evaluative
> Gates, Human-Predictive-Drive), and sustained practitioner attention. The specific
> "craniosacral" claims — bone mobility, CSR palpation, dural correction —
> add NO measurable mechanistic contribution beyond these non-specific
> pathways. This makes B14 the most important THERAPEUTIC SCAFFOLDING
> case study in the entire project.
>
> **Key comparison:** B06 Reflexology (zone map unsupported, non-specific
> effects real), B12 EFT (somatic contribution uncertain).
> B14 goes further than all three: its foundational ANATOMICAL claim
> (cranial bone mobility) is contradicted by established anatomy.

## §1 — DEFINITION & ORIGIN

### §1.1 — What Is Craniosacral Therapy?

```
🟢 PHYSICAL DESCRIPTION:

  Craniosacral therapy (CST) is a manual therapy involving very light
  touch (claimed ~5 grams of force, approximately the weight of a
  nickel) applied primarily to the cranium (skull), sacrum, and spine.

  DEFINING FEATURES:
  ┌─────────────────────────────────────────────────────────────────────┐
  │  1. ULTRA-LIGHT TOUCH                                               │
  │     → Claimed 5g (0.05 N) — LIGHTEST touch of any Track B therapy  │
  │     → Much lighter than B03 massage (25-450 N), B02 acupressure    │
  │       (30-80 N), even B04 MFR-Indirect (which is already light)    │
  │     → At 5g, force is below threshold for most mechanoreceptors    │
  │       EXCEPT Merkel cells and CT afferents                          │
  │                                                                     │
  │  2. CRANIAL AND SACRAL FOCUS                                        │
  │     → Primary contact: cranial vault (frontal, parietal, temporal,  │
  │       occipital bones), sacrum, coccyx                              │
  │     → Also: spine, diaphragm areas, feet                           │
  │     → Rationale: cranium-sacrum connected via dural tube            │
  │       (spinal meninges)                                             │
  │                                                                     │
  │  3. CLAIMED RHYTHM DETECTION                                        │
  │     → Practitioners claim to detect "craniosacral rhythm" (CSR)     │
  │       through palpation — a subtle rhythmic motion at 6-12          │
  │       cycles/min, distinct from cardiac and respiratory rhythms     │
  │     → CSR is the DIAGNOSTIC AND TREATMENT GUIDE                     │
  │     → ⚠ CSR inter-rater reliability = NEAR ZERO (see §5.1)        │
  │                                                                     │
  │  4. DIAGNOSTIC-THERAPEUTIC INTEGRATION                               │
  │     → Assessment and treatment are simultaneous                     │
  │     → "Listening" with hands → detecting "restrictions" →           │
  │       applying gentle holds until restriction "releases"            │
  │     → Parallels: B13 Shiatsu Hara diagnosis, B06 Ingham map        │
  │       — all unvalidated diagnostic systems                          │
  │                                                                     │
  │  5. LONG SESSION DURATION                                           │
  │     → Typical: 45-90 minutes (longer than most Track B therapies)   │
  │     → Practitioner remains still for extended periods (2-5 min      │
  │       per hold), "waiting for tissue release"                       │
  │     → Patient fully clothed, supine                                 │
  └─────────────────────────────────────────────────────────────────────┘

  🟢 Upledger & Vredevoogd 1983 (CranioSacral Therapy, original textbook)
  🟢 Green et al. 1999 (critique of CST theoretical basis)
```

### §1.2 — The "Craniosacral System" — Claimed Anatomy

```
  THE CLAIMED "CRANIOSACRAL SYSTEM":
  ┌─────────────────────────────────────────────────────────────────────┐
  │                                                                     │
  │  CST claims to work on a distinct physiological system:             │
  │                                                                     │
  │  ① CRANIAL BONES                                                    │
  │     → Claim: cranial sutures remain mobile throughout life,         │
  │       allowing rhythmic micro-motion of cranial bones               │
  │     → Actual anatomy: cranial sutures progressively ossify          │
  │       (fuse) from age ~25-30, with significant individual           │
  │       variation. Some sutures (sagittal) may retain minimal         │
  │       flexibility, but any motion is in the 1-25 MICROMETER         │
  │       range (Downey 2006) — far below palpation threshold           │
  │                                                                     │
  │  ② MENINGEAL MEMBRANES (the "reciprocal tension membrane")          │
  │     → 3 layers: dura mater (outermost), arachnoid, pia mater       │
  │     → Dura mater: tough connective tissue (A03 classification:      │
  │       visceral fascia), lines inner skull + forms spinal dural      │
  │       tube from foramen magnum to S2                                │
  │     → Claim: dural tube transmits motion from cranium to sacrum     │
  │       and vice versa, forming a continuous "hydraulic system"       │
  │     → Actual anatomy: dural tube IS continuous from cranium         │
  │       to sacrum — this is anatomically CORRECT. However,            │
  │       it is ANCHORED at multiple points (foramen magnum, C2-C3,    │
  │       S2) and the force transmission through this tube at 5g       │
  │       of external cranial pressure is UNMEASURABLE                  │
  │                                                                     │
  │  ③ CEREBROSPINAL FLUID (CSF)                                        │
  │     → Claim: CSF has an inherent "tide" or "fluctuation"           │
  │       rhythm (6-12 cycles/min) that drives the craniosacral        │
  │       rhythm and can be influenced by external manipulation         │
  │     → Actual physiology: CSF is produced continuously (~500         │
  │       ml/day) by choroid plexus, absorbed by arachnoid              │
  │       granulations. CSF pressure DOES fluctuate, but these          │
  │       fluctuations correlate with cardiac and respiratory           │
  │       cycles, NOT a separate rhythm                                 │
  │     → Traube-Hering-Mayer oscillations (6-12/min) exist as          │
  │       blood pressure waves — MAY be what practitioners detect,     │
  │       but they originate from VASCULAR not craniosacral system      │
  │                                                                     │
  │  ④ SACRUM                                                           │
  │     → Claim: sacrum moves in synchrony with cranium via dural       │
  │       tube, producing palpable sacral "rocking"                     │
  │     → Actual anatomy: sacrum articulates with ilia at               │
  │       sacroiliac joints (SIJ); SIJ has ~2-4° of motion but         │
  │       this is NOT synchronized with cranial rhythms                 │
  │                                                                     │
  └─────────────────────────────────────────────────────────────────────┘

  ⚠ CRITICAL ASSESSMENT:
    → Component ② (dural tube continuity) is anatomically CORRECT
    → Components ①③④ as described by CST are UNSUPPORTED or
      CONTRADICTED by established anatomy and physiology
    → The system AS A WHOLE (cranial bones moving rhythmically,
      driven by CSF fluctuation, transmitted to sacrum via dura)
      has NO measurable basis

  🟢 Downey et al. 2006 (cranial compliance, finite element modeling)
  🟢 Standring 2020 (Gray's Anatomy — suture ossification)
  🟢 Green et al. 1999 (CST theoretical critique)
  🟢 Hartman & Norton 2002 (interexaminer reliability)
```

### §1.5 — Terminological Note

  "CO"  = Cranial Osteopathy (Sutherland tradition)
  "CSR" = Craniosacral Rhythm — the claimed palpable rhythm

  When referring to both traditions collectively: "craniosacral
  approaches" or "craniosacral therapy (broad sense)."

  🟡 FORCE PARADOX:
  At the claimed 5g, force is BELOW the activation threshold for:
    → Pacinian corpuscles (require >0.5 N for deep pressure)
    → Ruffini endings (require sustained stretch, not static hold)
    → Aδ mechanonociceptors (require HIGH threshold)
    → Most muscle/fascial mechanotransduction (A03: requires
      measurable tissue deformation)

  At 5g, force is POTENTIALLY SUFFICIENT for:
    → Merkel cells (SA I) — very sensitive to sustained light touch
    → CT afferents — activated by gentle contact at 1-10 cm/s on
      hairy skin. BUT CT afferents respond to MOVEMENT (stroking),
      not static hold. Scalp contact during hand repositioning
      MAY briefly activate CTs.
    → Thermal transfer — practitioner hand warmth (~32-34°C) →
      patient skin → thermoreceptors (warm receptors, TRPV3/4)
    → Piezo2 channels — ultra-sensitive to gentle touch in Merkel
      cells (Woo et al. 2014, Nature)

  🟢 Woo et al. 2014 (Piezo2 in gentle touch, Nature)
  🟡 Force analysis: synthesis from A01 receptor thresholds

### §5.3 — The Craniosacral Rhythm Reliability Problem

```
🟢 CSR INTER-RATER RELIABILITY — THE CRITICAL TEST:

  IF craniosacral rhythm is a REAL physiological phenomenon (like
  pulse rate or respiratory rate), then TWO practitioners examining
  the SAME patient at the SAME time should detect the SAME rate.

  STUDIES TESTING THIS:

  ┌──────────────────────────────────────────────────────────────────────┐
  │  Moran & Gibbons 2001 (J Manipulative Physiol Ther):                │
  │  → 2 experienced CST practitioners simultaneously palpated CSR     │
  │    at occiput on 11 subjects                                        │
  │  → Correlation between examiners: r = 0.004                         │
  │  → ⭐ r = 0.004 = EFFECTIVELY RANDOM. No agreement whatsoever.      │
  │  → The TWO practitioners were touching the SAME skull at the        │
  │    SAME time and reported DIFFERENT rates.                           │
  ├──────────────────────────────────────────────────────────────────────┤
  │  Hartman & Norton 2002 (J Man Manip Ther):                          │
  │  → 3 therapists, 11 healthy subjects                                │
  │  → Interexaminer reliability: "very low"                            │
  │  → ICC range: 0.02-0.26                                             │
  │  → "Clinically unacceptable reliability"                            │
  ├──────────────────────────────────────────────────────────────────────┤
  │  Hanten et al. 1998 (Phys Ther):                                    │
  │  → 2 examiners, 12 subjects                                        │
  │  → Poor inter-rater reliability for CSR detection                   │
  ├──────────────────────────────────────────────────────────────────────┤
  │  Rogers et al. 1998 (JAOA):                                         │
  │  → 3 osteopaths, 12 subjects, simultaneous palpation               │
  │  → "No statistically significant interexaminer reliability"         │
  ├──────────────────────────────────────────────────────────────────────┤
  │  Wirth-Pattullo & Hayes 1994 (Phys Ther):                          │
  │  → Earliest reliability study                                       │
  │  → "No agreement between examiners on CSR rate"                    │
  └──────────────────────────────────────────────────────────────────────┘

  PATTERN: EVERY reliability study → NEAR-ZERO agreement.

  ⚠ WHAT THIS MEANS:
    → CSR as described by CST does NOT exist as a reliably detectable
      physiological phenomenon
    → Practitioners are likely detecting:
      (a) their OWN arterial pulse (Handoll 2000 hypothesis)
      (b) respiratory motion transmitted through tissue
      (c) expectation-driven perception (perceptual confirmation bias)
      (d) very slow Traube-Hering-Mayer blood pressure waves
          (~0.1 Hz = ~6/min, which matches CSR claimed rate)
    → If (d): practitioners may be detecting a REAL vascular phenomenon
      but MISATTRIBUTING it to craniosacral mechanism

  🟡 FRAMEWORK PARALLEL:
    This parallels B06 Ingham foot map — in both cases, the
    DIAGNOSTIC FRAMEWORK is unsupported, but the THERAPEUTIC CONTEXT
    (gentle touch + focused attention + calm environment +
    practitioner confidence) may still produce effects. B14's CSR
    unreliability is WORSE than B06 because reflexology at least has
    a FIXED map — CSR should be a measurable physiological signal
    and it isn't.

  🟢 Moran & Gibbons 2001 (r=0.004, J Manipulative Physiol Ther)

  🟢 Hanten et al. 1998 (poor reliability)
  🟢 Rogers et al. 1998 (no significant reliability)
  🟢 Wirth-Pattullo & Hayes 1994 (no agreement)
  🟡 Handoll 2000 (practitioner pulse hypothesis)

### §9.2 — Structural Challenges to Research

```
🟡 WHY CST EVIDENCE IS STRUCTURALLY DIFFICULT:

  ① SHAM CONTROL PROBLEM (shared with all manual therapies):
     → Practitioner cannot be blinded to intervention
     → Sham CST = light touch without CST technique — but HOW
       different is this from actual CST? If CST's mechanism IS
       non-specific touch, then sham = active treatment
     → "The sham IS the treatment" problem (more severe than B06,
       B12, B13 because CST's force is so light)

  ② STANDARDIZATION PROBLEM:
     → CST is INHERENTLY individualized — each treatment
       follows what practitioner "detects" via CSR
     → If CSR detection is unreliable → each practitioner does
       something DIFFERENT even with the same patient
     → 🔴 This means: CST RCTs may not be testing the SAME
       intervention across patients or studies

  ③ DOSE PROBLEM:
     → At ~5g, the "dose" is essentially unmeasurable
     → No way to quantify how much intervention was delivered
     → Unlike B01 (needle depth, duration) or B02 (pressure,
       duration, location), CST has NO quantifiable parameters

  ④ RESEARCHER AFFILIATION:
     → Substantial proportion of CST studies come from
       practitioners with training in CST
     → Upledger Institute-affiliated research
     → ⚠ Not necessarily bias, but structural COI concern
       (parallel to B12 EFT Church problem, though less extreme)

  ⑤ MECHANISM PLAUSIBILITY PROBLEM:
     → When foundational claims are contradicted by anatomy:
     → Positive results require explaining HOW effects occur
       through mechanisms OTHER than those claimed
     → This is an UNUSUAL position for a therapy — most Track B
       therapies have PLAUSIBLE mechanisms even if unproven
```

### §9.3 — Evidence Synthesis

```
🟡 WHAT IS SUPPORTED, PLAUSIBLE, AND NOT SUPPORTED:

  SUPPORTED (🟢):
    → CST is VERY SAFE (minimal force → minimal risk)
    → Patients report relaxation and comfort during treatment
    → Some small, low-quality RCTs show positive results
      for chronic neck pain (vs sham, with caveats)

  PLAUSIBLE (🟡):
    → Non-specific effects (relaxation, therapeutic context)
      account for observed clinical improvements
    → Suboccipital release via myodural bridge (Hack 1995)
      may contribute to neck pain/headache relief
    → CT afferent activation on hairy scalp during hand
      repositioning provides brief pleasant input
    → CST's therapeutic context may be UNUSUALLY strong
      due to long sessions, "listening" posture, and
      practitioner confidence

  NOT SUPPORTED (🔴):
    → Cranial bone mobility as therapeutic target in adults
    → Craniosacral rhythm as detectable phenomenon
    → CSF fluctuation as an independent rhythm
    → Dural "restrictions" correctable by 5g external force
    → SomatoEmotional Release (stored trauma in fascia)
    → "Energy cyst" concept
