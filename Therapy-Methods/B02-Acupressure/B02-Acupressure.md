# B02 — Acupressure

> **Scope:** The application of non-invasive manual pressure (finger, thumb, palm,
> elbow, or device) at specific acupoints to produce therapeutic effects. Includes
> body acupressure, auricular acupressure (ear seeds/pellets), and related traditions
> (Korean Hand Therapy, Jin Shin Jyutsu, Marma therapy).
>
> **Central question:** When you apply PRESSURE instead of a NEEDLE at the same
> acupoint, which mechanisms are activated, which are lost, and which are unique
> to pressure? This file answers that question.
>
> **Evidence scale:** ~642 RCTs (386 since 2018), ~217 meta-analyses, no dedicated
> Cochrane review. Best-evidenced single point: P6 (PC6, Neiguan) for nausea/vomiting
> — nested in Cochrane CD003281, 77 trials, ~9,800 participants.
>
> **Relationship to B01 (Acupuncture):** SAME acupoint framework, DIFFERENT stimulus.
> B02 does NOT repeat B01's acupoint system — cross-references it. B02 focuses on
> what changes when pressure replaces needle.
>
> **Relationship to B03 (Massage):** B02 = sustained pressure at SPECIFIC POINTS.
> B03 = varied techniques across broad AREAS. Overlap exists (Tui Na, Thai compression).
>
> **Framing:** Traditional theoretical constructs (Qi, meridians) are the same as B01.
> Recorded AS DATA in B01 §1.3 — not repeated here. See B01 §1.3 for full TCM
> framework.
>
> **Track A cross-reference:** 8 of 9 Track A systems are engaged by acupressure
> (A04 Vascular-Lymphatic engagement is minimal — no tissue penetration).

## §1 — DEFINITION & ORIGIN

### §1.1 — What Acupressure Is

```
🟢 PHYSICAL DESCRIPTION:

  Acupressure is a therapeutic intervention involving the application of
  sustained manual pressure — using fingers, thumbs, palms, elbows, or
  purpose-built devices — at specific anatomically-defined acupoints
  (the SAME points used in acupuncture, B01 §3.1).

  THE CORE DISTINCTION FROM ACUPUNCTURE:
    Same points → different stimulus → partially different mechanism profile.

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ACUPUNCTURE (B01)              │  ACUPRESSURE (B02)                    │
  │─────────────────────────────────┼───────────────────────────────────────│
  │  Invasive: needle penetrates    │  Non-invasive: pressure on surface   │
  │  skin and underlying tissue     │  (no tissue penetration)             │

  │  manipulation (rotation,        │  (static hold, circular motion,      │

  │                                 │                                       │

### §1.2 — Historical Development

```
🟢 ACUPRESSURE HISTORY — SHARED ROOT WITH ACUPUNCTURE:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  PRE-NEEDLE ORIGINS — ACUPRESSURE LIKELY PRECEDED ACUPUNCTURE          │
  │                                                                         │
  │  The simplest form of point-based therapy = pressing a painful spot    │
  │  with a finger. This is UNIVERSAL across cultures and requires no      │
  │  tools. Before stone needles (Bian Shi, ~5000 BCE), acupressure-like  │
  │  manipulation was almost certainly the original form of point therapy. │
  │                                                                         │
  │  Evidence: Neijing (2nd c. BCE) describes BOTH needling AND manual     │
  │  techniques at the same points. Lingshu discusses pressing (按 An),    │
  │  kneading (揉 Rou), and rubbing (摩 Mo) at acupoints alongside        │
  │  needle insertion — suggesting coexistence from earliest codification. │
  │                                                                         │
  │  The term "Tui Na" (推拿, push-grasp) encompasses both acupressure    │
  │  and massage within TCM. First formal manual therapy text: Huangdi     │
  │  Qibo An Mo Shi Juan (Yellow Emperor's Ten Volumes of Massage),       │
  │  referenced but lost — existence known from later bibliographies.      │
  │                                                                         │
  │  IMPORTANT: Acupuncture became the DOMINANT modality in Chinese        │
  │  medical literature → acupressure was practiced but LESS DOCUMENTED   │
  │  in classical texts. Most surviving classical theory describes         │
  │  needling, not pressing.                                               │
  │                                                                         │
  │  TIMELINE — KEY EVENTS FOR ACUPRESSURE SPECIFICALLY:                   │
  │                                                                         │
  │  Pre-5000 BCE  Finger pressure at painful points (universal, pre-tool) │
  │                                                                         │
  │  2nd c. BCE    Neijing: An Mo (按摩) techniques codified alongside     │
  │                acupuncture. Same point system, different stimulus.      │
  │                                                                         │
  │  610 CE        Zhubing Yuanhou Lun (诸病源候论, Chao Yuanfang):        │
  │                prescribes An Mo self-treatment for 110+ conditions.     │
  │                One of the earliest systematic self-acupressure guides.  │
  │                                                                         │
  │  ~752 CE       Ishinpō (医心方, Tamba Yasuyori): Japanese compilation  │
  │                of Chinese medical texts. Includes An Mo techniques     │
  │                that influenced Japanese Shiatsu development.            │
  │                                                                         │
  │  18th-19th c.  European travelers document Chinese "point pressing."   │
  │                European adaptations develop alongside massage therapy.  │
  │                                                                         │
  │  1940s-1950s   Tokujiro Namikoshi → Shiatsu system (Japan). Based on  │
  │                Western anatomy + Japanese adaptations of An Mo.         │
  │                (→ B13 for Shiatsu detail)                               │
  │                                                                         │
  │  1970s         Korean Hand Therapy: Yoo Tae-woo develops hand          │
  │                microsystem (Koryo Sooji Chim). 345 points on hand.     │
  │                                                                         │
  │  1973          H.L. Wen (Hong Kong): discovers electroacupuncture      │
  │                reduces opiate withdrawal symptoms → leads to NADA       │
  │                auricular protocol (needle-based, but ear seed           │
  │                acupressure used as adjunct between sessions).           │
  │                                                                         │
  │  1980s-1990s   P6 (Neiguan) wristband studies begin — acupressure     │
  │                enters Western mainstream via commercial devices.        │
  │                                                                         │
  │  1997          NIH Consensus: endorses acupuncture for PONV; P6        │
  │                acupressure implicitly included as non-invasive variant. │
  │                                                                         │
  │  2003-present  Chao-Hsing Yeh: Auricular Point Acupressure (APA)      │
  │                protocol development — vaccaria seeds at ear points.     │
  │                Most prolific acupressure researcher (~22 papers         │
  │                in bibliometric analysis, >$10M career grants).          │
  │                                                                         │
  │  2015-2026     Accelerating RCT output: 45% of all acupressure        │
  │                publications from 2020-2024 (Heliyon bibliometric).      │
  │                Meta-analyses proliferating (189 since 2018).            │
  │                                                                         │
  └──────────────────────────────────────────────────────────────────────────┘

  CRITICAL OBSERVATION:
    Acupressure's PRACTICE is ancient (likely pre-needle), but its
    RESEARCH BASE is very modern (~60% of evidence published since 2018).
    This inversion — oldest modality, newest evidence — shapes the field.

  🟢 Classical references: documented in Neijing, Zhubing Yuanhou Lun
  🟢 Modern timeline: published literature and bibliometric analysis
  🟡 Pre-needle precedence: logical inference, not directly provable
```

### §1.3 — Traditional Theoretical Framework

```
⚠️ FRAMING: Acupressure uses the SAME theoretical framework as acupuncture:
  Qi, meridians, Yin-Yang, Five Elements, Zang-Fu organ theory.

  These concepts are fully documented in B01 §1.3. NOT repeated here.
  → See B01 §1.3.1 (Qi), §1.3.2 (Meridians), §1.3.3 (Yin-Yang),
    §1.3.4 (Five Elements), §1.3.5 (Zang-Fu)

  TCM PERSPECTIVE ON PRESSURE vs NEEDLE:
    Traditional explanation: both needle and pressure "move Qi" at acupoints.
    → Needle: stronger, more precise, can tonify/sedate via manipulation
    → Pressure: gentler, more accessible, suitable for self-treatment
    → Some sources: pressure "promotes" (推动) Qi flow; needle "directs"
      (引导) Qi flow — implying a difference in strength/precision, not kind

  TRADITIONS WITH INDEPENDENT THEORETICAL FRAMEWORKS:
    ┌────────────────────────────────────────────────────────────────────────┐
    │  Tradition       │ Theory                │ Relationship to TCM        │
    │──────────────────┼───────────────────────┼────────────────────────────│
    │  TCM acupressure │ Qi, meridians         │ = TCM (identical)          │
    │  Shiatsu (B13)   │ Ki, Keiraku (経絡)     │ Japanese adaptation of TCM │
    │  Korean Hand     │ Qi, correspondence    │ TCM-derived microsystem    │
    │  Jin Shin Jyutsu │ Life energy, 26 SELs  │ Loosely TCM-inspired,     │
    │                  │ (Safety Energy Locks)  │ heavily reinterpreted      │
    │  Marma therapy   │ Prana, Dosha, Srotas  │ INDEPENDENT (Ayurvedic)    │
    │                  │ (107 Marma points)     │ Some anatomical overlap    │
    │  EFT (B12)       │ "Energy meridians" +  │ TCM-derived point names,   │
    │                  │ cognitive psychology   │ + exposure therapy hybrid   │
    └──────────────────┴───────────────────────┴────────────────────────────┘

  NOTE: Marma points (Ayurvedic tradition) = 107 points with INDEPENDENT
  origin from TCM's 361 acupoints. A comparative study (PMC10382659)
  found anatomical overlap at some locations but distinct theoretical
  frameworks. This represents convergent clinical observation, not
  cultural transmission.

  🟢 Historical data: documented in classical texts
  🔴 "Qi movement" explanation: traditional theory, not mechanism
```

### §2.1 — Manual Pressure Techniques

```
🟢 ACUPRESSURE TECHNIQUES — APPLIED WITHOUT PENETRATING SKIN:

  │  TECHNIQUE         │ TOOL          │ APPLICATION                        │
  │────────────────────┼───────────────┼────────────────────────────────────│
  │  ① Sustained       │ Thumb pad,    │ Steady pressure held for           │
  │     pressure       │ fingertip     │ 10-60 seconds per point.           │
  │     (按 An)        │               │ Most common clinical technique.    │
  │                    │               │ Typically 3-5 kg force (30-50N).   │
  │                    │               │ Used at most body acupoints.       │
  │────────────────────┼───────────────┼────────────────────────────────────│
  │  ② Circular        │ Thumb, middle │ Small circular motions ON the      │

  │────────────────────┼───────────────┼────────────────────────────────────│
  │  ⑤ Pressing with   │ Elbow tip,    │ Deep pressure at points with       │
  │     tool           │ knuckle,      │ thick overlying tissue (gluteal,   │

  │                    │               │ Higher force: 50-80N possible.     │
  │────────────────────┼───────────────┼────────────────────────────────────│

  │     (Jin Shin      │ full hand     │ 1-3 minutes. Targets              │

  🟡 Force values: estimated from available measurement studies

### §2.2 — Pressure Parameters

```
🟢 PRESSURE PARAMETERS — QUANTIFIABLE BUT POORLY STANDARDIZED:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  Parameter        │ Range              │ Notes                          │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  FORCE            │ 5-80 N             │ Most studies: 30-50 N          │

  │                   │                    │ Fingertip ~1-2 cm²             │
  │                   │                    │ vs needle tip ~0.05 mm²        │
  │                   │                    │ → PRESSURE/area differs by     │
  │                   │                    │ ORDERS OF MAGNITUDE            │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  DEPTH reached    │ Surface-to-deep    │ Depends on force + anatomy     │
  │  (tissue layer)   │ fascia             │ No penetration beyond skin     │
  │                   │                    │ but force TRANSMITS through    │
  │                   │                    │ fascial continuum (A03 §1.2)   │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  DURATION         │ 10-60 sec/point    │ Most protocols: 30 sec/point   │
  │  per point        │                    │ Self-treatment: often 1-3 min  │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  SESSION          │ 10-30 minutes      │ Typical: 15-20 min             │
  │  duration         │                    │ Self-treatment: 5-15 min       │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  FREQUENCY        │ 1-7 sessions/week  │ Self-treatment enables         │
  │  of treatment     │                    │ daily application (compliance  │
  │                   │                    │ 92.3% at week 8 in one study)  │
  │───────────────────┼────────────────────┼────────────────────────────────│
  │  TREATMENT        │ 1-12 weeks         │ Chronic conditions: 4-8 weeks  │
  │  course           │                    │ Acute (PONV): single session   │
  └──────────────────────────────────────────────────────────────────────────┘

  CRITICAL PARAMETER: PRESSURE-PER-AREA
    Needle: 0.25mm Ø tip → ~0.05 mm² → 30N/0.00005 m² ≈ 600 MPa at tip
    Thumb: ~4 cm² contact → 30N/0.0004 m² ≈ 75 kPa at surface
    → RATIO: needle delivers ~8,000× more pressure per unit area
    → This explains why needle penetrates tissue and acupressure does not
    → BUT: acupressure distributes force across MORE mechanoreceptors
      simultaneously (wider field of Aβ activation)

  DOSE-RESPONSE GAP:
    No systematic human study has established the minimum effective pressure
    for acupressure, or an optimal dose-response curve. One trial measured
    25-35 N at specific points (Tiantu/Chize/Taiyuan) for post-operative
    cough — but this is a single data point, not a dose-response study.
    → This is one of acupressure's most significant evidence gaps.

  🟢 Parameter ranges: from published RCTs and measurement studies
  🟡 Pressure-per-area calculation: physics, straightforward
  🔴 Dose-response: explicitly identified as unresolved gap
```

### §2.3 — Sensation: The Absent De Qi

```
🟡 ACUPRESSURE SENSATION vs DE QI:

  De Qi (得气, B01 §2.3) = the composite sensation specific to needle
  acupuncture: suan (aching), ma (tingling/numbness), zhang (distension),
  zhong (heaviness). Its physical basis includes needle grasp (collagen
  winding), tissue deformation, and multi-fiber (Aδ + C + Aβ) activation.

  ACUPRESSURE PRODUCES A DIFFERENT SENSATION PROFILE:
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  De Qi Component      │ Acupressure Equivalent                         │
  │───────────────────────┼────────────────────────────────────────────────│
  │  酸 suan (aching)     │ PARTIAL — tenderness at point, not identical   │
  │  麻 ma (numbness)     │ ABSENT — no tingling/numbness reported         │
  │  胀 zhang (distension)│ CLOSEST MATCH — fullness/pressure sensation    │
  │  重 zhong (heaviness) │ PARTIAL — some sense of heaviness with deep    │
  │                       │ pressure, but less distinct                     │
  │  Spreading/radiating  │ RARE — occasional referred sensation with      │
  │                       │ sustained deep pressure at specific points     │
  │  Needle grasp         │ ABSENT — no shaft to create tissue-winding     │
  └──────────────────────────────────────────────────────────────────────────┘

  TCM PRACTITIONERS' VIEW:
    Some describe a "pressure De Qi" — the patient feels the point become
    tender or "activated" under sustained pressure. This is used as a
    clinical guide: practitioners press until they feel the tissue "yield"
    or the patient reports a characteristic ache.

  NEUROPHYSIOLOGICAL INTERPRETATION:
    → Acupressure sensation = predominantly Aβ mechanoreceptor activation
      (Ruffini SA-II: sustained pressure; Merkel SA-I: edge detection)
    → Deep acupressure may recruit some Aδ high-threshold mechanoreceptors
      → producing the "hurts-so-good" ache that overlaps with De Qi's
      suan component
    → The tingling/numbness (ma) component of De Qi likely requires
      C-fiber and Aδ activation from tissue penetration
    → NO needle-grasp → no connective tissue winding → no ATP cascade
      from concentrated focal deformation (Goldman 2010)

  CLINICAL SIGNIFICANCE:
    If De Qi is required for acupuncture's therapeutic effect (debated —
    see B01 §2.3), its absence in acupressure would predict REDUCED
    efficacy. This aligns with the fMRI finding that acupuncture activated
    substantially more brain regions than pressure at the same points
    (LI11/ST36; PubMed 20423217). But acupressure still works for some
    conditions (PONV, anxiety) → suggesting De Qi is NOT the sole
    mechanism, and gate control/somatovisceral pathways suffice for
    certain outcomes.

  🟡 Sensation comparison: synthesis from De Qi research + acupressure reports
  🟡 Neurophysiological interpretation: consistent inference, not direct study
```

### §2.4 — Auricular Acupressure Devices

```
🟢 AURICULAR ACUPRESSURE — NON-INVASIVE TOOLS FOR EAR POINTS:

  Unlike body acupressure (which uses fingers), auricular acupressure
  typically uses small objects TAPED to ear points for continuous
  stimulation between sessions. This is a DISTINCT delivery method.

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  Device Type       │ Description                 │ Mechanism            │
  │────────────────────┼─────────────────────────────┼──────────────────────│
  │  Vaccaria seeds    │ Hard round seeds of Wang    │ Constant low-level   │
  │  (王不留行)         │ Bu Liu Xing plant, ~2mm Ø.  │ pressure at taped    │
  │                    │ Taped to ear with adhesive.  │ point. Patient       │
  │                    │ Most used in APA research.   │ presses 3×/day for   │
  │                    │                             │ additional stimulus. │
  │────────────────────┼─────────────────────────────┼──────────────────────│
  │  Magnetic pellets  │ Small magnetic beads,       │ Pressure + magnetic  │
  │                    │ ~1.5-2mm Ø, taped to ear.   │ field (mechanism of  │
  │                    │                             │ magnetic component   │
  │                    │                             │ unclear/unvalidated).│
  │────────────────────┼─────────────────────────────┼──────────────────────│
  │  Metal pellets     │ Small steel or gold beads.  │ Pressure only.       │
  │                    │ Used in Japanese auricular.  │ No magnetic field.   │
  │────────────────────┼─────────────────────────────┼──────────────────────│
  │  Crystal/ceramic   │ Non-magnetic alternatives.  │ Pressure only.       │
  │  pellets           │ Recent commercial product.  │                      │
  └──────────────────────────────────────────────────────────────────────────┘

  PROTOCOL — APA (Auricular Point Acupressure, Yeh protocol):
    1. Select 3-5 auricular points based on condition
    2. Clean ear surface with alcohol
    3. Tape vaccaria seed to each point with adhesive (hypoallergenic)
    4. Instruct patient to press each point ~3 times/day, 3 min per session
    5. Replace seeds every 3-5 days
    6. Course: typically 4-8 weeks
    → Self-managed between visits = high treatment density possible

  IMPORTANT DISTINCTION — ACUPRESSURE vs ACUSTIMULATION:
    "Sea-Band" and similar elastic wristbands = mechanical acupressure
    "ReliefBand" and similar battery-powered devices = electrical stimulation
    These are MECHANISTICALLY DIFFERENT and sometimes yield different
    results (e.g., 739-patient chemo trial: men benefited more from
    electrical band, effect not seen in women).
    → Keep these device classes distinct.

  🟢 Device descriptions: published in clinical protocols
  🟡 Magnetic pellet mechanism: unclear, magnetic component unvalidated
```

### §2.5 — Self-Administration: A Unique Feature

```
🟢 SELF-ADMINISTRATION — ACUPRESSURE'S KEY PRACTICAL ADVANTAGE:

  Unlike acupuncture (requires trained practitioner + needle + licensing),
  acupressure can be taught to patients for self-treatment. This is NOT
  just a convenience feature — it fundamentally changes the treatment model.

  WHAT SELF-ADMINISTRATION ENABLES:
    → Daily treatment (vs weekly clinic visits for acupuncture)
    → Treatment in any setting (home, workplace, hospital bed)
    → Access for populations with limited healthcare access
      (veterans, rural communities, developing countries)
    → Caregiver-administered for elderly/cognitive impairment
    → Reduced cost (no practitioner fees after initial training)
    → Patient empowerment/agency in own treatment

  COMPLIANCE DATA:
    92.3% of participants still practicing at week 8 (one study)
    → Self-acupressure compliance is remarkably HIGH
    → Possibly because it is simple, painless, and felt to be helpful
    → Several studies used app/booklet support for point location

  THE DOUBLE-EDGED SWORD:
    Self-administration is ALSO acupressure's major methodological weakness:
    → When the patient IS the practitioner, blinding is nearly impossible
    → Patient knows whether they're pressing the "right" point
    → Patient knows the force they're applying
    → This structural blinding problem affects ALL self-administered
      acupressure evidence (→ §9 Evidence Assessment)

  POPULATIONS STUDIED FOR SELF-ACUPRESSURE:
    → Veterans with chronic back pain (VA studies)
    → Family caregivers (caregiver burden/stress)
    → Psychiatric inpatients (constipation)
    → Cancer survivors (fatigue — Zick protocol)
    → Pregnant women (nausea — P6 wristband)
    → Older adults with insomnia
    → Knee osteoarthritis patients

  🟢 Compliance data: published in RCTs
  🟢 Population studies: published trials
  🟡 "Double-edged sword" framing: our synthesis of evidence patterns
```

  1. NOT ALL ACUPOINTS ARE EQUALLY SUITED TO ACUPRESSURE:
     → Points requiring DEEP stimulation (BL54 at gluteal depth,
       GV26 at philtrum) may not receive adequate force from finger pressure
     → Points at THIN tissue (scalp points, face) may be overstimulated
       by the same force appropriate for limb points
     → BEST suited: points at accessible, moderate-tissue-depth locations
       on limbs, trunk, ears, hands

     → Acupuncture protocols: 8-20 needles simultaneously
     → Acupressure protocols: typically 3-6 points per session
       (each pressed sequentially, since only 2 hands available)
     → Self-acupressure: 1-4 easily-located points
     → This CONCENTRATES treatment on high-value points

  3. ASHI POINTS (tender points) ARE NATURALLY ACCESSIBLE:
     → Patient presses until they find the tender spot = self-location
     → No anatomical training needed for Ashi-based self-acupressure
     → Overlaps with B08 trigger point self-treatment

### §3.3 — Auricular Anatomy: The ABVN Advantage

```
🟢 WHY EAR ACUPRESSURE HAS A UNIQUE ANATOMICAL BASIS:

  The outer ear is the ONLY place on the body surface directly innervated
  by a cutaneous branch of the VAGUS NERVE — the auricular branch of the
  vagus nerve (ABVN, also called Arnold's nerve).

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ABVN ANATOMY:                                                          │
  │                                                                         │
  │  Vagus nerve (CN X) → auricular branch (ABVN) → exits jugular foramen │
  │  → travels through temporal bone → emerges to innervate:                │
  │    → Concha (cymba conchae + cavum conchae) ← MOST densely innervated │
  │    → Tragus                                                             │
  │    → Antihelix                                                         │
  │    → Parts of external auditory meatus                                  │
  │                                                                         │
  │  ABVN afferents project to → nucleus tractus solitarius (NTS)          │
  │    = the SAME brainstem nucleus that receives:                          │
  │    → Cardiac vagal afferents (baroreceptor reflex)                     │
  │    → Pulmonary vagal afferents (respiratory control)                   │
  │    → Gastrointestinal vagal afferents (gut-brain axis)                 │
  │    → → A02 §2.2 for NTS hub role                                      │
  │                                                                         │
  │  THIS MEANS: pressing the concha/tragus of the ear provides a         │
  │  non-invasive route to the VAGAL BRAINSTEM CIRCUIT — the same          │
  │  circuit that electroacupuncture at ST36 engages via deep-tissue       │
  │  nerve stimulation.                                                     │
  └──────────────────────────────────────────────────────────────────────────┘

  EVIDENCE FOR ABVN PATHWAY:
    → Transcutaneous auricular vagus nerve stimulation (taVNS) literature
      provides the strongest mechanistic evidence for auricular acupressure
    → taVNS at concha → measurable changes in:
      - fMRI: NTS activation confirmed (Frangos 2015)
      - HRV: parasympathetic upregulation (pilot studies)
      - Gastric motility: vagal gastric effects (Farmer 2020)
    → taVNS uses ELECTRICAL stimulation, but the anatomical pathway
      (ABVN → NTS) is the same for mechanical pressure
    → Whether PRESSURE produces the SAME magnitude of ABVN activation
      as electrical stimulation = not directly compared

  CLINICAL IMPLICATION:
    Auricular acupressure at concha/tragus-innervated points has a
    STRONGER anatomical rationale than body acupressure — because it
    has a DIRECT, KNOWN, MAPPED neural pathway (ABVN → NTS → vagal
    output) that does not require tissue penetration to reach.

    Body acupoints rely on: Aβ → gate control (indirect)
    Ear concha points rely on: ABVN → NTS → vagal circuit (direct)

    → This may explain why auricular acupressure has its own
      independent evidence stream across multiple conditions.

  🟢 ABVN anatomy: well-established neuroanatomy
  🟢 taVNS/NTS activation: fMRI-confirmed (Frangos 2015)
  🟡 Mechanical pressure → ABVN equivalence with electrical: inferred

  ATLAS NOTE (AP-16, ABVN gradient mapping):
    → taVNS evidence applies to CYMBA CONCHAE specifically
      (100% ABVN innervation, Peuker & Filler 2002)
    → Other auricular zones have MIXED or NO ABVN:
      cavum conchae ~45%, tragus V3+ABVN mixed, antihelix
      body 73%, crura 9%, lobule/scaphoid fossa 0%
    → Transferring taVNS evidence to non-cymba auricular
      points is NOT supported — mixed innervation ≠ pure ABVN
    → AP-Mechanism-Summary §5.2, AP-16 Auricular ⚡6
```

## §4 — DOCUMENTED CLINICAL EFFECTS

### §4.1 — Evidence Tiering

```
🟡 EVIDENCE TIERING — HOW CONDITIONS ARE CLASSIFIED:

  TIER 1 (Strong): Multiple RCTs + meta-analysis with consistent positive
    results + at least one guideline recommendation
  TIER 2 (Moderate): Multiple RCTs + at least one meta-analysis, positive
    pooled effects, but GRADE certainty low or very low
  TIER 3 (Preliminary): Few RCTs, mixed results, or only pilot studies
  TIER 4 (Emerging): Single trials, case reports, or just-initiated research

  NOTE: Unlike acupuncture (B01), acupressure has NO dedicated Cochrane
  review for any condition. Its best-graded evidence lives INSIDE combined
  acupoint-stimulation reviews (most notably CD003281 for PC6/PONV).
  This means acupressure-specific effect estimates are often SUB-ANALYSES
  within larger reviews, not primary outcomes.

  COMPARISON WITH B01 AND B03:
    B01 Acupuncture: 862 SRs, 56 Cochrane, 6,562 RCTs
    B03 Massage: 400-600+ RCTs, 8 Cochrane reviews
    B02 Acupressure: ~642 RCTs, 0 dedicated Cochrane reviews
    → B02 has the WEAKEST systematic evidence infrastructure of the three
    → But P6/PONV evidence is comparable in quality to B01's best
```

### §9.2 — The Structural Blinding Problem

```
🟢 ACUPRESSURE'S FUNDAMENTAL METHODOLOGICAL WEAKNESS:

  Unlike acupuncture (where sham needles like Streitberger/Park devices
  can create a credible placebo), acupressure has NO satisfactory
  sham control.

  THE PROBLEM:
    Patient FEELS pressure. Patient KNOWS the location.
    → If self-administered: patient IS the practitioner AND the subject
    → True double-blinding is structurally impossible

  6 SHAM APPROACHES USED IN RCTS (Tan et al. 2015, 66 RCTs, 7,265 pts):
  ┌──────────────────────────────────────────────────────────────────────────┐
  │  Sham Type                 │ Limitation                                 │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ① Non-acupoint location  │ Most common. Still involves pressure →    │
  │     (pressure at "wrong"   │ activates SOME mechanisms (gate control). │
  │     points)                │ NOT inert. May be therapeutic itself.     │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ② Light touch at real    │ Different DOSE, not different treatment.  │
  │     point                  │ Still touches acupoint → may activate    │
  │                            │ CT afferents.                             │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ③ Sham device (wristband │ Only applicable for P6 wristband.         │
  │     without pressure nub)  │ Patient may notice missing nub.           │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ④ No-treatment control   │ Unblinded. Placebo/attention effects     │
  │                            │ completely uncontrolled.                   │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ⑤ Usual care control     │ Same as ④ — adds treatment attention.    │
  │────────────────────────────┼────────────────────────────────────────────│
  │  ⑥ Standard treatment     │ Active comparator, not placebo control.   │
  │     (medication)           │ Different question entirely.              │
  └──────────────────────────────────────────────────────────────────────────┘

  CRITIQUE (Tan et al. 2015):
    → No sham design shown superior to others
    → No consistent relationship between sham type and outcome
    → Risk-of-bias: ~32 trials "high risk" for participant blinding,
      45 "high risk" for personnel blinding
    → Only a minority successfully blinded care provider

  SELF-ADMINISTRATION COMPOUNDS THE PROBLEM:
    → Patient applies own pressure → knows exact location and force
    → Genuine allocation concealment "nearly impossible"
    → Structurally WORSE blinding than acupuncture
    → This is NOT solvable with better trial design — it's inherent
      to the modality

  IMPLICATION FOR ALL ACUPRESSURE EVIDENCE:
    Every positive acupressure finding must be interpreted through this lens.
    The large effect sizes seen in some meta-analyses (e.g., SMD −1.30 for
    anxiety) may partly reflect inadequate blinding. This does not mean
    acupressure is ineffective — it means we cannot isolate the "specific"
    effect from the "contextual/placebo" effect with current methods.

  COMPARISON WITH THE ACUPUNCTURE "SHAM PROBLEM":
    B01 also faces blinding challenges, but:
    → Streitberger needle: telescoping sham with credible skin sensation
    → Park sham: validated blinding device
    → GERAC trials: demonstrated that sham is NOT inert but verum still
      2× conventional therapy
    → Acupressure has NO equivalent validated sham technology
    → → Acupressure's sham problem is STRUCTURALLY WORSE than acupuncture's

  🟢 Sham critique: published (Tan et al. 2015, PLOS ONE)
  🟢 Bias assessment: reported in systematic reviews
  🟡 "Structurally worse" assessment: our comparative analysis
```

  Acupressure is:

    Acupressure may be the most UNDERRESEARCHED relative to its

## §5 — PROPOSED MECHANISMS

> **Organizing principle:** B01 (acupuncture) uses a 6-LEVEL CASCADE model
> (L1-L6: Local → Systemic) because needle insertion triggers a sequential
> chain. B03 (massage) uses 6 MECHANISM CATEGORIES cross-cut by a 4-level
> pressure model because massage is area-based. B02 sits BETWEEN them —
> it shares B01's POINT-BASED precision but B03's NON-INVASIVE PRESSURE
> stimulus. Therefore §5 uses MECHANISM CATEGORIES (like B03) organized
> around the central question: what changes when pressure replaces needle
> at the same point?

### §5.1 — Traditional Explanation

```
🔴 TCM EXPLANATION — SAME FRAMEWORK AS B01 (CROSS-REFERENCE):

  TCM views both acupuncture and acupressure as "moving Qi" (气) at
  acupoints. The difference:
    → Needle "directs" (引导) Qi flow — stronger, more precise
    → Pressure "promotes" (推动) Qi flow — gentler, broader
    → Both work through the same meridian system (→ B01 §1.3)

  Other traditions have their own pressure-specific explanations:
    → Shiatsu: restoring Ki balance through thumb/palm pressure (→ B13)
    → Jin Shin Jyutsu: unlocking Safety Energy Locks by light hold
    → Marma: releasing Prana at vital junction points (Ayurvedic)
    → Each tradition emphasizes that pressure is SUFFICIENT —
      penetration is NOT required for therapeutic effect

  MODERN PERSPECTIVE ON THIS CLAIM:
    Traditional frameworks are CORRECT that pressure works differently
    from needle, but the explanation why differs. Track A data shows:
    → Pressure activates a DIFFERENT mechanism profile, not just
      a "gentler version" of the same pathways (→ §5.2)
    → The clinical domains where acupressure excels (nausea, anxiety,
      sleep) align with the mechanisms it DOES activate strongly
      (gate control, vagal tone, anxiolysis)
    → The domains where it underperforms (chronic pain, organ-specific
      effects) align with the mechanisms it LOSES (descending modulation,
      PROKR2, purinergic signaling)

  🔴 Qi-based explanation: traditional theory, not mechanism
  🟡 Domain-mechanism alignment: our synthesis from §4 + Track A
```

### §5.2 — Modern Research-Based Mechanisms

```
🟡 THE ACUPRESSURE MECHANISM SCORECARD:

  Track A analysis reveals 3 categories:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  FULLY SHARED or STRONGER for pressure (11 mechanisms):                │
  │    Gate control, somatovisceral reflex, CT afferent reward,            │

#### §5.2.1 — Neural Mechanisms

```
🟢 NEURAL PATHWAYS — ACUPRESSURE'S PRIMARY MECHANISM DOMAIN:

  Neural pathways are acupressure's STRONGEST mechanism category.
  4 of 5 neural pathways are fully or partially available:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ① GATE CONTROL — PRIMARY ACUPRESSURE MECHANISM                        │
  │     (A01 §3.3, Melzack & Wall 1965)                                    │
  │                                                                         │
  │  Pathway: Pressure at acupoint → Aβ mechanoreceptor activation         │
  │    (Ruffini SA-II for sustained; Merkel SA-I for edge detection)        │
  │    → dorsal horn lamina II (substantia gelatinosa)                     │
  │    → inhibitory interneuron activation → closes pain "gate"            │
  │    → reduces nociceptive transmission to brain                          │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    FULLY AVAILABLE — identical to acupuncture's Aβ component.          │
  │    But acupressure activates gate control as the DOMINANT pathway      │
  │    (because Aβ is the PRIMARY fiber recruited by surface pressure),    │
  │    whereas in acupuncture gate control is ONE OF MANY pathways         │
  │    alongside Aδ/C-mediated descending modulation.                     │
  │                                                                         │
  │  KEY DIFFERENCE: Aβ activation CLOSES the gate (inhibitory).           │
  │    Acupuncture's Aδ/C activation OPENS the gate locally but then      │
  │    triggers descending opioid inhibition from PAG (net analgesic).     │
  │    → Same destination (pain reduction), different circuit,             │
  │      different magnitude, different duration                            │
  │                                                                         │
  │  CONTACT AREA CONSIDERATION:                                           │
  │    Thumb pressure activates Aβ receptors across ~3-4 cm² simultaneously│
  │    Needle tip activates receptors at ~0.05 mm² focal point             │
  │    → Acupressure = WIDER Aβ recruitment field per stimulus             │
  │    → This may partly compensate for lack of Aδ/C pathway              │
  │                                                                         │
  │  Duration: during stimulation + short period after (minutes)           │
  │                                                                         │
  │  🟢 Gate control: well-established (Melzack & Wall 1965, A01 §3.3)    │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ② SOMATOVISCERAL REFLEX — SHARED, LOCATION-DEPENDENT                 │
  │     (A01 §2.3, A07 §1.6, §3.2; Sato et al. 1997)                     │
  │                                                                         │
  │  Pathway: Somatic afferent at dermatome → dorsal horn convergent       │
  │    neurons (Lamina V WDR) → autonomic outflow → organ modulation       │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    FULLY AVAILABLE — because the reflex depends on LOCATION            │
  │    (correct dermatome), NOT stimulus type. Lamina V WDR neurons        │
  │    receive Aβ alongside Aδ/C (A07 §3.2). Pressure at a dermatome     │
  │    point activates the same convergent neurons as needle.              │
  │                                                                         │
  │  TWO FORMS (Sato's distinction, A02 §3.5):                            │
  │    Segmental: abdominal stimulation → segmental sympathetic →          │
  │      modulates GI function, adrenal, renal blood flow                  │
  │    Supraspinal: limb stimulation → ascending to brainstem →            │
  │      vagal efferent → modulates heart, lung, gastric motility          │
  │                                                                         │
  │  P6 ANTI-NAUSEA EXPLAINED:                                            │
  │    P6 (forearm, median nerve territory) → supraspinal pathway →        │
  │    vagal modulation of gastric motility → anti-emetic effect.          │
  │    This somatovisceral reflex does NOT require tissue penetration.     │
  │    → Explains why P6 acupressure works nearly as well as P6            │
  │      acupuncture for PONV (Cochrane CD003281)                          │
  │                                                                         │
  │  MAGNITUDE QUESTION:                                                   │
  │    Does pressure activate Lamina V convergent neurons as STRONGLY      │
  │    as needle? Aβ reaches Lamina V, but Aδ/C provide STRONGER          │
  │    convergent input. The fMRI finding (PubMed 20423217) — acupuncture  │
  │    activated more brain regions than pressure at same points            │
  │    (LI11/ST36) — suggests the MAGNITUDE of central activation          │
  │    is lower for pressure, even if the PATHWAY is the same.            │
  │                                                                         │
  │  HEAD ZONES VALIDATION (A07 §4.1-4.2):                                │
  │    Beissner & Henke 2011: Mu/Shu points fall WITHIN Head zones for    │
  │    corresponding organs. Both TCM and Western medicine independently   │
  │    discovered viscero-cutaneous reflex points. → The LOCATIONS used    │
  │    in acupressure are physiologically real regardless of stimulus type. │
  │                                                                         │
  │  🟢 Somatovisceral reflex: well-established (Sato 1997, A07)          │
  │  🟡 Magnitude comparison pressure vs needle: inferred from fMRI       │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ③ DESCENDING MODULATION — REDUCED FOR ACUPRESSURE                    │
  │     (A01 §3.2; Pomeranz & Chiu 1976; Han 2004)                        │
  │                                                                         │
  │  Pathway: Strong Aδ/C input → ascending to PAG (periaqueductal gray)  │
  │    → activates descending inhibition via RVM → endorphin/enkephalin   │
  │    release → inhibits pain at spinal level                              │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    REDUCED — this pathway requires nociceptive (Aδ/C) input.          │
  │    Surface pressure primarily activates Aβ (touch/pressure), with     │
  │    only "some Aδ" recruited during deep pressure (A01 §4.1).          │
  │    → Insufficient to robustly activate PAG-RVM circuit                 │
  │    → Explains why acupressure is WEAKER for chronic pain than         │
  │      acupuncture: it lacks the descending opioid cascade              │
  │                                                                         │
  │  DEEP PRESSURE EXCEPTION:                                             │
  │    A01 §1.5: "Deep pressure / needling → Aδ + C nociceptors →        │
  │    endorphin release + axon reflex." Very deep acupressure (technique  │
  │    ⑤: elbow/tool, 50-80N) MAY partially cross the nociceptive        │
  │    threshold and engage some descending modulation. But:              │
  │    → No quantification exists for acupressure specifically             │
  │    → The "hurts-so-good" ache at deep acupressure (§2.3 partial      │
  │      suan overlap) suggests some Aδ activation does occur             │
  │    → Whether this is SUFFICIENT for PAG activation = unknown          │
  │                                                                         │
  │  NALOXONE DATA:                                                        │
  │    Pomeranz & Chiu 1976: naloxone blocked ACUPUNCTURE analgesia.      │
  │    No equivalent naloxone study for acupressure exists.                │
  │    If acupressure's analgesic effect were opioid-mediated, naloxone   │
  │    should reverse it. This test has not been done.                     │
  │                                                                         │
  │  🟢 Descending modulation pathway: well-established for acupuncture   │
  │  🟡 Partial availability for deep acupressure: plausible, untested    │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ④ CT AFFERENT — AFFECTIVE TOUCH PATHWAY                              │
  │     (A01 §1.4, §4.3; A06 §3.5; Löken 2009)                           │
  │                                                                         │
  │  Pathway: Gentle, slow stroking (1-10 cm/s) on hairy skin →           │
  │    C-tactile (CT) afferents → posterior insula → pleasant/rewarding    │
  │    signal → oxytocin release via PVN hypothalamus                      │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    STRONGER THAN NEEDLE for light techniques.                          │
  │    CT afferents respond to gentle touch — needles bypass this          │
  │    entirely (needles activate nociceptors, not CT afferents).          │
  │    → Technique ⑥ (Jin Shin Jyutsu light hold) is ideally suited      │
  │    → Technique ② (circular kneading, 2-3 circles/sec) has a          │
  │      movement component that may engage CT afferents                   │
  │    → Technique ① (sustained static pressure, 30-50N) is LESS         │
  │      suited — CT afferents prefer MOVING touch, not static hold       │
  │                                                                         │
  │  IMPORTANT LIMITATION:                                                 │
  │    CT afferents are found primarily in HAIRY skin.                     │
  │    Many acupoints are on glabrous skin (palms, soles) where CT        │
  │    density is low or absent. P6 (wrist, hairy side) = CT accessible.  │
  │    KI1 (sole) = no CT afferents. Point location matters.              │
  │                                                                         │
  │  OXYTOCIN CONNECTION (A06 §3.5):                                      │
  │    CT afferent activation → PVN → oxytocin release → OTR on C/Aδ     │
  │    terminals → reduced nociceptor excitability → analgesia.            │
  │    Intranasal OT enhances pleasantness of gentle stroking (eLife 2023).│
  │    OT antagonist reverses thermal (but NOT mechanical) antinociception │
  │    from massage → partial mediator.                                    │
  │                                                                         │
  │  🟢 CT afferents: well-characterized (Löken 2009, Olausson 2002)      │
  │  🟡 Applicability to specific acupressure techniques: synthesis        │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ⑤ ABVN PATHWAY — UNIQUE TO AURICULAR ACUPRESSURE                     │
  │     (A02 §2.2; §3.3 ABVN anatomy; Frangos 2015)                       │
  │                                                                         │
  │  Pathway: Pressure at concha/tragus → ABVN (auricular branch of       │
  │    vagus nerve) → NTS (nucleus tractus solitarius) → vagal efferent   │
  │    → cardiac, respiratory, GI modulation                               │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    UNIQUE ADVANTAGE — the ear is the ONLY body surface with            │
  │    cutaneous vagal innervation. No tissue penetration needed to        │
  │    reach ABVN — it is SUPERFICIAL by anatomy.                          │
  │                                                                         │
  │    This means auricular acupressure has a DIRECT, MAPPED neural       │
  │    route to the vagal brainstem circuit:                                │
  │    → Body acupoints: Aβ → gate control → indirect autonomic shift     │
  │    → Ear concha points: ABVN → NTS → DIRECT vagal circuit             │
  │    → Same NTS that receives cardiac, pulmonary, GI vagal afferents    │
  │                                                                         │
  │  EVIDENCE:                                                             │
  │    → taVNS (electrical) at concha: NTS activation on fMRI (Frangos    │
  │      2015). HRV parasympathetic upregulation. Gastric motility         │
  │      changes (Farmer 2020).                                            │
  │    → Mechanical pressure at same location uses SAME nerve (ABVN),     │
  │      though magnitude comparison with electrical = not done            │
  │    → This pathway is INDEPENDENT of general acupressure mechanisms     │
  │      and may explain auricular acupressure's repeated appearance       │
  │      across clinical domains (pain, anxiety, sleep, constipation,      │
  │      depression — §4.3, §4.4)                                         │
  │                                                                         │
  │  TRIGEMINAL-VAGAL COUPLING (A02 §4.5):                                │
  │    Facial acupressure points (EX-HN3 Yintang, ST2, etc.) may access  │
  │    a second cranial vagal route: trigeminal afferent → brainstem →    │
  │    DMN of vagus → parasympathetic activation. The diving reflex       │
  │    (face immersion → bradycardia) demonstrates this pressure →        │
  │    vagal coupling principle.                                           │
  │                                                                         │
  │  ABVN GRADIENT (Atlas AP-16, Peuker & Filler 2002):                   │
  │    Cymba conchae: 100% ABVN → strongest vagal access                 │
  │    Cavum conchae: ~45% ABVN (mixed with V3)                          │
  │    Antihelix body: 73% (partial vagal)                                │
  │    Tragus: V3 + ABVN mixed                                           │
  │    Antihelix crura: 9% (minimal vagal)                               │
  │    Lobule / scaphoid fossa: 0% ABVN (pure C2-C3 GAN)               │
  │  → Mixed innervation ≠ pure ABVN. Zone determines mechanism.        │
  │  → AP-Mechanism-Summary §5.2, AP-16 ⚡6                              │
  │                                                                         │
  │  🟢 ABVN anatomy: well-established neuroanatomy                       │
  │  🟢 taVNS/NTS activation: fMRI-confirmed (Frangos 2015)              │
  │  🟡 Mechanical pressure = electrical at ABVN: assumed, not tested     │
  └──────────────────────────────────────────────────────────────────────────┘
```

```

  │  This is one of acupressure's STRONGEST immune mechanisms because     │
  │  it operates through vagal tone enhancement, which acupressure        │
  │  achieves through multiple converging routes. Auricular acupressure   │
  │  has the most DIRECT route (ABVN → NTS → vagal efferent).            │

  │                                                                         │

  │    → Reduces inflammation while promoting tissue repair                │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    AVAILABLE — Crane's study used post-exercise MASSAGE (pressure),    │

  │    at specific points would activate integrins → FAK cascade.          │

  │                                                                         │

  │    Crane's massage = broad area compression (quadriceps muscle belly). │
  │    Acupressure = focal point compression. Same pathway, but:           │
  │    → Less tissue volume affected per stimulus                          │
  │    → Higher pressure concentration at point (75 kPa thumb tip)         │
  │    → Net mechanotransduction effect: likely similar per unit area,     │
  │      but less total tissue response than full muscle massage           │
  │                                                                         │
  │  🟢 Crane 2012 mechanotransduction: well-established                  │

  │                                                                         │

#### §5.2.4 — Fascial / Connective Tissue Mechanisms

```
🟡 FASCIAL PATHWAYS — THE BIGGEST MECHANISTIC DIVERGENCE:

  Fascial mechanisms represent the LARGEST gap between acupressure and
  acupuncture. The best-characterized fascial mechanism (needle grasp)
  is entirely needle-specific. But pressure-native alternatives exist.

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  ① MECHANOTRANSDUCTION VIA INTEGRINS/ION CHANNELS — PARTIALLY SHARED  │
  │     (A03 §3.1; Langevin 2002, 2006)                                    │
  │                                                                         │
  │  Pathway 1 (integrin): ECM deformation → integrins → FAK →            │
  │    Rho/Rac/YAP/TAZ → ECM remodeling, collagen production              │
  │  Pathway 2 (ion channel): Membrane stretch → Piezo1 (rapid Ca²⁺),     │
  │    Piezo2 (touch/proprioception), TRPV4 (osmotic) → sustained signal  │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    PARTIALLY AVAILABLE — these pathways respond to ANY mechanical     │
  │    input (pressure, needle, stretch, vibration). Acupressure DOES     │
  │    deform tissue. But:                                                 │
  │    → Surface pressure attenuates with DEPTH — the fascial layers      │
  │      closest to the surface receive most deformation                   │
  │    → Needle physically REACHES deep fascial planes (80% of acupoints  │
  │      sit at intermuscular/intramuscular CT planes, Langevin 2002)      │
  │    → Whether surface pressure produces sufficient deformation at      │
  │      the RELEVANT fascial depth = open question                        │
  │                                                                         │
  │  FORCE TRANSMISSION PRINCIPLE (A03 §2.2, §4.1):                       │
  │    15-37% of muscular force is transmitted via myofascial pathways    │
  │    (Huijing 2009). Pressure at the surface DOES propagate through     │
  │    the fascial continuum. But signal attenuates with distance.         │
  │    "Anatomy Trains" provide mechanical pathways for distant effects.   │
  │                                                                         │
  │  🟢 Mechanotransduction pathways: well-characterized (A03 §3.1)       │
  │  🟡 Depth of signal from surface pressure: qualitative, not measured  │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ② NEEDLE GRASP / COLLAGEN WINDING — LOST FOR ACUPRESSURE             │
  │     (A03 §3.2; Langevin 2006)                                          │
  │                                                                         │
  │  THE best-characterized fascial therapy mechanism:                     │
  │    Langevin's 5-step model:                                            │
  │      1. Needle inserted into connective tissue                         │
  │      2. Needle rotated → collagen fibers WIND around shaft             │
  │      3. Creates expanding "whorl" of tissue deformation                │
  │      4. Fibroblast cytoskeletal reorganization (Rho/Rac pathways)      │
  │      5. Sustained cellular signaling (ATP release, Ca²⁺ waves)         │
  │    167% increase in pullout force during rotation.                     │
  │    Signal propagates SEVERAL CENTIMETERS from needle.                  │
  │    Dose-dependent: peaks at 2 revolutions.                             │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    ENTIRELY ABSENT — no shaft to wind around, no tissue penetration,  │
  │    no collagen winding, no 167% tissue coupling.                       │
  │    This is the single clearest mechanistic loss for acupressure.       │
  │                                                                         │
  │  🟢 Needle grasp: well-established (Langevin 2001, 2006)              │
  │                                                                         │
  ├──────────────────────────────────────────────────────────────────────────┤
  │  ③ HA METABOLISM / THIXOTROPY — FULLY SHARED                          │
  │     (A03 §2.4; Langevin 2011)                                          │
  │                                                                         │
  │  Fascial densification = HA viscosity increase between fascial        │
  │  sublayers → restricted gliding → pain. Reversible with               │
  │  mechanical input: manual therapy (including pressure) →              │
  │  metabolizes HA chains → restores low viscosity → pain relief.        │
  │                                                                         │
  │  FOR ACUPRESSURE:                                                      │
  │    FULLY AVAILABLE — this is a PRESSURE-NATIVE mechanism:             │
  │    → Does NOT require tissue penetration                               │
  │    → Sustained pressure → fascial elongation → HA metabolism          │
  │    → Demonstrated for massage (B03 §5.2.4 ②) — same mechanical       │
  │      principle applies to sustained pressure at a point               │
  │    → TLF in chronic LBP: 25% thickness increase, 56% shear strain    │
  │      reduction (Langevin 2011) — reversed by manual therapy           │
  │                                                                         │
  │  CHA FRAMEWORK (A03 §3.1):                                            │
  │    Mechanical stress → Ca²⁺ channels (Piezo1, TRPV4, P2Y2) →         │
  │    Ca²⁺ influx → HAS2 → HA synthesis. Explains molecular mechanism   │
  │    by which acupressure affects HA at the cellular level.              │
  │                                                                         │
  │  This represents acupressure's ALTERNATIVE to needle grasp:            │
  │    Needle grasp = rapid, focal, high-magnitude fascial engagement      │
  │    HA metabolism = slower, sustained, diffuse fascial engagement       │
  │    Different temporal profile, potentially converging outcomes.         │
  │                                                                         │
  │  🟢 HA/thixotropy: established mechanism for manual therapy           │
  │  🟡 Equivalence with needle grasp outcome: not directly compared      │
  └──────────────────────────────────────────────────────────────────────────┘
```

#### §5.2.5 — Musculoskeletal Mechanisms

```
🟢 MUSCULOSKELETAL PATHWAYS — MOSTLY SHARED:

  ┌──────────────────────────────────────────────────────────────────────────┐

  │                                                                         │

  │    simultaneous trigger point compression for most common trigger point loci.   │

### §5.3 — Framework Synthesis: The Pressure-Point Divergence Model

```
🟡 SYNTHESIS — ACUPRESSURE IS A DISTINCT MODALITY, NOT A WEAKER SUBSTITUTE:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  THE PRESSURE-POINT DIVERGENCE MODEL                                   │
  │                                                                         │
  │  When PRESSURE replaces NEEDLE at the SAME POINT, the mechanism       │
  │  profile DIVERGES into a distinct therapeutic modality:                 │
  │                                                                         │
  │  RETAINED: The LOCATION-DEPENDENT pathways                             │
  │    → Somatovisceral reflex (dermatome → organ modulation)              │
  │    → Gate control (Aβ at any body site)                                │
  │    → ABVN pathway (auricular points → NTS → vagal)                    │
  │    → trigger point compression (93.3% overlap with acupoints)                    │
  │    → Segmental convergence at Lamina V WDR neurons                     │
  │    These pathways depend on WHERE you stimulate, not HOW.             │
  │                                                                         │
  │  LOST: The TISSUE-PENETRATION-DEPENDENT pathways                      │
  │    → Needle grasp / collagen winding (no shaft)                        │
  │    → Goldman adenosine 24× (needs fascial-level rotation)              │
  │    → PROKR2 vagal-adrenal (neurons in deep fascia/periosteum)          │
  │    → LTR / endplate reset (needs penetration to endplate zone)         │
  │    → Full axon reflex (needs nociceptor activation from penetration)   │
  │    → Frequency-dependent opioid release (needs EA)                     │
  │    → Micro-wound healing cascade (no tissue damage)                    │
  │    These pathways require WHAT the needle physically does.             │
  │                                                                         │
  │  GAINED: The PRESSURE-NATIVE pathways                                  │
  │    → Wider Aβ recruitment field (thumb 3-4 cm² vs needle 0.05 mm²)    │
  │    → CT afferent activation (gentle techniques — stronger than needle) │
  │    → HA/thixotropy (sustained pressure → fascial densification         │
  │      reversal — no penetration needed)                                  │
  │    → trigger point reactive hyperemia (pressure-SPECIFIC mechanism)              │
  │    → Self-treatment neuroplastic advantage (frequency × duration)      │
  │    These pathways work BECAUSE of how pressure differs from needle.   │
  │                                                                         │
  │  → The INTERSECTION determines SHARED clinical territory              │
  │    (PONV, anxiety, basic pain modulation — gate control +              │
  │    somatovisceral reflex are sufficient for these)                     │
  │                                                                         │
  │  → The LOSSES determine where acupuncture EXCEEDS acupressure         │
  │    (chronic pain, organ-specific deep effects — need PROKR2,           │
  │    descending modulation, adenosine cascade)                           │
  │                                                                         │
  │  → The GAINS determine acupressure's UNIQUE value                     │
  │    (self-management, accessibility, compliance, daily treatment        │
  │    density, zero adverse events, CT afferent reward pathway)           │
  │                                                                         │
  └──────────────────────────────────────────────────────────────────────────┘

  THE AURICULAR EXCEPTION:

    Auricular acupressure is MECHANISTICALLY DISTINCT from body acupressure
    because it accesses a pathway (ABVN → NTS) that is:
    → ANATOMICALLY SUPERFICIAL (no deep penetration needed)
    → DIRECT vagal (not indirect via gate control → ANS shift)
    → SHARED with taVNS electrical stimulation (which has stronger evidence)

    This makes auricular acupressure a separate sub-modality with a
    STRONGER anatomical rationale than body acupressure. It may deserve
    its own mechanism classification in future iterations.

  THE 8,000× PARADOX:

    Needle delivers ~8,000× more pressure per unit area than thumb (§2.2).
    Yet acupressure still produces clinically significant effects.
    The divergence model explains this: the effects that survive are
    NOT pressure-magnitude-dependent (gate control works at Aβ threshold;
    somatovisceral reflex depends on location, not force; ABVN is
    superficial). The effects that are lost ARE magnitude/depth-dependent
    (PROKR2 needs periosteal depth; adenosine needs fascial-level
    deformation; collagen winding needs concentrated torque).

  CLINICAL PREDICTION FROM THIS MODEL:
    Acupressure should be BEST for conditions where gate control +
    somatovisceral reflex + vagal tone are the primary therapeutic
    pathways. This aligns with the observed clinical profile (§4.6):
    → PONV: somatovisceral reflex at P6 → vagal → gastric motility ✓
    → Anxiety: gate control → ANS shift → parasympathetic ✓
    → Sleep: CT afferents + auricular vagal → relaxation ✓
    → Chronic pain: would need descending modulation → weaker ✓
    → Organ-specific: would need PROKR2 → unavailable ✓

  🟡 Divergence model: our synthesis from Track A (individual components 🟢)
  🟡 Clinical prediction alignment: consistent but not independently tested
```

### §8.2 — Contraindications and Safety

```
🟢 ACUPRESSURE SAFETY — THE SAFEST MANUAL THERAPY IN TRACK B:

  ABSOLUTE CONTRAINDICATIONS:
    → Open wounds / skin lesions at the treatment point
    → Active skin infection at treatment site
    → Fracture at or near treatment site
    → Deep vein thrombosis at treatment limb (avoid limb pressure)

  RELATIVE CONTRAINDICATIONS:
    → SP6 during pregnancy (traditionally avoided — associated with
      labor induction; contraindicated for BL67 moxibustion/acupressure
      before full term, though evidence is weak)
    → Severe osteoporosis (avoid deep pressure at fragile sites)
    → Anticoagulant therapy (risk of bruising with deep pressure)
    → Over tumors or metastatic sites (avoid direct pressure)

  AURICULAR-SPECIFIC:
    → Adhesive allergy (hypoallergenic tape available)
    → Ear infection / inflammation (do not place seeds)
    → Skin irritation from prolonged seed/pellet placement
    → Seeds occasionally fall into ear canal (rare)

  ADVERSE EVENTS:
    → Essentially ZERO serious adverse events reported in literature
    → Minor: temporary soreness at pressure site, bruising (rare),
      light-headedness (vasovagal, very rare)
    → Auricular: skin irritation from tape (~5-10% of trials),
      seed displacement

  SAFETY COMPARISON:
    B01 acupuncture: rare but possible serious AEs (pneumothorax,
      nerve injury, organ puncture, infection) — estimated 1 in 10,000
      to 1 in 200,000 for serious events
    B03 massage: very safe, occasional transient soreness, rare nerve
      compression with deep techniques
    B02 acupressure: SAFEST — no tissue penetration, no equipment
      risk, self-limiting force (patient controls own pressure)

  SELF-TREATMENT SAFETY ADVANTAGE:
    Because the patient controls their own force, self-acupressure
    is self-limiting: pain prompts reducing pressure. This eliminates
    the practitioner-induced injury risk that exists for B01 and
    (rarely) B03. No licensing requirement → no unregulated practice
    safety concern.

  🟢 Safety profile: derived from published RCTs and systematic reviews
  🟢 Contraindications: standard clinical practice guidelines

## §10 — OPEN QUESTIONS

```
🟡 UNRESOLVED QUESTIONS — PRIORITIES FOR FUTURE RESEARCH:

  Q1. PROKR2 FOR PRESSURE (CRITICAL)
    Liu 2021 (Nature): PROKR2+ sensory neurons in deep fascia/periosteum
    are ESSENTIAL for EA at ST36 → vagal-adrenal anti-inflammatory axis.
    PROKR2 ablation = complete loss of effect. Can surface finger pressure
    at ST36 activate PROKR2+ neurons that sit at periosteal depth?
    → This is the SINGLE MOST IMPORTANT open question for acupressure.
    → If NO: acupressure fundamentally cannot access the vagal-adrenal
      anti-inflammatory pathway at body points (auricular ABVN pathway
      remains available independently)
    → If YES: acupressure's mechanism profile is significantly richer
      than currently attributed
    → Resolution requires: electrophysiological recording from PROKR2+
      neurons during calibrated surface pressure vs needle insertion

  Q2. endocannabinoid system ACTIVATION THRESHOLD FOR ACUPRESSURE
    Light touch massage: no endocannabinoid system change (Lindgren 2015).
    Deep OMT: AEA ↑168% (McPartland 2005).
    Where does acupressure fall? Standard technique ① (30-50N) vs
    deep technique ⑤ (50-80N)? Threshold for clinical endocannabinoid system engagement?
    → Resolution requires: AEA/2-AG measurement during standardized
      acupressure at different pressure levels

  Q3. MAST CELL ACTIVATION BY SURFACE PRESSURE
    Mast cells at acupoints express mechanosensitive channels (TRPV2/4).
    Sodium cromoglycate blocks acupuncture analgesia (proving mast cells
    contribute). Does surface pressure produce sufficient membrane
    deformation for mast cell degranulation?
    → Resolution requires: sodium cromoglycate pre-treatment in
      acupressure analgesia trial (replicating the acupuncture study)

  Q4. DOSE-RESPONSE CURVE
    No systematic study establishes minimum effective pressure, optimal
    pressure, or pressure-response curve for acupressure at any point.
    Force ranges in RCTs (5-80N) are wide and poorly standardized.
    → The most significant methodological gap in the field
    → Resolution requires: multi-arm RCT with calibrated pressure
      delivery device at standardized force levels

  Q5. ADENOSINE RELEASE WITHOUT NEEDLE
    Goldman 2010: 24× adenosine increase from needle rotation.
    Underlying pathway (fibroblast ATP → CD39/CD73 → adenosine) is
    general mechanotransduction. Does sustained surface pressure produce
    measurable adenosine increase? At what magnitude?
    → Resolution requires: microdialysis at acupoint during acupressure
      (same methodology as Goldman 2010 but with pressure instead of needle)

  Q6. HEAD-TO-HEAD ACUPUNCTURE vs ACUPRESSURE
    No adequately powered RCT directly compares acupuncture vs acupressure
    at the same points for the same condition. The field lacks this
    fundamental comparison. The SP6 dysmenorrhea finding (acupressure
    p=0.001 vs acupuncture p=0.371 in different trials) demands a
    direct head-to-head study.
    → Resolution requires: multi-arm RCT: needle vs pressure vs sham
      vs no treatment at identical points for a single condition
    → ATLAS NOTE: SP6 is one of 5 modality-effect relationships
      documented across 520 entries. Optimal modality is POINT-SPECIFIC,
      not universal: PC6 modality-independent, SP6 pressure > needle,
      BL67 moxa-only, HT7 possibly A-beta (De Qi incidental),
      Wrist-Ankle Acupuncture/Korean Hand Therapy
      subcutaneous-only.
      → AP-Mechanism-Summary §9.1 Discovery 6

  Q7. AURICULAR PRESSURE vs ELECTRICAL EQUIVALENCE
    taVNS (electrical at concha) has fMRI-confirmed NTS activation.
    Auricular acupressure (mechanical at concha) uses the SAME nerve
    (ABVN) but: does mechanical pressure produce EQUIVALENT NTS
    activation magnitude? If not, how much lower?
    → Resolution requires: fMRI comparison of taVNS vs auricular
      seed pressure at matched concha locations

  Q8. SELF-TREATMENT ACCURACY
    Self-acupressure compliance is high (92.3% at week 8), but:
    how ACCURATE is self-point-location? What percentage of self-
    treatments miss the intended acupoint? Does wider thumb contact
    area compensate for location imprecision?
    → Resolution requires: motion-capture + pressure-mapping study
      of self-acupressure technique accuracy

  🟡 All questions: derived from evidence gaps identified in §5 + §9
```
