# B06 — Foot Reflexology

> **Position:** Track B file #7 — Phản xạ học bàn chân.
>
> **Core Question:** Does the foot sole contain a functional "map" of the body, where
> stimulating specific zones produces organ-specific therapeutic effects? Or do all
> beneficial effects of foot reflexology arise from non-specific mechanisms (gate control,
> relaxation response, therapeutic context) that any systematic foot massage would produce?
>
> **Evidence Level:** MODERATE quantity (~50-80 RCTs across conditions), LOW-MODERATE quality.
> The critical finding: positive effects vs passive/non-active controls, but largely NULL
> vs sham foot massage → the SPECIFICITY PROBLEM.
>
> **Key Contrast:** B05 Dien Chan works on the face (CN V trigeminal → brainstem → vagal =
> proven neuroanatomical pathway). B06 foot reflexology works on feet (L4-S3 spinal nerves →
> NO direct connection to most organ viscerotomes). Dien Chan has a STRONGER neuroanatomical
> case, despite having ~0 RCTs. Foot reflexology has MORE clinical trials but a WEAKER
> mechanistic basis.
>
> **Track A Foundation:** A01 §4.1 (PNS-therapy mapping), A07 §1.2/§1.6 (dermatome/viscerotome
> maps — foot = L4-S1, organs served = bladder/rectum S2-S4 only), A03 (fascia in foot =
> plantar fascia, thick but not primary therapeutic target).

## §1 — DEFINITION & ORIGIN

### §1.1 — Definition: What Is Foot Reflexology?

```
🟢🟡 FOOT REFLEXOLOGY — DEFINITION:

  Foot reflexology is a manual therapy in which specific ZONES and POINTS
  on the feet — primarily the soles, but also dorsum, medial, and lateral
  surfaces — are stimulated using thumb, finger, and hand pressure techniques,
  based on the claim that these zones "correspond to" and can therapeutically
  influence specific organs, glands, and body parts.

  ┌──────────────────────────────────────────────────────────────────────┐
  │                                                                      │
  │  CORE CLAIM:                                                        │
  │    The foot contains a MINIATURE MAP of the entire body.            │
  │    Stimulating a zone on the foot → therapeutic effect on           │
  │    the corresponding body part/organ.                               │
  │                                                                      │
  │  THE "BODY ON FOOT" LAYOUT:                                         │
  │    → Toes = head, brain, sinuses                                    │
  │    → Ball of foot = chest (lungs, heart, shoulders)                 │
  │    → Upper arch = upper abdomen (stomach, liver, pancreas)          │
  │    → Lower arch = lower abdomen (intestines, kidneys)               │
  │    → Heel = pelvis (sciatic, reproductive organs)                   │
  │    → Medial edge = spine                                            │
  │    → Right foot = right side of body                                │
  │    → Left foot = left side of body                                  │
  │                                                                      │
  │  DISTINGUISHING FEATURES:                                           │
  │    ✓ Non-invasive (no needles, no penetration)                      │
  │    ✓ Manual pressure (thumbs/fingers, some tools)                   │
  │    ✓ Systematic coverage (entire foot in each session)              │
  │    ✓ Zone-specific claim (NOT just "foot massage")                  │
  │    ✓ Typically practitioner-administered (30-60 min sessions)       │
  │    ✓ Self-treatment also practiced                                  │
  │                                                                      │
  │  REFLEXOLOGY ≠ FOOT MASSAGE:                                       │
  │    Practitioners insist reflexology is NOT generic foot massage.     │
  │    The distinction: reflexology targets SPECIFIC zones claimed       │
  │    to correspond to organs, while foot massage addresses the        │
  │    foot itself (muscle tension, circulation, relaxation).            │
  │    Whether this distinction matters therapeutically is the           │
  │    CENTRAL QUESTION of this file (see §5, §9).                     │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘

  🟢 Ernst 2009 (definition framework used in SR)
  🟡 Distinction claim from reflexology professional associations
```

### §1.3 — Traditional Explanations

```
🟡🔴 TRADITIONAL EXPLANATORY MODELS — RECORDED AS DATA:

  ⚠️ These are historical/practitioner explanations.
     NOT endorsed as mechanisms. Analyzed in §5.

  ① FITZGERALD'S ZONE THEORY (1917):
    → Body divided into 10 longitudinal zones (5 per side)
    → Each zone runs continuously from head → toe → finger
    → "Energy" flows through each zone
    → Blockage → disease; pressure → restores flow
    → Pressure at any point in a zone → analgesia/effect
      throughout that zone
    → Framework: quasi-electrical/energy metaphor
    → NOTE: Fitzgerald was an MD who observed real clinical
      effects (pressure analgesia) and created a theory to
      explain them. The analgesia was real; the zone energy
      explanation is unvalidated.

  ② INGHAM'S REFLEX CORRESPONDENCE (1938):
    → Each organ/gland has a "reflex" on the foot sole
    → Stimulating the reflex → influences the corresponding organ
    → "Crystal deposits" (uric acid, calcium) accumulate at
      reflexes corresponding to dysfunctional organs
    → Practitioner can FEEL these deposits (granular texture)
    → Breaking up deposits → restores organ function
    → Framework: mechanical/hydraulic metaphor
    → ⚠️ "Crystal deposits" theory has NO scientific support.
      Anatomical studies do not find organ-specific deposits
      at claimed reflex locations.

  ③ ENERGY FLOW MODEL (modern practitioner variant):
    → Borrowing from TCM qi concept
    → "Vital energy" flows to organs via reflex pathways
    → Reflexology "balances" energy flow
    → Framework: adopted Eastern energy metaphor onto
      Western zone framework
    → Inconsistent: Fitzgerald/Ingham did NOT use qi/meridian
      concepts. This is a later retrofit.

  ④ "NERVE IMPULSE" MODEL (modern practitioner variant):
    → Pressure on reflex zones → nerve impulses → organ response
    → Closer to scientific framing than energy models
    → BUT: does not specify WHICH nerves, WHICH pathways
    → Vague enough to sound scientific without being testable
    → Analyzed vs actual neuroanatomy in §3.4 and §5.2

  OBSERVATION:
    Traditional reflexology has FOUR different explanatory models
    that are mutually inconsistent:
    (a) Zone energy (Fitzgerald)
    (b) Crystal deposits (Ingham)
    (c) Qi/energy flow (Eastern retrofit)
    (d) Nerve impulses (scientific-sounding but vague)
    = No unified traditional theory, unlike TCM (which has
      a coherent if unvalidated system) or chiropractic
      (which has the subluxation theory, also unvalidated
      but internally consistent).

  🟡 Compiled from reflexology training literature
  🔴 "Crystal deposits" theory: no anatomical evidence
```

## §2 — STIMULATION TYPE

### §2.1 — Core Stimulus: Mechanical Pressure on Foot

```
🟢🟡 STIMULUS CHARACTERISTICS:

  MODALITY: Mechanical pressure (manual)
  TOOL: Primarily thumbs and fingers; some traditions use
        wooden sticks, metal probes, or rollers

  PRESSURE PROFILE:
  ┌──────────────────────────────────────────────────────────────────────┐
  │  Compared to other Track B therapies:                                │
  │                                                                      │
  │  B01 Acupuncture:  needle → 600 MPa (extremely focal)              │
  │  B11 Dry Needling:  needle → similar to B01                         │
  │  B04 Deep Tissue:   deep pressure → 100-200 kPa (estimated)        │
  │  B06 REFLEXOLOGY:  thumb pressure → ~75-150 kPa (estimated) ⬅     │
  │  B02 Acupressure:   finger/thumb → ~75 kPa                          │
  │  B05 Dien Chan:     tool on face → ~30-50 kPa (lightest)           │
  │  B03 Massage:       varies widely (effleurage 20 → deep 200 kPa)  │
  │                                                                      │
  │  Foot reflexology applies MODERATE pressure —                        │
  │  heavier than facial work (B05), lighter than deep tissue (B04),   │
  │  comparable to acupressure (B02).                                   │
  │                                                                      │
  │  FOOT SOLE = THICK SKIN:                                            │
  │  → Stratum corneum on sole = thickest on body (up to 1.5mm)       │
  │  → Glabrous (hairless) skin                                         │
  │  → Requires MORE pressure to activate deep mechanoreceptors        │
  │    than thinner skin areas (face, forearm)                          │
  │  → Callus formation further increases threshold                    │
  │  → = Moderate-to-firm pressure is functionally necessary           │
  └──────────────────────────────────────────────────────────────────────┘

  FIBERS ACTIVATED:
    → Aβ mechanoreceptors: YES — primary (touch, pressure)
    → CT afferents: NO — glabrous skin has NO CT afferents
      (CT afferents are in HAIRY skin only)
      = Foot sole CANNOT activate the affective touch pathway
      = Different from general body massage (B03) which CAN
    → Aδ nociceptors: possibly, with firm pressure on tender areas
    → C polymodal: unlikely at normal reflexology pressures

  🟢 Foot sole skin anatomy (Standring 2020, Gray's)
  🟢 CT afferents absent from glabrous skin (McGlone 2014)
  🟡 Pressure estimates from clinical descriptions
```

### §2.2 — Technique Variants

```
🟡 REFLEXOLOGY TECHNIQUES — STANDARDIZED IN TRAINING:

  ① THUMB-WALKING ("Caterpillar Walk") ⭐ — SIGNATURE TECHNIQUE
    → Thumb moves forward in small creeping steps
    → First joint bends and straightens rhythmically
    → Continuous pressure with forward progression
    → Covers zones systematically
    → Creates: rhythmic Aβ stimulation along zone
    → = Most commonly taught and used technique

  ② DIRECT SUSTAINED PRESSURE
    → Thumb/finger held on one point, steady pressure
    → Duration: 5-30 seconds per point
    → Used on: specific "reflex points" where practitioner
      detects tenderness or "congestion"
    → Creates: sustained Aβ → gate control activation
    → = Similar to acupressure point technique (B02)

  ③ HOOK AND BACK-UP
    → Thumb presses in, then pulls back ("hooking" motion)
    → For deep, precise access to small reflex areas
    → Used on: pituitary point (center of great toe pad),
      ileocecal valve (lateral heel area)
    → Creates: brief deep pressure → Aδ possible

  ④ ROTATION ON A POINT
    → Thumb/finger applies pressure while rotating
    → For: breaking up "congestion" (practitioner claim)
    → Creates: combined pressure + shear stimulation

  ⑤ FINGER-WALKING
    → Same as thumb-walking but with index/middle finger
    → Used on: dorsum of foot, lateral/medial surfaces
    → For: areas where thumb access is difficult

  ⑥ KNUCKLE PRESS (some traditions)
    → Proximal interphalangeal joint used for deeper pressure
    → On: plantar surface, particularly arch and heel
    → Creates: deeper pressure than thumb alone

  SESSION STRUCTURE:
    → Duration: 30-60 minutes typical
    → Sequence: usually begins with relaxation techniques
      (general foot massage, ankle rotations)
    → Then: systematic coverage of reflex zones
    → Frequency: weekly for treatment courses,
      monthly for maintenance (practitioner recommendation)
    → Self-treatment: 10-20 minutes daily possible

  🟡 Compiled from reflexology training curricula (IIR, AoR)
```

  │    → Pancreas, duodenum                                              │

  │  HEEL:                                                               │
  │    → Sciatic nerve area                                              │
  │    → Reproductive organs (uterus/prostate: medial heel,             │

  │    → Pelvic region                                                   │
  │                                                                      │
  │  MEDIAL EDGE (great toe → heel):                                    │
  │    → SPINE (cervical → lumbar, head-to-heel correspondence)         │
  │                                                                      │
  │  DORSUM (top of foot):                                               │
  │    → Chest/breast (lymphatics)                                      │
  │    → Upper body lymph drainage                                       │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘

  MAP LOGIC:
    → The body is "projected" onto the foot as if the person is
      sitting down, folded forward, with the soles facing outward
    → Head at toes, spine along medial edge, pelvis at heel
    → Organs roughly in anatomical order top-to-bottom
    → Heart reflex: primarily LEFT foot (anatomical laterality)
    → Liver reflex: primarily RIGHT foot (anatomical laterality)
    → Paired organs (kidneys, lungs): on both feet

  VARIATIONS BETWEEN MAPS:
    → Multiple reflexology maps exist (Ingham, Marquardt,
      Kunz & Kunz, Chinese, Thai)
    → Maps DISAGREE on exact locations of many organ reflexes
    → No standardization exists
    → Similar problem to dermatome map discrepancies (A07 §1.3)
      but WORSE — dermatome maps at least have anatomical basis
    → = Reflexology maps are PRACTITIONER-CREATED, not
      anatomically derived

  🟡 Ingham 1938 (original map)
  🟡 Multiple map variants documented in reflexology training
  ⚠️ No anatomical validation of organ-zone correspondence
```

### §3.2 — Fitzgerald's 10-Zone Theory

```
🟡 ZONE THERAPY — THE THEORETICAL FRAMEWORK:

  William Fitzgerald's 10-ZONE MODEL (1917):

  ┌──────────────────────────────────────────────────────────────────────┐
  │                                                                      │
  │  The body is divided into 10 LONGITUDINAL ZONES:                    │
  │                                                                      │
  │  Zone 1: centerline of body → great toe → thumb                    │
  │  Zone 2: next lateral → 2nd toe → index finger                     │
  │  Zone 3: → 3rd toe → middle finger                                  │
  │  Zone 4: → 4th toe → ring finger                                    │
  │  Zone 5: lateral body → little toe → little finger                  │
  │                                                                      │
  │  LEFT SIDE: Zones 1-5        RIGHT SIDE: Zones 1-5                  │
  │                                                                      │
  │  CLAIM:                                                              │
  │  → Organs in Zone 3 can be influenced by pressure on               │
  │    Zone 3 of the foot (3rd toe area) or hand (middle finger)       │
  │  → Continuous energy pathway from head to extremity                 │
  │  → Similar to meridian concept but SIMPLER (10 zones vs            │
  │    12+ meridians, no complex branching/cycling)                     │
  │                                                                      │
  │  FITZGERALD'S CLINICAL USE:                                         │
  │  → Pressure analgesia (clothes pegs, combs, probes)                │
  │  → For dental procedures, minor ENT surgery                        │
  │  → Used on HANDS primarily, not feet                                │
  │  → Claimed ANALGESIA, not organ healing                             │
  │                                                                      │
  │  EVOLUTION: FITZGERALD → INGHAM                                     │
  │  → Fitzgerald: 10 zones, hands+feet, ANALGESIA focus               │
  │  → Riley: added horizontal zones, expanded mapping                  │
  │  → Ingham: foot-specific, organ HEALING focus, detailed map        │
  │  → = The theory GREW in claims as it passed from MD to             │
  │    physiotherapist to popular practice                               │
  │  → = Scope inflation without corresponding evidence                 │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘

  ASSESSMENT:
    → Fitzgerald's analgesia observations may have been real
      (gate control via intense pressure → Aβ activation)
    → The 10-zone theory has NO anatomical correlate:
      - Body is segmented HORIZONTALLY (dermatomes, A07)
      - NOT vertically (Fitzgerald zones)
      - No nerve pathway runs from great toe → body midline
        → brain in a single continuous tract
    → The vertical zone concept conflicts with known
      neuroanatomy at every level

  🟢 Fitzgerald & Bowers 1917
  🟡 Evolution analysis from historical sources
```

### §4.2 — Condition-Specific Evidence

```
🟢🟡 EVIDENCE BY CONDITION:

  ① ANXIETY AND STRESS:
    Wang 2020 meta-analysis: reflexology reduces anxiety scores
    vs non-active controls (SMD significant).
    Meta-regression: greater total reflexology time → greater
    anxiety reduction (dose-response relationship).
    Evidence level: 🟡 Positive vs passive controls only.
    BUT: consistent with general relaxation response.

  ② SLEEP DISTURBANCES:
    Huang 2021: Hedges' g = -1.37 (large effect).
    → Sleep is the STRONGEST effect in reflexology literature.
    → Consistent finding across multiple studies.
    → Plausible mechanism: relaxation → parasympathetic → sleep.
    Evidence level: 🟡 Strong effect size, but vs passive controls.
    Quality caveat: most studies in hospitalized patients.

  ③ DEPRESSION:
    Wang 2020: reflexology reduces depression scores.
    Effect smaller than for anxiety/sleep.
    Evidence level: 🟡 Moderate. Likely a relaxation effect.

  ④ VITAL SIGNS:
    Jing 2022: SBP -4.62mmHg, DBP -3.32mmHg, HR -4.76 bpm,
    RR -0.77, SpO2 +0.95%.
    All statistically significant.
    → BUT: effects are SHORT-TERM (longest follow-up 8 weeks).
    → Magnitude: clinically modest (4.6mmHg SBP ≈ borderline).
    → Compare: acupuncture SBP reduction ~5-8mmHg in meta-analyses.
    Evidence level: 🟡 Real but modest short-term effects.

  ⑤ CANCER-RELATED SYMPTOMS:
    Klaus 2024: pain (9/15 studies positive), fatigue (6/9 positive),
    QoL (several positive). All vs passive controls.
    → Widely used in palliative/oncology settings.
    → Value may be in supportive care context, not cure.
    → HIGH bias risk (26/29 high RoB).
    Evidence level: 🟡 Supportive care context.

  ⑥ PAIN (General):
    Mixed results across SRs. Lee 2011 (44 studies):
    "less successful" for pain.
    → Chronic pain: insufficient evidence.
    → Acute/postoperative: some positive findings, low quality.
    Evidence level: 🟡 Inconsistent.

  ⑦ CONSTIPATION:
    Limited studies. Some positive results.
    Interesting because bladder/rectum S2-S4 viscerotomes
    DO overlap with foot S1-S2 dermatome — one of the FEW
    zone claims with partial neuroanatomical basis.
    Evidence level: 🔴 Insufficient.

  ⑧ NAUSEA/VOMITING:
    2025 SR: mixed results.
    Compare: P6 acupressure for PONV has Cochrane support (B02).
    No equivalent evidence for foot reflexology.
    Evidence level: 🔴 Insufficient.

  ⑨ MULTIPLE SCLEROSIS:
    Hughes 2009 sham-controlled trial: reflexology and sham
    BOTH improved symptoms equally.
    → = No specific reflexology effect beyond sham massage.
    Evidence level: 🔴 Sham-controlled trial NEGATIVE.

  🟢 Meta-analyses cited above
  🟡 Condition profiles synthesized from multiple SRs

### §9.2 — The Specificity Challenge Explained

```
🟡 WHY REFLEXOLOGY ≠ SHAM IN MOST COMPARISONS:

  THE PROBLEM:
    Reflexology's ONLY unique claim vs general foot massage is
    ZONE SPECIFICITY — stimulating the "liver zone" helps the liver.

  To test this, a trial needs:
    (a) Reflexology on "correct" zones for the condition
    (b) Sham: identical foot massage on "wrong" zones
    (c) Blinded assessors, ideally blinded patients

  WHAT HAPPENS:
    → Both groups receive: same duration, same pressure, same attention
    → Both groups get: gate control, relaxation, context effects
    → The ONLY difference: zone location
    → Result: NO difference between groups

  WHY THIS IS DECISIVE:
    → If zones mattered, correct zones > wrong zones
    → They don't → zones don't matter
    → What remains is: foot massage + therapeutic context
    → = Reflexology = foot massage + narrative

  COUNTER-ARGUMENT FROM REFLEXOLOGISTS:
    → "You can't do sham reflexology because ALL foot zones are
      connected to the body — there is no 'wrong' zone."
    → This argument makes reflexology UNFALSIFIABLE:
      if any foot stimulation "works," then the zone concept
      is meaningless (every zone = every organ?)
    → = Claiming sham is impossible = admitting the zones
      are not specific

  🟡 Analysis of the specificity/falsifiability challenge
```

### §9.4 — What Would Validate Zone-Specific Effects?

```
🟡 RESEARCH DESIGN NEEDED TO SETTLE THE QUESTION:

  A definitive test of reflexology's zone specificity would require:

  ① LARGE ADEQUATELY POWERED RCT (n ≥ 200):
    → Group A: reflexology on "correct" zones for specific condition
    → Group B: sham reflexology on "incorrect" zones (same pressure,
      duration, technique, but different zones)
    → Group C: general foot massage (no zone targeting)
    → Group D: no-treatment control

  ② STANDARDIZED PROTOCOL:
    → Fixed pressure (measured in kPa)
    → Fixed duration (e.g., 30 min)
    → Fixed technique (e.g., thumb-walking only)
    → Trained practitioners following scripted protocol

  ③ BLINDING:
    → Patient blinded (told they're receiving "foot treatment"
      without specifying type)
    → Assessor blinded (outcome measures collected by someone
      who doesn't know group assignment)

  ④ OBJECTIVE OUTCOME MEASURES:
    → Not just subjective scales (VAS, STAI)
    → Physiological: organ-specific biomarkers, imaging
    → Example: if "kidney zone" → renal blood flow (Doppler)
    → Example: if "lung zone" → spirometry measures

  ⑤ HYPOTHESIS:
    → If zones are real: A > B ≈ C > D
    → If zones are not real: A ≈ B ≈ C > D
    → Current evidence pattern: A ≈ B ≈ C > D
    → = Consistent with "zones not real"

  ⑥ MECHANISTIC ADD-ON:
    → fMRI during foot stimulation: does zone-matched stimulation
      produce DIFFERENT brain activation than zone-mismatched?
    → Descamps 2023 already showed: NO difference
    → Larger replication needed

  🟡 Research design proposal based on evidence gaps
```

## §10 — OPEN QUESTIONS

```
🟡🔴 8 OPEN QUESTIONS FOR FUTURE RESEARCH:

  Q1 — ZONE SPECIFICITY [CRITICAL]:
    Does stimulating the "liver zone" on the foot produce any
    measurable effect on the liver that stimulating the "lung zone"
    does not? Current evidence says NO, but larger trials needed.
    If definitively NO → the zone model is empirically dead.
    🔴 Hypothesis: zones are anatomically meaningless scaffolding.

  Q2 — SUDMEIER RENAL BLOOD FLOW [IMPORTANT]:
    Sudmeier 1999 reported increased renal blood flow during
    kidney zone stimulation. This is the SOLE positive specific
    finding in reflexology mechanism literature. Needs rigorous
    replication with proper controls (sham zone, general massage).
    If replicated: which mechanism? (Kidney T10-L1 is at the
    border of foot L4-S3 territory — marginal segmental possibility.)
    🔴 Unconfirmed. Potentially artifact or general hemodynamic.

  Q3 — DOSE-RESPONSE RELATIONSHIP:
    Wang 2020 meta-regression showed: more total reflexology time →
    greater anxiety reduction. This supports a REAL dose-response,
    but does it reflect zone-specific or non-specific (more foot
    massage = more relaxation) effects?
    🟡 Real pattern, ambiguous mechanism.

  Q4 — REFLEXOLOGY vs GENERAL FOOT MASSAGE (HEAD-TO-HEAD):
    Need definitive, well-powered RCT: reflexology with correct zones
    vs general foot massage (same duration/pressure/attention, no zones)
    for specific conditions. Descamps 2023 started this but in
    healthy subjects (10 min, n=30 — likely underpowered for clinical
    populations). Clinical-population replication needed.
    🟡 Key research priority.

  Q5 — SELF-TREATMENT EFFECTIVENESS:
    Does self-administered foot reflexology produce similar effects to
    practitioner-administered? If YES: supports non-specific mechanisms
    (the foot stimulation itself is sufficient). If NO: supports
    contextual/relational mechanisms (practitioner attention matters).
    🟡 Limited self-treatment data.

  Q6 — MECHANORECEPTOR TYPE CONTRIBUTION:
    Which of the 4 foot mechanoreceptor types (SAI, RAI, SAII, RAII)
    contributes most to reflexology effects? Could specific receptor
    targeting (e.g., vibration for RAII) enhance effects? This question
    is about optimizing foot massage, not validating zones.
    🟡 Basic science question, not specific to reflexology.

  Q7 — WHY POSITIVE vs PASSIVE BUT NULL vs SHAM:
    The consistent evidence pattern (reflexology > nothing, but
    reflexology ≈ sham) has a simple explanation (non-specific
    mechanisms), but alternative explanations should be tested:
    → Is ANY touch sufficient? (hand-holding control)
    → Does session DURATION matter? (dose-matching)
    → Does EXPECTATION matter? (expectation manipulation)
    🟡 Important for understanding therapy design, not just reflexology.

  Q8 — CULTURAL VARIANT COMPARISON:
    Does Western (Ingham), TCM (足底按摩), Thai, or Ayurvedic
    (pada abhyanga) foot massage produce different outcomes?
    If YES: technique matters (pressure, depth, duration).
    If NO: all are equivalent → non-specific mechanisms confirmed.
    🟡 Cross-cultural comparison would be informative.
```
