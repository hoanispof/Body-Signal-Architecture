# B13 — Shiatsu

> **Scope:** Shiatsu (指圧, literally "finger pressure") — a Japanese manual therapy
> applying perpendicular sustained pressure along meridian pathways using thumbs,
> fingers, palms, elbows, and knees, delivered as a systematic whole-body protocol
> on a floor mat with the recipient fully clothed.
>
> **Central question:** When Shiatsu applies the SAME TYPES of pressure as B02
> (acupressure) but DEPLOYS them across the whole body in a structured meridian-
> following protocol with diagnostic integration, does this produce different
> mechanisms or just different DELIVERY of the same mechanisms?
>
> **Evidence scale:** ~10 Shiatsu-specific controlled studies (vs B02's ~642 RCTs).
> Only 1 proper RCT (Kobayashi 2019, n=59). Robinson 2011 landmark
> systematic review found 9
> Shiatsu-specific studies total. Evidence quality: POOR to VERY LOW.
>
> **Relationship to B02 (Acupressure):** Shiatsu shares B02's fundamental
> mechanisms but DIFFERS in deployment: whole-body protocol (vs point-focused),
> perpendicular body-weight pressure (vs varied techniques), diagnostic-therapeutic
> integration (vs separate assessment), floor-based practice (vs table/self).
> Cabo et al. 2018 argue these are "Two Different and Distinct Techniques."
>
> **Relationship to B03 (Massage):** Shiatsu shares B03's full-body coverage
> and practitioner-delivered sustained touch, but uses PRESSURE AT SPECIFIC
> POINTS along meridians (not broad-area techniques). Historically, Shiatsu
> derives from Anma (Japanese massage) + acupoint theory.
>
> **Framing:** Shiatsu has TWO competing theoretical frameworks that constitute
> a natural experiment: Namikoshi style (Western anatomy, NO meridian theory)
> vs Masunaga Zen Shiatsu (extended meridians + Kyo/Jitsu energetics).
> Same physical stimulus, different theory → if outcomes are similar, the
> physical stimulus is what matters.
>
> **Track A cross-reference:** 7 of 9 Track A systems engaged at LOW-MODERATE
> level. Profile similar to B02 but with BROADER spatial distribution and
> additional A08 engagement from stretching/rotation components.

## §1 — DEFINITION & ORIGIN

### §1.1 — What Shiatsu Is

```
🟢 PHYSICAL DESCRIPTION:

  Shiatsu is a Japanese manual therapy involving:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  DEFINING FEATURES:                                                     │
  │                                                                         │
  │  ① PERPENDICULAR SUSTAINED PRESSURE                                    │
  │    → Pressure applied straight inward (perpendicular to body surface)   │
  │    → From practitioner's body weight, NOT muscular effort               │
  │    → No rotation, circular motion, or pumping                          │
  │    → Simple, direct, sustained hold at each point (3-7 seconds)        │
  │                                                                         │
  │  ② WHOLE-BODY PROTOCOL                                                 │
  │    → Every session covers the ENTIRE body systematically               │
  │    → Not limited to symptomatic area or selected points                │
  │    → Treatment follows meridian pathways sequentially                  │
  │    → Contrasts with B02's point-specific approach                      │
  │                                                                         │
  │  ③ DIAGNOSTIC-THERAPEUTIC INTEGRATION                                  │
  │    → Assessment occurs DURING treatment, not before                    │
  │    → Practitioner reads tissue response continuously                   │
  │    → Two-hand technique: "mother hand" senses, "working hand" treats   │
  │    → Hara (abdominal) diagnosis guides treatment in Zen Shiatsu        │
  │                                                                         │
  │  ④ FLOOR-BASED PRACTICE                                                │
  │    → Performed on floor mat/futon (not massage table)                  │
  │    → Allows gravity-based pressure from practitioner's body weight     │
  │    → Client fully clothed (no oil, no skin contact)                   │
  │    → Multiple practitioner positions: kneeling, sitting, standing      │
  │                                                                         │
  │  ⑤ TOOLS: thumbs (primary), fingers, palms, elbows, knees             │
  │    → No instruments, oils, or devices                                  │
  │    → Session duration: 60-90 minutes typically                         │
  └──────────────────────────────────────────────────────────────────────────┘

  JAPANESE MINISTRY OF HEALTH DEFINITION (1957):
    "Shiatsu technique refers to the use of fingers and palms of the hands
    to apply pressure to particular sections on the surface of the body
    for the purpose of correcting the imbalances of the body, and for
    maintaining and promoting health. It is also a method contributing
    to the healing of specific illnesses."

  🟢 Physical description: directly observable
  🟢 Ministry definition: official government source

    This split constitutes a NATURAL EXPERIMENT:

      → Uses Western anatomical/physiological framework ONLY
      → Same physical techniques as Masunaga (perpendicular pressure)

      → The PHYSICAL STIMULUS is what matters, not the theory
      → Parallels B01 vs B11 (same needle, different theory → similar

      → Theoretical framework = clinical scaffolding (cf. B06 Ingham map)

## §2 — STIMULATION TYPE

### §2.1 — Pressure Parameters

```
🟢 SHIATSU PRESSURE CHARACTERISTICS:

  ┌──────────────────────────────────────────────────────────────────────────┐
  │  PARAMETER         │ SHIATSU                │ B02 ACUPRESSURE           │
  │────────────────────┼────────────────────────┼──────────────────────────│
  │  Force range       │ 30-80 N (moderate-deep)│ 5-80 N (full range)      │
  │  Primary tool      │ Thumb pad (~4 cm²)     │ Thumb, finger, device    │
  │  Pressure source   │ Body weight (gravity)  │ Muscular effort ± body   │
  │  Direction         │ PERPENDICULAR ONLY     │ Perpendicular, circular, │
  │                    │                        │ press-release, rubbing   │
  │  Duration/point    │ 3-7 sec (sustained)    │ 1-120 sec (variable)     │
  │  Points/session    │ Hundreds (whole body)  │ 4-20 (selected)          │
  │  Session duration  │ 60-90 min              │ 10-30 min (point-focus)  │
  │  Position          │ Floor mat/futon        │ Table, chair, or self    │
  │  Clothing          │ YES (fully clothed)    │ Variable                 │
  │  Oil/lubricant     │ NEVER                  │ Optional                 │
  └──────────────────────────────────────────────────────────────────────────┘

  PERPENDICULAR PRESSURE — THE SHIATSU SIGNATURE:
    Masunaga described ideal Shiatsu pressure as having 3 qualities:
      ① Perpendicular (直角): straight inward, no lateral component
      ② Sustained (持続): maintained for several seconds, no pumping
      ③ Concentrated (集中): focused attention through the contact point

    This is MECHANISTICALLY distinct from B02's circular kneading (rou fa),
    press-release (an-rou), or rubbing (mo fa) techniques:
      → Perpendicular sustained pressure maximizes DEPTH PENETRATION
        for a given surface force
      → No lateral shear component → less superficial tissue displacement
      → Body-weight source → more CONSISTENT force delivery vs muscular
        effort which fatigues

  FIBER RECRUITMENT (same as B02 §2.2):
    → Moderate pressure (30-50N): Aβ mechanoreceptors dominant
      (Ruffini SA-II for sustained, Merkel SA-I, some Meissner)
    → Deep pressure (50-80N): Aβ + some Aδ nociceptive recruitment
    → Through clothing: NO CT afferent activation
      (CT afferents require skin-to-skin contact at 1-10 cm/s)
      → This is a SIGNIFICANT mechanistic difference from B03 massage

  🟢 Pressure parameters: measured in clinical practice
  🟡 Mechanistic comparison with B02: our analysis
```

## §3 — APPLICATION POINTS & AREAS

### §3.1 — Tsubo System

```
🟢 JAPANESE TSUBO (ツボ) CONCEPT:

  "Tsubo" = Japanese term for acupoints/pressure points. Same anatomical
  locations as Chinese acupoints (穴位, xuéwèi) and same meridian framework
  (→ B01 §3.1 for acupoint system, B02 §3.1 for overlap).

  HOWEVER, Shiatsu's relationship to tsubos differs by style:

  NAMIKOSHI: ~660 points based on ANATOMICAL landmarks
    → Points correspond to muscle origins/insertions, nerve passages,
      blood vessel bifurcations, joint spaces
    → NO meridian attribution — points are defined by anatomy
    → Shares many locations with TCM acupoints but uses Western naming

  MASUNAGA: Extended meridian pathways
    → 12 classical meridians EXTENDED to cover head-to-feet bilaterally
    → All meridians originate from Hara (abdominal region)
    → Points are NOT fixed anatomical locations — they are where the
      practitioner FEELS tissue response (reactive points)
    → Similar to Ashi point concept in B01/B02

  SERIZAWA (Tsubo Therapy): Classical 361 acupoints
    → Closest to B02's standard acupressure approach
    → Point-specific rather than meridian-following

  PRACTICAL IMPLICATION:
    In Namikoshi Shiatsu, the practitioner covers 660 points regardless
    of the client's condition. In Zen Shiatsu, the practitioner follows
    meridians selected by Hara diagnosis, pressing wherever tissue
    quality changes. Both cover the WHOLE BODY but via different logic.

  🟢 Tsubo system: established in Japanese medical education
  🟡 Style differences: our comparative analysis
```

## §5 — PROPOSED MECHANISMS

> **Organizing principle:** Shiatsu's mechanisms are FUNDAMENTALLY THE SAME as
> B02's acupressure mechanisms (gate control, somatovisceral reflex, muscle
> tone regulation). The question is NOT "what mechanisms?" but "does DIFFERENT
> DEPLOYMENT produce different effects?" §5 focuses on what changes when B02's
> mechanisms are applied across the whole body in a structured protocol.

### §5.1 — Traditional Explanation

```
🔴 KI/KEIRAKU THEORY — TWO VERSIONS:

  NAMIKOSHI (Western):
    Pressure on specific anatomical structures (muscles, nerves, blood
    vessels, lymph nodes) produces direct physiological responses:
    muscle relaxation, improved circulation, nerve stimulation, pain
    reduction. NO reference to Ki, meridians, or energetic concepts.
    → This is NOT a traditional explanation — it IS the Western
      physiological framework, applied to Japanese body landmarks.

  MASUNAGA (Zen Shiatsu):
    Ki (気) flows through 12 Keiraku (経絡, meridians). Disease =
    Kyo (虚, depletion) or Jitsu (実, excess) in one or more meridians.
    Treatment: sustained pressure transfers Ki from Jitsu areas to Kyo
    areas, restoring balance. Two-hand technique: "mother hand" at Kyo
    point draws Ki, "working hand" disperses Jitsu.

    Masunaga's EXTENDED MERIDIANS differ from classical TCM meridians:
      → Each meridian runs from head to feet (bilateral)
      → All originate from Hara (abdominal center)
      → Pathways do NOT match classical TCM meridian charts
      → Masunaga's extensions are UNVALIDATED — no anatomical or
        physiological basis distinct from classical TCM meridians
        (which themselves have limited validation, A09 §1-2)

  THE PARADOX:
    Namikoshi deliberately stripped meridian theory to gain legitimacy.
    Masunaga deliberately reintegrated and expanded it.
    BOTH are called "Shiatsu." BOTH use perpendicular sustained pressure.
    The physical stimulus is IDENTICAL. The theoretical framework is
    OPPOSED. This makes the theoretical framework unlikely to be the
    mechanism — unless the framework changes HOW the practitioner
    applies pressure (point selection, sequence, duration, attention).

  🔴 Ki/Keiraku theory: traditional framework, not mechanism
  🟡 Paradox analysis: our synthesis
```

### §5.3 — Framework Hypothesis

```
🔴 WHOLE-BODY PROTOCOL DEPLOYMENT MODEL:

  Shiatsu and B02 acupressure activate FUNDAMENTALLY THE SAME mechanisms.
  The difference is in DEPLOYMENT, not in mechanism.

  ┌──────────────────────────────────────────────────────────────────────────┐
  │                                                                         │
  │  B02 ACUPRESSURE:          │  B13 SHIATSU:                             │

  │  → 30-120 sec/point        │  → 3-7 sec/point                         │
  │  → HIGH per-point dose     │  → LOW per-point dose                    │
  │  → Point-specific effect   │  → Whole-body coverage                   │
  │  → Self-admin possible     │  → Practitioner-only                     │
  │  → 10-30 min sessions      │  → 60-90 min sessions                    │

  │                             │                                           │

    Same mechanisms + different deployment → different CLINICAL PROFILE.
    → B02's "rifle" approach: more effective for TARGETED conditions
      (P6/PONV, specific acupoint prescriptions)
    → B13's "shotgun" approach: more effective for SYSTEMIC conditions
      (general well-being, stress, fatigue, constitutional treatment)

    This would explain why:
    → B02 has strong evidence for SPECIFIC conditions (nausea, labor pain)
    → B13's clinical profile skews toward GENERAL well-being (Long 2008)

    → Clothing barrier removes CT afferents — a REAL mechanistic loss
    → Floor-based position changes gravitational dynamics
    → Longer sessions may enhance cumulative relaxation
    → Practitioner-only delivery loses B02's self-treatment advantage

  UNRESOLVED: Does deployment difference produce MEASURABLY different
  outcomes, or is it the same effect packaged differently? No head-to-head
  Shiatsu vs acupressure RCT exists.
