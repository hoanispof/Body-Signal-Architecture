# A05 — Neuroimmune Interface

> **Core insight — Neuroimmune Bidirectional Communication Principle:**
> The nervous and immune systems are NOT independent — they form a unified
> BIDIRECTIONAL communication network. Sensory neurons (nociceptors) are not
> passive damage reporters: they actively REGULATE immune cell behavior through
> neuropeptides (CGRP, Substance P). Immune cells are not autonomous: they are
> regulated by vagal (cholinergic anti-inflammatory pathway) AND sympathetic
> (β2-adrenergic) neural input. Cytokines released by immune cells directly
> modulate neural excitability → sensitization or resolution.
>
> Body-based therapies work by modulating BOTH directions of this communication:
> they activate sensory neurons that influence immune function (bottom-up),
> AND they engage autonomic pathways that regulate systemic inflammation (top-down).
> At acupuncture points, this interface is enriched: higher mast cell density,
> concentrated nerve endings, and fascial mechanotransduction create privileged
> sites for neuroimmune modulation.
>
> **Why this file matters:**
> A01 established neural signal pathways. A02 established the autonomic bridge
> including the cholinergic anti-inflammatory pathway. A03 showed fascial
> mechanotransduction and immune cells in fascia. A08 documented the inflammatory
> milieu at trigger points (Shah 2008: pH 4.7, cytokines, neuropeptides).
> This file INTEGRATES these findings into the complete neuroimmune picture:
> HOW neural and immune systems talk to each other, and HOW body therapies
> leverage this conversation for therapeutic benefit.

### §1.2 — Neuropeptides: The Neuroimmune Messengers

```
🟢 NEUROPEPTIDES — MOLECULES THAT BRIDGE NERVE AND IMMUNE:

  Sensory neurons synthesize and release neuropeptides from their
  peripheral terminals. These peptides act DIRECTLY on immune cells.

  ┌──────────────┬──────────────────────────────────────────────────────┐
  │ Neuropeptide │ Source & Immune Effects                              │
  ├──────────────┼──────────────────────────────────────────────────────┤
  │ CGRP ⭐⭐    │ Source: C fibers, Aδ nociceptors (DRG neurons)      │
  │ (Calcitonin  │ Receptor: RAMP1/CLR complex on immune cells         │
  │ Gene-Related │ Effects on macrophages:                              │
  │ Peptide)     │   → Suppresses antigen presentation                 │
  │              │   → Inhibits pro-inflammatory cytokines (TNF-α)     │
  │              │   → Enhances IL-10 secretion via cAMP/PKA           │
  │              │   → Promotes M2 (pro-repair) polarization           │
  │              │ Effects on neutrophils:                              │
  │              │   → Inhibits recruitment via RAMP1                   │
  │              │   → Promotes apoptosis                               │
  │              │   → Enhances efferocytosis (clearance of dead cells)│
  │              │ Effects on dendritic cells:                          │
  │              │   → Suppresses IL-12 production                     │
  │              │   → Inhibits NF-κB → anti-inflammatory              │
  │              │ Vascular: POTENT vasodilator (neurogenic flare)      │
  │              │ Wound healing: promotes tissue repair (Nature 2024)  │
  │              │ DUAL ROLE: immunosuppressive in infection, but       │
  │              │   pro-healing in tissue repair                       │
  ├──────────────┼──────────────────────────────────────────────────────┤
  │ SUBSTANCE P  │ Source: C fibers (polymodal nociceptors)             │
  │ (SP) ⭐⭐    │ Receptor: NK1R (neurokinin-1) on immune cells       │
  │              │ Effects: predominantly PRO-INFLAMMATORY              │
  │              │   → Activates mast cells → degranulation             │
  │              │   → Stimulates macrophage TNF-α, IL-1β production   │
  │              │   → Enhances T cell proliferation                    │
  │              │   → Promotes dendritic cell maturation               │
  │              │   → Increases vascular permeability (plasma leak)    │
  │              │ Creates POSITIVE FEEDBACK: SP → mast cell tryptase  │
  │              │   → PAR-2 on nerve terminal → more SP release       │
  │              │ = Self-amplifying neuroinflammatory loop ⭐          │
  ├──────────────┼──────────────────────────────────────────────────────┤
  │ VIP          │ Source: parasympathetic neurons, some sensory        │
  │ (Vasoactive  │ Receptor: VPAC1, VPAC2 on immune cells              │
  │ Intestinal   │ Effects: ANTI-INFLAMMATORY                          │
  │ Peptide)     │   → Inhibits macrophage TNF-α, IL-6, IL-12         │
  │              │   → Promotes Treg differentiation                    │
  │              │   → Suppresses Th1/Th17 responses                   │
  │              │   → Vasodilator (GI blood flow)                      │
  ├──────────────┼──────────────────────────────────────────────────────┤
  │ NPY          │ Source: sympathetic postganglionic neurons           │
  │ (Neuropeptide│ Receptor: Y1-Y5 on immune cells                     │
  │ Y)           │ Effects: CONTEXT-DEPENDENT                          │
  │              │   → Can be pro- or anti-inflammatory                 │
  │              │   → Modulates macrophage cytokine production         │
  │              │   → Affects T cell differentiation                   │
  │              │ Co-released with NE from sympathetic terminals       │
  ├──────────────┼──────────────────────────────────────────────────────┤
  │ Galanin      │ Source: DRG neurons, CNS                             │
  │              │ Effects: anti-nociceptive, anti-inflammatory         │
  │              │   → Upregulated after nerve injury                   │
  │              │   → Inhibits nociceptive transmission                │
  └──────────────┴──────────────────────────────────────────────────────┘

  ⭐ CGRP vs SP = OPPOSING immune modulators from the SAME neuron:
    C fiber nociceptors co-express BOTH CGRP and SP
    → SP: pro-inflammatory, recruits immune cells, amplifies inflammation
    → CGRP: anti-inflammatory on most immune cells, promotes repair
    → The RATIO and CONTEXT determine the net effect
    → Acute injury → SP-dominant → immune recruitment (protective)
    → Resolution phase → CGRP-dominant → immune suppression + repair

  🟢 Chiu et al. 2012 (Nature: nociceptors and immunity)
  🟢 Lu et al. 2024 (Nature: CGRP promotes tissue healing)
  🟢 Iyengar et al. 2017 (CGRP and immune system review)
  🟢 O'Connor et al. 2004 (substance P and immune function)
```

```

```

  │    → Adjacent to nerve endings (see §1.3)                        │

  │                                                                   │
  │  DERMAL MACROPHAGES:                                              │
  │    → Phagocytosis, tissue repair, antigen presentation            │

  │                                                                   │
  │  SENSORY NERVE ENDINGS:                                           │
  │    → Dense innervation: ~200 nerve fibers per cm²                │
  │    → Free nerve endings penetrate to dermal-epidermal junction   │
  │    → Release CGRP, SP upon activation                             │
  │    → = Every point on skin surface is a neuroimmune interface    │
  │                                                                   │

    → Keratinocytes (cytokine producers)
    → Langerhans cells (antigen presenters)
    → T cells (effectors, both resident and recruited)
    → Dermal dendritic cells
    → Endothelial cells (leukocyte trafficking)
    → = Skin is an IMMUNOLOGICALLY ACTIVE ORGAN

  ⭐ THERAPY IMPLICATION:
    Every needle insertion or pressure application engages
    the ENTIRE cutaneous neuroimmune apparatus:
    → Nerve endings (CGRP, SP release)
    → Mast cells (degranulation)
    → Keratinocytes (cytokine + antimicrobial peptide release)
    → Langerhans cells (immune modulation)
    → Local vasculature (inflammatory mediator trafficking)

  🟢 Streilein 1983 (SALT concept)
  🟢 Roosterman et al. 2006 (neuronal control of skin function)

## §2 — FUNCTION

### §2.1 — Neurogenic Inflammation: The Local Neuroimmune Response

```
🟢 NEUROGENIC INFLAMMATION — NERVE-DRIVEN IMMUNE ACTIVATION:

  DISTINCT from classical inflammation (immune cell-initiated).
  Neurogenic inflammation is INITIATED by sensory neurons.

  MECHANISM (axon reflex pathway — builds on A01 §3.4):

  ┌──────────────────────────────────────────────────────────────────┐
  │                                                                   │
  │  STIMULUS (needle, pressure, heat, tissue damage)                 │
  │           ↓                                                      │
  │  C fiber nociceptor activation                                    │
  │           ↓                                                      │
  │  Action potential travels:                                        │
  │    ORTHODROMIC → spinal cord (pain signal)                       │
  │    ANTIDROMIC → other branches of SAME neuron (axon reflex)      │
  │           ↓                                                      │
  │  Peripheral branches release neuropeptides:                       │
  │                                                                   │
  │    CGRP ──→ Arteriolar vasodilation ──→ FLARE (redness)          │
  │             Duration: minutes to hours                            │
  │             Mechanism: direct smooth muscle relaxation via         │
  │             CGRP receptor (CLR/RAMP1) + NO release                │
  │                                                                   │
  │    SP ────→ Venular permeability ↑ ──→ EDEMA (swelling)          │
  │             Plasma protein extravasation                          │
  │             Mechanism: NK1R on endothelial cells                  │
  │                                                                   │
  │    SP ────→ Mast cell degranulation ──→ HISTAMINE release        │
  │             → further vasodilation + immune cell recruitment      │
  │             Mechanism: MRGPRX2 receptor on mast cells             │
  │                                                                   │
  │  RESULT: "Triple response of Lewis" (1927):                       │
  │    ① Local redness (vasodilation)                                 │

### §2.2 — Nociceptor Immune Regulation: Neurons as Immune Controllers

```
