## §1 — PHYSICAL ARCHITECTURE

### §1.1 — Overview: PNS = Everything Outside Brain + Spinal Cord

```
🟢 PNS = ALL NEURAL TISSUE OUTSIDE THE CNS:

  The Peripheral Nervous System includes:
    → ALL nerves branching from brain (cranial) and spinal cord (spinal)
    → ALL sensory receptors in skin, muscle, joints, organs
    → ALL motor nerve endings (neuromuscular junctions)
    → Ganglia (clusters of neuron cell bodies outside CNS)

  2 MAJOR FUNCTIONAL DIVISIONS:
  ┌───────────────────────────────────────────────────────────┐
  │  SOMATIC NERVOUS SYSTEM                                    │
  │    Sensory: skin, muscle, joint → CNS (conscious)          │
  │    Motor: CNS → skeletal muscle (voluntary)                │
  │    = "Interface with external world"                       │
  ├───────────────────────────────────────────────────────────┤
  │  AUTONOMIC NERVOUS SYSTEM (ANS)                            │
  │    Sensory: viscera, blood vessels → CNS (mostly unconscious)│
  │    Motor: CNS → smooth muscle, cardiac, glands              │
  │    Sympathetic + Parasympathetic + Enteric                  │
  │    = "Internal regulation" → detail in A02                  │
  └───────────────────────────────────────────────────────────┘

  THIS FILE focuses on: somatic sensory pathways + receptor systems +
    reflex mechanisms + local tissue responses.
  ANS detail → A02-Autonomic-Nervous-System.md

  🟢 Standring 2020 (Gray's Anatomy, 42nd ed.)
```

### §1.2 — Spinal Nerves: 31 Pairs

```
🟢 SPINAL NERVES — SEGMENTAL ORGANIZATION:

  31 pairs, each exits between adjacent vertebrae:
  ┌──────────────────────────────────────────────────┐
  │  Cervical:     C1-C8   (8 pairs)  — neck, arms  │
  │  Thoracic:     T1-T12  (12 pairs) — trunk        │
  │  Lumbar:       L1-L5   (5 pairs)  — lower back   │
  │  Sacral:       S1-S5   (5 pairs)  — pelvis, legs │
  │  Coccygeal:    Co1     (1 pair)   — tailbone      │
  └──────────────────────────────────────────────────┘

  EACH spinal nerve = MIXED:
    → Dorsal root = SENSORY (afferent) — carries signals TO spinal cord
    → Ventral root = MOTOR (efferent) — carries signals FROM spinal cord
    → Dorsal root ganglion (DRG) = cell bodies of sensory neurons
      ⭐ DRG neurons are THE primary sensory transducers —
         every touch, pain, temperature signal starts HERE

  DERMATOME = skin area served by ONE spinal nerve:
    → Each dermatome maps to a specific spinal segment
    → Overlap ~50% between adjacent dermatomes
    → Clinical importance: dermatome testing reveals which nerve is affected
    → Therapy importance: dermatome maps explain WHY stimulation at one
      skin area affects specific organs (viscerosomatic convergence, §3.5)

  🟢 Standring 2020. 🟢 Foerster 1933 (dermatome mapping, foundational).
```

  │     │                   │ face + mouth. Motor: mastication.          │
  │     │                   │ → KEY for diện chẩn, facial reflexology    │
  │     │                   │ → Projects to vagal nucleus → parasympathetic│

  ⭐ CN V (Trigeminal): sensory innervation of ENTIRE face
    → 3 branches: V1 (ophthalmic), V2 (maxillary), V3 (mandibular)
    → Trigeminal projects to dorsal motor nucleus of vagus

    → Auricular branch (Arnold's nerve) innervates ear concha
    → Ear acupuncture at concha → vagus activation → HR down, BP down

    🟢 Peuker & Filler 2002 (auricular vagal innervation)
    🟢 Frangos et al. 2015 (auricular stimulation → vagal activation, fMRI)

### §1.4 — Sensory Receptor Types

```
🟢 SENSORY RECEPTORS — BODY-DOMAIN INTERFACE:

  Classified by stimulus modality AND by structural complexity:

  ┌──────────────────────────────────────────────────────────────────────┐
  │                    MECHANORECEPTORS (pressure, vibration, stretch)   │
  ├──────────────────┬───────────────────────────────────────────────────┤
  │ Merkel cells     │ Light touch, texture. Slowly adapting (SA I).     │
  │ (Type I)         │ HIGH spatial resolution. Fingertips dense.        │
  │                  │ Sustained pressure → sustained signal.            │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Meissner         │ Light touch, low-frequency vibration (10-50 Hz). │
  │ corpuscles       │ Rapidly adapting (RA I). Detect onset/offset.     │
  │                  │ Fingertips, lips — glabrous (hairless) skin.      │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Ruffini endings  │ Skin stretch, sustained pressure. SA II.          │
  │                  │ Joint position. Deeper dermis.                    │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Pacinian         │ Deep pressure, high-frequency vibration           │
  │ corpuscles       │ (100-300 Hz). RA II. Very rapidly adapting.       │
  │                  │ Deep dermis, joint capsules, periosteum.          │
  └──────────────────┴───────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │                    NOCICEPTORS (pain/damage detection)               │
  ├──────────────────┬───────────────────────────────────────────────────┤
  │ Aδ mechano-      │ Sharp, well-localized pain. Fast (5-30 m/s).     │
  │ nociceptors      │ High-threshold mechanical stimuli.                │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Aδ mechano-      │ Respond to both mechanical AND heat (>43°C).     │
  │ thermal          │ Fast first-pain signal.                           │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ C polymodal      │ Respond to mechanical, thermal, AND chemical.     │
  │ nociceptors      │ Slow (0.5-2 m/s). Dull, diffuse, burning pain.   │
  │                  │ ALSO release SP + CGRP → neurogenic inflammation │
  │                  │ (axon reflex, §3.4)                              │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Silent           │ Normally unresponsive. ACTIVATED by inflammation. │
  │ nociceptors      │ Become active in peripheral sensitization (§3.6).│
  └──────────────────┴───────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │                    THERMORECEPTORS (temperature)                     │
  ├──────────────────┬───────────────────────────────────────────────────┤
  │ Warm receptors   │ 30-45°C range. TRPV3, TRPV4 channels.            │
  │ (C fibers)       │ Unmyelinated, slow.                              │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Cold receptors   │ 10-35°C range. TRPM8 channels.                   │
  │ (Aδ fibers)      │ Thinly myelinated, moderate speed.               │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Noxious heat     │ >43°C. TRPV1 channel ("capsaicin receptor").     │
  │                  │ Pain threshold = tissue damage threshold.         │
  │                  │ → Relevant to moxibustion (B08)                  │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Noxious cold     │ <15°C. TRPA1 channel.                            │
  │                  │ → Relevant to cryotherapy                        │
  └──────────────────┴───────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │                    PROPRIOCEPTORS (body position)                    │
  ├──────────────────┬───────────────────────────────────────────────────┤
  │ Muscle spindles  │ Muscle length + rate of change. Intrafusal fibers.│
  │                  │ Stretch reflex (monosynaptic). Ia afferents.      │
  │                  │ → Critical for chiropractic, massage response    │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Golgi tendon     │ Muscle tension (force). Located at muscle-tendon  │
  │ organs           │ junction. Ib afferents. Protective inhibition.    │
  │                  │ → Activated in deep tissue massage, stretching   │
  ├──────────────────┼───────────────────────────────────────────────────┤
  │ Joint receptors  │ Joint position, movement. Ruffini-like + Pacinian.│
  │                  │ → Activated in chiropractic manipulation         │
  └──────────────────┴───────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │              CT AFFERENTS — AFFECTIVE TOUCH SYSTEM ⭐                │
  ├──────────────────┬───────────────────────────────────────────────────┤
  │ C-Tactile (CT)   │ Unmyelinated C fibers, SEPARATE from nociceptors.│

  │                  │ Optimal: 1-10 cm/s velocity.                     │
  │                  │ Inverted U-shaped response curve.                 │

  │         │           │ myelinated│ m/s      │ Temperature, itch.      │
  │         │           │           │          │ Polymodal nociceptors.  │
  │         │           │           │          │ ⭐ CT afferents (touch) │
  │         │           │           │          │ ⭐ Release SP + CGRP    │
  │         │           │           │          │   (axon reflex, §3.4)  │

  THERAPY IMPLICATION — FIBER TYPE DETERMINES WHAT THERAPY ACTIVATES:
    Gentle massage (1-10 cm/s) → CT afferents (C fiber) → pleasant
    Moderate pressure        → Aβ (touch) → gate control → pain reduction
    Deep pressure / needling → Aδ + C nociceptors → pain signal →
                               BUT also → endorphin release + axon reflex

    Aβ touch (30-70 m/s) → arrives at spinal cord BEFORE
    C pain (0.5-2 m/s) → arrives AFTER

    = Basis of rubbing an injury to reduce pain

## §2 — FUNCTION

### §2.1 — Sensory Function (Afferent)

```
🟢 SENSORY: BODY → CNS (afferent direction):

  The PNS continuously monitors:
    ① External environment — touch, temperature, pain, pressure
    ② Body position — proprioception (muscle length, joint angle, force)
    ③ Internal state — visceral signals via vagus + spinal visceral afferents

  SIGNAL FLOW:
    Stimulus → receptor activation → transduction (mechanical/thermal/chemical
    → electrical signal) → action potential → nerve fiber → dorsal root
    ganglion → spinal cord dorsal horn (or brainstem for cranial nerves)

  RECEPTOR ADAPTATION — KEY FOR THERAPY:
    Rapidly adapting (RA): respond to CHANGE only (onset/offset)
      → Meissner, Pacinian — detect movement, vibration
      → Habituate quickly — explains why constant pressure stops "feeling"
    Slowly adapting (SA): respond to SUSTAINED stimulus
      → Merkel, Ruffini — detect texture, stretch
      → Maintain signal — explains why sustained pressure in acupressure
        continues to produce effect

  🟢 Gardner & Johnson 2013 (receptor adaptation mechanisms)
```

### §2.2 — Motor Function (Efferent)

```
🟢 MOTOR: CNS → BODY (efferent direction):

  SOMATIC MOTOR:
    → α-motor neurons → skeletal muscle contraction (voluntary)
    → γ-motor neurons → muscle spindle sensitivity adjustment
    → Direct pathway: cortex → spinal cord → muscle

  AUTONOMIC MOTOR:
    → Sympathetic + parasympathetic → smooth muscle, cardiac, glands
    → 2-neuron chain (preganglionic → ganglionic → target)
    → Detail in A02

  MOTOR RELEVANCE TO THERAPY:
    → Muscle tension/spasm = motor neuron overactivity
    → Massage/manipulation → afferent input → reflex modulation of
      motor output → muscle relaxation (reciprocal inhibition)
    → Trigger points (A08) = sustained motor unit contraction
      → needling/pressure → interrupts contraction cycle
```

### §2.3 — Reflex Function (Protection)

```
🟢 REFLEXES: SPINAL PROCESSING WITHOUT BRAIN INVOLVEMENT:

  Reflex arc = sensory → integration (spinal cord) → motor response
  ⭐ NO BRAIN REQUIRED → fastest response possible

  MONOSYNAPTIC (2 neurons, 1 synapse):
    → Stretch reflex (knee-jerk / patellar)
    → Ia afferent (muscle spindle) → α-motor neuron → same muscle contracts
    → Speed: ~50ms total circuit
    → Clinical: tests spinal segment integrity
    → Therapy: chiropractic adjustment may reset stretch reflex threshold

  POLYSYNAPTIC (3+ neurons, 2+ synapses):
    → Withdrawal reflex (flexor reflex)
    → Nociceptor → interneurons → flexor motor neurons (excite)
                               → extensor motor neurons (inhibit)
    → + Crossed-extensor reflex (opposite limb extends for balance)
    → Speed: ~100-200ms (more synapses = more time)

  VISCEROSOMATIC REFLEX ⭐:
    → Visceral organ disease → spinal segment → somatic output
    → Example: heart attack → left arm/jaw pain (T1-T4 convergence)
    → Example: gallbladder → right shoulder pain (C3-C5 phrenic nerve)
    → = Bridge between organ disease and body surface symptoms
    → = WHY body surface stimulation (acupuncture, massage) CAN affect organs
      (the pathway goes BOTH directions: somato-visceral reflex)

  SOMATOVISCERAL REFLEX ⭐⭐:
    → Body surface stimulation → spinal segment → visceral organ effect
    → Somatic afferent → interneuron → preganglionic autonomic neuron
      → organ response
    → = The REVERSE pathway — skin stimulation → organ function change
    → = FOUNDATIONAL mechanism for acupuncture/acupressure organ effects
    → 🟢 Sato et al. 1997 (somatovisceral reflexes — monograph)
    → 🟢 Budgell 2000 (spinal reflex, chiropractic)

  🟢 Kandel et al. 2021 (Principles of Neural Science, 6th ed.)
```

## §3 — PATHWAYS

### §3.1 — Ascending Sensory Pathways

```
🟢 SENSORY SIGNALS — 3 MAIN ASCENDING PATHWAYS:

  ① DORSAL COLUMN–MEDIAL LEMNISCAL (DCML):
    → Fine touch, vibration, proprioception
    → Aβ + Ia fibers → dorsal columns → medulla → thalamus → S1 cortex
    → FAST, precise, well-localized
    → Ipsilateral until medulla, then crosses
    → = "Discriminative touch" pathway
    → Activated by: massage, acupressure, light touch

  ② SPINOTHALAMIC TRACT (anterolateral system):
    → Pain, temperature, crude touch
    → Aδ + C fibers → dorsal horn → CROSS at spinal level → thalamus
    → Further divided:
      Lateral spinothalamic: pain + temperature
      Anterior spinothalamic: crude touch + pressure
    → = "Pain and temperature" pathway
    → Activated by: needling, heat therapy, cold therapy

  ③ SPINORETICULAR + SPINOMESENCEPHALIC:
    → Diffuse pain, arousal, emotional response to pain
    → C fibers → reticular formation → PAG → thalamus
    → = "Affective-motivational" pain pathway
    → Connects to descending inhibition (endorphin system)
    → Activated by: deep needling → PAG → endorphin release

  🟢 Willis & Coggeshall 2004 (Sensory Mechanisms of the Spinal Cord)
```

### §3.2 — Descending Modulation Pathways

```
🟢🟡 DESCENDING PAIN MODULATION — BRAIN → SPINAL CORD:

  The brain does NOT passively receive pain — it ACTIVELY modulates:

  PAG (Periaqueductal Gray) → RVM (Rostral Ventromedial Medulla) → Dorsal Horn:
    → PAG activation → releases enkephalin → RVM releases serotonin
      → dorsal horn inhibitory interneurons → BLOCK pain transmission
    → = Endogenous opioid system
    → = WHY intense exercise, acupuncture, stress → pain reduction

  DESCENDING INHIBITORY PATHWAYS:
    ① Opioidergic: PAG → RVM → dorsal horn (enkephalin, β-endorphin)
    ② Serotonergic: raphe nuclei → dorsal horn (5-HT)
    ③ Noradrenergic: locus coeruleus → dorsal horn (NE)

  THERAPY ACTIVATION OF DESCENDING MODULATION:
    → Acupuncture (Aδ stimulation) → PAG → endorphin release
    → 🟢 Han 2004: electroacupuncture at different frequencies activates
      different opioid peptides:
      2 Hz → β-endorphin + enkephalin
      100 Hz → dynorphin
    → 🟢 Pomeranz & Chiu 1976: acupuncture analgesia blocked by naloxone
      = PROOF that opioid system is involved

  🟢 Basbaum & Fields 1984 (descending modulation review)
  🟢 Millan 2002 (descending control of pain — comprehensive)
```

### §3.3 — Gate Control Theory (Melzack & Wall 1965)

```
🟢 GATE CONTROL — THE FOUNDATIONAL THEORY FOR BODY-BASED PAIN RELIEF:

  CORE MECHANISM:
    In the dorsal horn (substantia gelatinosa, lamina II):
    → Large Aβ fibers (touch/pressure) → ACTIVATE inhibitory interneurons
      → CLOSE the "gate" → BLOCK pain transmission to brain
    → Small Aδ/C fibers (pain) → INHIBIT inhibitory interneurons
      → OPEN the gate → ALLOW pain transmission

  SIMPLIFIED:
    Touch/pressure (Aβ) → CLOSES gate → reduces pain
    Pain signals (C) → OPENS gate → increases pain
    BOTH converge at dorsal horn → competitive interaction

  DIAGRAM:
  ┌─────────────────────────────────────────────────────┐
  │  Aβ fiber (touch) ──→ (+) Inhibitory interneuron   │
  │                              ↓ (inhibits)           │
  │  C fiber (pain) ───→ (-) Inhibitory interneuron     │
  │                              ↓                      │
  │                     Transmission neuron (T cell)     │
  │                              ↓                      │
  │                     → To brain (pain perception)     │
  │                                                      │
  │  Aβ active → gate CLOSED → T cell inhibited → less pain │
  │  C active → gate OPEN → T cell active → more pain     │
  │  BOTH active → competition → outcome depends on ratio │
  └─────────────────────────────────────────────────────┘

  WHY THIS MATTERS FOR EVERY BODY-BASED THERAPY:
    → Massage → Aβ activation → closes gate → pain reduction
    → Acupressure → sustained Aβ + some Aδ → gate modulation
    → TENS (transcutaneous electrical nerve stimulation) → Aβ → gate
    → Rubbing a bruise → Aβ > C → gate closes → less pain
    → Cupping (suction) → broad Aβ activation → gate

  LIMITATIONS (modern understanding):
    → Original model was simplified — actual dorsal horn circuitry
      is more complex (multiple interneuron types, glial involvement)
    → Gate control alone does NOT explain:
      - Long-lasting effects (hours/days after treatment)
      - Segmental vs systemic effects
      - Emotional component of pain
    → Must combine with: descending modulation (§3.2),
      neurogenic inflammation (§3.4), central sensitization (§3.6)

  🟢 Melzack & Wall 1965 (Science — original paper, ~10,000+ citations)
  🟢 Moayedi & Davis 2013 (gate control theory update)
```

### §3.4 — Axon Reflex: Local Tissue Response WITHOUT CNS

```
🟢 AXON REFLEX — THE "LOCAL THERAPY EFFECT" MECHANISM:

  WHAT IT IS:
    A sensory nerve ending branches in tissue. Stimulation at one branch
    → action potential travels ANTIDROMICALLY (backwards) along the axon
    → reaches OTHER branches of the SAME neuron
    → releases neuropeptides from those branches
    → LOCAL tissue effect WITHOUT any signal reaching the spinal cord or brain

  MECHANISM:
  ┌───────────────────────────────────────────────────────────────────┐
  │                                                                   │
  │  Needle/pressure at point A                                       │
  │       ↓                                                           │
  │  C fiber activation → action potential travels                    │
  │       ↓ (orthodromic → to spinal cord)                           │
  │       + (antidromic → backwards to other branches)                │
  │       ↓                                                           │
  │  Adjacent branches release:                                       │
  │    → CGRP (Calcitonin Gene-Related Peptide) → VASODILATION        │
  │    → Substance P → PLASMA EXTRAVASATION + mast cell degranulation │
  │    → ATP → purinergic signaling                                   │
  │       ↓                                                           │
  │  LOCAL EFFECTS (neurogenic inflammation):                         │
  │    → Vasodilation → increased blood flow ("flare response")       │
  │    → Plasma extravasation → edema (local swelling)                │
  │    → Mast cell activation → histamine release                     │
  │    → Immune cell recruitment                                      │
  │    → Tissue repair factors released                               │
  │                                                                   │
  │  = The "REDNESS AROUND THE NEEDLE" = axon reflex in action        │

### §3.5 — Referred Pain: Viscerosomatic Convergence

```
🟢 REFERRED PAIN — WHY ORGAN PROBLEMS SHOW UP ON THE SKIN:

  MECHANISM (Convergence-Projection Theory):
    Visceral afferent (from organ) + somatic afferent (from skin/muscle)
    → CONVERGE on the SAME second-order neuron in the dorsal horn
    → Brain cannot distinguish the source
    → Interprets the signal as coming from the somatic area (skin/muscle)
    → = "Referred pain"

  DERMATOMAL RULE:
    Pain is referred to structures that share the same embryonic segment:
    → Heart (T1-T5) → left arm, jaw, chest wall (same spinal segments)
    → Gallbladder (C3-C5 via phrenic) → right shoulder
    → Kidney (T10-L1) → flank, groin
    → Stomach (T6-T9) → epigastric region

  CLINICAL MAP (selected organ-dermatome):
  ┌──────────────────┬────────────────┬──────────────────┐
  │ Organ            │ Spinal segment │ Referred area    │
  ├──────────────────┼────────────────┼──────────────────┤
  │ Heart            │ T1-T5          │ Left arm, jaw    │
  │ Lungs/diaphragm  │ C3-C5          │ Shoulder tip     │
  │ Stomach          │ T6-T9          │ Epigastric       │
  │ Liver/gallbladder│ T7-T9, C3-C5   │ Right shoulder   │
  │ Small intestine  │ T9-T10         │ Periumbilical    │
  │ Appendix         │ T10            │ Periumbilical→RLQ│
  │ Kidney/ureter    │ T10-L1         │ Flank, groin     │
  │ Bladder          │ T11-L2, S2-S4  │ Suprapubic, back │
  │ Uterus           │ T10-L1, S2-S4  │ Lower back, groin│
  └──────────────────┴────────────────┴──────────────────┘

  ⭐ THERAPY IMPLICATION — THE PATHWAY GOES BOTH DIRECTIONS:
    Viscerosomatic: organ → skin symptoms (referred pain)
    Somatovisceral: skin stimulation → organ effect (therapy)
    = SAME convergent neurons, BIDIRECTIONAL signaling

    → Acupuncture at dermatome matching organ → somatovisceral reflex
      → autonomic modulation of that organ
    → = WHY specific acupoints correspond to specific organs
    → = NOT "mystical meridian" — MEASURABLE neuroanatomical convergence
    → BUT: mapping is not 1:1 clean — overlap, individual variation

### §3.6 — Peripheral and Central Sensitization

```
🟢 SENSITIZATION — WHY PAIN AMPLIFIES AND PERSISTS:

  PERIPHERAL SENSITIZATION:
    After tissue injury → inflammatory mediators released:
      bradykinin, prostaglandins, histamine, serotonin, NGF, cytokines
    → These LOWER the threshold of nociceptors
    → Previously sub-threshold stimuli now activate pain
    → "Silent nociceptors" WAKE UP and become active
    → Result: HYPERALGESIA (increased pain from painful stimuli)
               + ALLODYNIA (pain from normally non-painful stimuli)
    → RESTRICTED to the injury site
    → REVERSIBLE when inflammation resolves

  CENTRAL SENSITIZATION ⭐:
    Persistent peripheral input → changes in dorsal horn neurons:
    → C fiber release of glutamate + substance P
    → NMDA receptor activation (normally Mg²⁺ blocked)
    → Mg²⁺ block removed → Ca²⁺ influx → intracellular cascades
    → GENE EXPRESSION changes → long-term excitability increase
    → Results:
      - Receptive field EXPANSION (wider area perceived as painful)
      - Reduced threshold (more sensitive)
      - Enhanced response (same stimulus → more pain)
      - After-discharge (pain continues after stimulus stops)
    → NOT restricted to injury site — SPREADS
    → CAN become SELF-MAINTAINING (independent of peripheral input)
    → = THE mechanism behind chronic pain becoming "its own disease"

  NOCIPLASTIC PAIN (newer concept, 2017+):
    → Pain arising from altered nociceptive processing
    → No clear tissue damage OR nerve lesion
    → Central sensitization as the primary driver
    → Examples: fibromyalgia, IBS, chronic tension headache
    → 🟢 Kosek et al. 2016 (IASP taskforce — nociplastic pain)

  THERAPY RELEVANCE ⭐⭐:
    Peripheral sensitization:
    → Anti-inflammatory therapies (cupping, gua sha → local inflammation
      → paradoxically RESOLVES chronic inflammation via immune reset)
    → Acupuncture → local anti-inflammatory via adenosine release

    Central sensitization:
    → Harder to treat — need to "reprogram" spinal cord processing
    → Repetitive sensory input (massage, acupuncture series)
      → may gradually reset dorsal horn excitability
    → 🟡 Hypothesis: repeated non-painful input → competes with
      sensitized pain circuits → gradual normalization
    → = WHY body therapies often require MULTIPLE sessions for chronic pain

  🟢 Woolf 1983 (central sensitization — original discovery)
  🟢 Latremoliere & Woolf 2009 (central sensitization review)
  🟢 Ji et al. 2003 (molecular mechanisms)
```

### §3.7 — Purinergic Signaling: ATP/Adenosine Pathway

```
🟢 PURINERGIC SIGNALING — ACUPUNCTURE'S MOLECULAR MECHANISM:

  DISCOVERY:
    Acupuncture needle insertion + rotation → tissue deformation
    → Cells at acupoint release ATP (adenosine triphosphate)
    → ATP degrades: ATP → ADP → AMP → ADENOSINE (via CD39/CD73 enzymes)
    → Adenosine binds A1 receptors on sensory neurons
    → A1 activation → INHIBITS nociceptive transmission → ANALGESIA

  KEY PLAYERS:
  ┌──────────────────────────────────────────────────────────────┐
  │  CELLS:                                                      │
  │    Fibroblasts → release ATP when mechanically deformed       │
  │    Mast cells → release ATP + degranulate (histamine, etc.)  │
  │    Keratinocytes → release ATP under mechanical stress        │
  │                                                              │
  │  MOLECULES:                                                   │
  │    ATP → initial signaling molecule, pro-inflammatory         │
  │    Adenosine → anti-nociceptive, anti-inflammatory            │
  │    P2X receptors (P2X3, P2X4, P2X7) → respond to ATP         │
  │    A1 receptor → responds to adenosine → pain suppression     │
  │    CD39 enzyme → degrades ATP → AMP → pathway to adenosine   │
  │                                                              │
  │  SEQUENCE:                                                    │
  │    Needle rotation → tissue deformation → ATP release         │
  │    → P2X activation (initial sensation)                       │
  │    → CD39/CD73 convert ATP → adenosine                        │
  │    → A1 activation → analgesia                               │
  └──────────────────────────────────────────────────────────────┘

  EVIDENCE:
    → 🟢 Goldman et al. 2010 (Nature Neuroscience): acupuncture at
      Zusanli (ST36) → adenosine release → A1-mediated analgesia
      → Effect ABOLISHED in A1 knockout mice
      → Effect ENHANCED by deoxycoformycin (blocks adenosine degradation)
    → 🟢 Takano et al. 2012: needle rotation → ATP release from
      connective tissue fibroblasts → confirmed in vivo
    → 🟢 CD39 agonists MIMIC acupuncture analgesia (2024)

  THIS MECHANISM EXPLAINS:
    → Why needle ROTATION matters (more tissue deformation = more ATP)
    → Why effect is LOCAL initially (adenosine acts near release site)
    → Why electroacupuncture can enhance effect (more consistent stimulation)
    → Why the effect builds over minutes (time for ATP → adenosine conversion)
```

### §4.2 — The 5 PNS Mechanisms Underlying Body Therapies

```
🟡 SYNTHESIS: 5 DISTINCT PNS MECHANISMS — MOST THERAPIES USE MULTIPLE:

  ① GATE CONTROL (spinal cord level)
     Input: Aβ fiber activation (touch, pressure, vibration)
     Output: Reduced pain transmission to brain
     Duration: DURING stimulation + short after
     Therapies: ALL contact-based therapies

  ② DESCENDING MODULATION (brain → spinal cord)
     Input: Aδ + C fiber → PAG activation
     Output: Endorphin/enkephalin/serotonin release → inhibits dorsal horn
     Duration: Minutes to hours after treatment
     Therapies: Acupuncture, deep tissue, intense stimulation

  ③ AXON REFLEX (local tissue, no CNS)
     Input: C fiber activation → antidromic propagation
     Output: CGRP + SP release → vasodilation, immune modulation
     Duration: Minutes to hours
     Therapies: Acupuncture, moxibustion, gua sha, cupping

  ④ SOMATOVISCERAL REFLEX (spinal segment → organ)
     Input: Somatic afferent at specific dermatome
     Output: Autonomic modulation of corresponding organ
     Duration: Variable — can be sustained with repeated treatment
     Therapies: Acupuncture at specific points, acupressure, diện chẩn

  ⑤ PURINERGIC SIGNALING (local biochemistry)
     Input: Tissue deformation → ATP release from fibroblasts/mast cells
     Output: ATP → adenosine → A1 receptor → analgesia + anti-inflammation
     Duration: Minutes (ATP → adenosine conversion time)
     Therapies: Acupuncture (especially with needle rotation)

  ⭐ MOST THERAPIES ACTIVATE MULTIPLE MECHANISMS SIMULTANEOUSLY:
     Acupuncture = ①+②+③+④+⑤ (all five)
     Massage = ①+② (+ CT afferent reward pathway)
     Acupressure = ①+④
     Deep Tissue = ①+②+③ (intense pressure)
     Diện chẩn = ①+④ (via trigeminal, not spinal)
     Cupping = ①+③
     Gua Sha = ①+③ (shear-specific)                       [RC#5]
     Moxibustion = ③+④
     Chiropractic = ①+②+④ (joint proprioceptors)          [RC#5]
     Tai Chi/Qigong = ① (proprioceptive gate control)      [RC#6]
     Yoga Therapy = ① (proprioceptive gate control)        [RC#6]
     ⚠ B15/B16 engage PNS primarily through PROPRIOCEPTIVE/MOTOR
     pathways (Ia/Ib/II afferents, α/γ motor neurons, vestibular)
     rather than the PAIN-MODULATION focus of mechanisms ①-⑤.
     Their PNS engagement is QUALITATIVELY different from passive
     therapies: self-generated, sustained, movement-based.

  🟡 This 5-mechanism model is a framework synthesis.

### §4.3 — CT Afferents: The Reward Pathway for Touch Therapy

```
🟢 CT AFFERENTS — WHY MASSAGE FEELS GOOD:

    → CT afferents evolved for inter-individual bonding

    → Absent (or minimal) in non-social species

    → The therapeutic relationship (practitioner touch) →

    → Explains why "same acupoint" → slightly different effects
      between individuals
    → Clinical: dermatome maps are AVERAGES, not individual blueprints
```

## §8 — OPEN QUESTIONS

```
🔴 WHAT IS NOT YET UNDERSTOOD:

  Q1: ACUPUNCTURE POINT SPECIFICITY
    Gate control + axon reflex + purinergic signaling explain
    WHY needling produces local effects. BUT: WHY do specific
    points (acupoints) produce SPECIFIC organ effects?
    Somatovisceral convergence explains SEGMENTAL effects (same dermatome).
    It does NOT explain NON-segmental effects (e.g., LI4 hand point → headache).
    → Candidates: fascial connectivity (A03), meridian-like pathways (A09),
      long-range neural circuits
    → Status: partially explained, much still unknown

  Q2: DOSE-RESPONSE RELATIONSHIP
    Why does "gentle touch" → relaxation (CT pathway)
    while "deep pressure" → pain relief (descending modulation)?
    Is there a continuous dose-response curve or discrete thresholds?
    → Clinical implications: optimal pressure/depth for each condition?
    → Status: some data exists, no unified model

  Q3: CUMULATIVE TREATMENT EFFECTS
    Single session → acute effects (gate control, endorphin).
    Series of sessions → longer-lasting changes.
    MECHANISM of cumulative effect:
    → Reversal of central sensitization? (gradual dorsal horn reset)
    → Peripheral nerve remodeling? (repeated stimulation → structural change)
    → Immune system recalibration? (repeated axon reflex → new setpoint)
    → Status: largely unknown — this is a major research gap

  Q4: CT AFFERENT THERAPEUTIC vs SOCIAL ROLE
    CT afferents evolved for social bonding.
    Therapeutic touch activates the same pathway.
    Is the therapeutic benefit of CT activation DIFFERENT from social touch?
    Or is therapy-touch working THROUGH the social bonding pathway?
    → Implications for practitioner-patient relationship
    → Status: emerging research area

  Q5: NEUROPLASTICITY IN THERAPY RESPONSE
    Do repeated body therapy sessions cause measurable changes in
    peripheral nerve function? (threshold shifts, receptor density, etc.)
    → Some evidence for acupuncture → cortical remapping
    → Less evidence for peripheral structural changes
    → Status: limited data

  Q6: INDIVIDUAL RESPONSE PREDICTION
    Can we predict WHO will respond to WHICH therapy based on
    PNS profiling? (receptor density, pain sensitivity genetics,
    sensitization status)
    → Would allow personalized therapy selection
    → Status: very early stage

  Q7: INTERACTION BETWEEN MECHANISMS
    The 5 mechanisms (§4.2) operate simultaneously.
    How do they INTERACT? Additive? Synergistic? Competitive?
    → Example: does gate control ENHANCE or INTERFERE with
      descending modulation?
    → Status: mostly studied in isolation, not as interacting system
```
