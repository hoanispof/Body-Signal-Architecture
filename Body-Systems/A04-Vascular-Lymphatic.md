# A04 — Vascular & Lymphatic System

> **Position:** Track A file #7 — the DELIVERY AND EXCHANGE system.
> A01 describes HOW signals travel through nerves. A02 describes HOW signals become organ responses.
> A03 describes the STRUCTURAL MATRIX. A05 describes neuroimmune communication.
> This file describes HOW blood and lymph DELIVER the effects of therapy to tissues,
> HOW microcirculation creates the local tissue environment,
> and HOW specific therapies (cupping, gua sha) work PRIMARILY through vascular mechanisms.
>
> **Core Insight — The Circulatory Mediation Principle:**
> The vascular-lymphatic system is both DELIVERY MECHANISM and THERAPEUTIC TARGET.
> Blood vessels are not passive pipes — they are mechanosensitive organs whose endothelium
> responds to shear stress, neuropeptides, and therapy input via NO, CGRP, and HO-1 pathways.
> Body therapies produce effects by modulating CIRCULATORY EXCHANGE: controlling what gets
> delivered (O₂, nutrients, immune cells), what gets removed (waste, inflammatory mediators),
> and how the tissue microenvironment changes. Every acupoint is a neurovascular bundle
> (nerve + artery + veins), making vascular modulation inseparable from neural therapy effects.
>
> **Scope:** Arterial, venous, and microcirculatory anatomy. Lymphatic system.
> Endothelial function and NO pathway. Neurogenic vascular control (CGRP, SP).
> HO-1 pathway (cupping, gua sha). Lymphatic pumping. Vascular pathology in chronic pain.

## §1 — PHYSICAL ARCHITECTURE

### §1.1 — Overview: The Circulatory Exchange Network

```
🟢 THE VASCULAR-LYMPHATIC SYSTEM — TWO INTERCONNECTED NETWORKS:

  ┌───────────────────────────────────────────────────────────────────┐
  │  ① CARDIOVASCULAR SYSTEM (closed circuit)                         │
  │                                                                   │
  │    Heart → Arteries → Arterioles → CAPILLARIES → Venules → Veins │
  │      ↑                                ↓                          │
  │      └──────────── Heart ←────────────┘                          │
  │                                                                   │
  │    Function: O₂/nutrient DELIVERY, CO₂/waste REMOVAL              │
  │    Volume: ~5 liters blood, ~100,000 km of vessels                │
  │    Key: CAPILLARIES are the functional exchange unit              │
  │                                                                   │
  ├───────────────────────────────────────────────────────────────────┤
  │  ② LYMPHATIC SYSTEM (open-ended, one-way)                         │
  │                                                                   │
  │    Interstitial fluid → Lymph capillaries → Collecting vessels    │
  │    → Lymph nodes → Lymphatic trunks → Thoracic duct → Venous     │
  │                                                                   │
  │    Function: FLUID RECOVERY, IMMUNE SURVEILLANCE, fat transport   │
  │    Volume: ~3-4 liters lymph/day returned to blood                │
  │    Key: NO PUMP — relies on muscle contraction, breathing,        │
  │         and intrinsic lymphangion contractions                    │
  │                                                                   │
  └───────────────────────────────────────────────────────────────────┘

  ⭐ FOR BODY THERAPY, THE CRITICAL INSIGHT IS:
    Every acupoint = a NEUROVASCULAR BUNDLE
    (nerve + artery + veins running through fascia)
    Cadaveric studies describe acupoints as structures comprising
    an artery, two veins, and a nerve passing through fascia
    → Vascular modulation is INSEPARABLE from neural therapy effects

  🟢 Standring 2020 (Gray's Anatomy, 42nd ed.)
  🟢 Dorsher 2017 (neuroembryology of acupuncture meridians)
```

### §1.2 — Arterial System: The Delivery Network

```
🟢 ARTERIES — HIGH-PRESSURE DISTRIBUTION:

  STRUCTURE (3 layers — tunica):
    ┌──────────────────────────────────────────────────────────┐
    │  TUNICA INTIMA (inner)                                    │
    │    → Endothelial cells (single layer) — THE SENSOR LAYER │
    │    → Endothelial GLYCOCALYX — mechanosensitive coating    │
    │    → Basement membrane                                    │
    │                                                           │
    │  TUNICA MEDIA (middle)                                    │
    │    → Smooth muscle cells — contractile = VASOCONSTRICTION │
    │    → Elastic fibers — large arteries are mainly elastic   │
    │    → Sympathetic innervation → α1 adrenergic → constrict  │
    │                                                           │
    │  TUNICA ADVENTITIA (outer)                                │
    │    → Collagen fibers — structural strength                │
    │    → Vasa vasorum — blood vessels of blood vessels         │
    │    → Nerve fibers (sympathetic, sensory)                  │
    │    → Lymphatic vessels                                    │
    └──────────────────────────────────────────────────────────┘

  ARTERIAL HIERARCHY:
    Aorta (25mm) → elastic arteries → muscular arteries (4mm)
    → ARTERIOLES (10-100μm) → metarterioles → CAPILLARIES (5-10μm)

  ⭐ ARTERIOLES = KEY RESISTANCE VESSELS:
    → Where blood pressure is regulated (60% of total resistance)
    → Heavily innervated by sympathetic fibers (A02 §3.1)
    → Smooth muscle tone determines tissue blood flow
    → Local metabolites can override neural control
    → = THE level where therapy-induced vasodilation matters most

  🟢 Tortora & Derrickson 2017 (Principles of Anatomy & Physiology)
```

### §1.3 — Venous System: The Return Network

```
🟢 VEINS — LOW-PRESSURE RETURN:

  KEY STRUCTURAL DIFFERENCES FROM ARTERIES:
    → Thinner walls (less smooth muscle)
    → VALVES — one-way flow toward heart (absent in brain/abdomen)
    → Higher compliance (distensibility) — act as blood RESERVOIRS
    → 60-70% of blood volume at any time is in veins
    → Lower pressure: 5-15 mmHg vs 80-120 mmHg arterial

  VENOUS RETURN MECHANISMS:
    ┌──────────────────────────────────────────────────────────┐
    │  ① MUSCLE PUMP (skeletal muscle contraction)              │
    │    → Contraction compresses veins → blood pushed toward   │
    │      heart through one-way valves                         │
    │    → Relaxation → veins refill from capillary side        │
    │    → = WHY immobility → venous stasis → edema → DVT risk │
    │    → = WHY massage TOWARD HEART mimics muscle pump        │
    │                                                           │
    │  ② RESPIRATORY PUMP                                       │
    │    → Inspiration → diaphragm descends → abdominal         │
    │      pressure ↑ → thoracic pressure ↓ → blood pulled     │
    │      toward heart (pressure gradient)                     │
    │    → = WHY deep breathing improves venous return           │
    │    → Connects to A02 §3.7 (breathing as Zone D bridge)    │
    │                                                           │
    │  ③ VENOCONSTRICTION (sympathetic)                          │
    │    → SNS activation → venous smooth muscle contraction    │
    │    → Reduces venous compliance → shifts blood from        │
    │      reservoir to active circulation                       │
    │    → = WHY sympathetic activation ↑ cardiac output        │
    │                                                           │
    │  ④ CARDIAC SUCTION                                         │
    │    → Atrial relaxation creates slight negative pressure    │
    │    → Draws blood from great veins into heart               │
    └──────────────────────────────────────────────────────────┘

  THERAPY RELEVANCE:
    → Massage (centripetal strokes) → assists muscle pump
    → Cupping (negative pressure) → local venous redistribution
    → Exercise/movement therapies → activates both muscle + respiratory pumps
    → Compression therapy → increases venous return velocity

  🟢 Standring 2020. 🟢 Levick 2010 (cardiovascular physiology).
```

### §1.4 — Microcirculation: The Functional Exchange Unit

```
🟢 MICROCIRCULATION — WHERE THERAPY EFFECTS HAPPEN:

  The microcirculation = arterioles + capillaries + venules
  This is WHERE gas/nutrient exchange occurs with tissue
  This is WHERE therapy-induced changes in blood flow matter

  CAPILLARY STRUCTURE:
    → Diameter: 5-10 μm (just wide enough for 1 RBC)
    → Wall: SINGLE LAYER of endothelial cells + basement membrane
    → NO smooth muscle (cannot actively constrict)
    → Blood flow controlled by UPSTREAM arterioles
    → Transit time: ~1-2 seconds per capillary

  3 TYPES OF CAPILLARIES:
    ┌──────────────────────────────────────────────────────────┐
    │  CONTINUOUS (most tissues, including muscle, skin, brain) │
    │    → Tight junctions between endothelial cells            │
    │    → Selective permeability via transport proteins         │
    │    → Blood-brain barrier = most extreme form              │
    │                                                           │
    │  FENESTRATED (kidneys, intestines, endocrine glands)      │
    │    → Small pores (60-80nm) through endothelial cells      │
    │    → Rapid filtration/absorption                           │
    │                                                           │
    │  SINUSOIDAL (liver, spleen, bone marrow)                  │
    │    → Large gaps between endothelial cells                 │
    │    → Allow whole cells to pass (RBCs, WBCs)               │
    └──────────────────────────────────────────────────────────┘

  PRECAPILLARY SPHINCTERS:
    → Smooth muscle rings at arteriole-capillary junction
    → Open/close individual capillary beds
    → Controlled by LOCAL metabolites (O₂, CO₂, adenosine, NO)
    → At rest: only 25-30% of capillaries are open
    → Active tissue: up to 100% open → blood flow ↑ 4-10x
    → = WHY acupuncture-induced vasodilation has measurable effect

  ⭐ ACUPOINTS HAVE HIGHER MICROVASCULAR DENSITY:
    → Laser Doppler flowmetry (LDF) shows significantly larger
      blood flow signals at acupoints than surrounding tissue
    → Acupoints are located at neurovascular bundle convergence
    → Higher capillary density + nerve density = amplified
      response to mechanical stimulation
    🟢 Hsiu et al. 2011 (LDF acupoint microcirculation)

  🟢 Tortora & Derrickson 2017. 🟢 Levick 2010.
```

### §1.5 — Lymphatic System: Fluid Recovery and Immune Highway

```
🟢 LYMPHATIC SYSTEM — THE PARALLEL CIRCULATION:

  Unlike the cardiovascular system (closed loop), the lymphatic
  system is OPEN-ENDED — begins as blind-ended capillaries in tissue.

  LYMPHATIC CAPILLARIES:
    → Start as blind-ended tubes in interstitial space
    → BUTTON-LIKE JUNCTIONS (not tight) — allow large molecules,
      proteins, immune cells, and pathogens to ENTER
    → Anchoring filaments connect to surrounding tissue →
      when tissue swells → filaments pull → junctions open wider
    → = Edema PROMOTES lymphatic drainage (self-regulating)
    → Absent in: CNS (but see GLYMPHATIC below), cartilage, cornea

  COLLECTING VESSELS AND LYMPHANGIONS:
    → Lymph capillaries merge into collecting vessels
    → Collecting vessels have VALVES (like veins)
    → LYMPHANGION = pumping unit (segment between 2 valves) ⭐
      • Encircled by lymphatic smooth muscle cells
      • Spontaneous phasic contractions (intrinsic pump)
      • Action potentials propagate at ~10 mm/s
      • Regulated by mechano-chemical oscillator:
        intracellular Ca²⁺ coupled with NO transients
      • Shear stress → eNOS → NO → relaxation (negative feedback)
    🟢 Davis 2025 (J Physiology: lymphatic pacemaking mechanics)

  LYMPH NODES:
    → ~600-800 nodes throughout body
    → Filter lymph: trap pathogens, cancer cells, debris
    → Immune cell stations: B cells, T cells, macrophages, DCs
    → Afferent lymph → subcapsular sinus → cortex (B cells) →
      paracortex (T cells) → medulla → efferent lymph
    → Each node filters AND adds immune cells to lymph
    → = Lymph nodes are immune CHECKPOINTS

  MAJOR LYMPHATIC TRUNKS AND DUCTS:
    → Thoracic duct (left): drains ~75% of body lymph
      → Empties into left subclavian-jugular junction
    → Right lymphatic duct: right upper quadrant
    → Cisterna chyli: abdominal lymph reservoir (fat absorption)

  LYMPHATIC PUMPING (no heart for lymph):
    ┌──────────────────────────────────────────────────────────┐
    │  INTRINSIC PUMP:                                          │
    │    → Lymphangion smooth muscle contractions               │
    │    → 6-10 contractions/min (rate varies by region)        │
    │    → Stretch-activated: more lymph → stronger contraction │
    │    → Generates ~3-5 mmHg propulsive pressure              │
    │                                                           │
    │  EXTRINSIC PUMP:                                          │
    │    → Skeletal muscle contraction (exercise, massage)      │
    │    → Arterial pulsation (arteries run alongside lymphatics)│
    │    → Respiratory motion (thoracic pressure changes)       │
    │    → Intestinal peristalsis (abdominal lymph)             │
    │    → External compression (massage, compression garments) │
    │                                                           │
    │  ⭐ BODY THERAPIES PRIMARILY ASSIST EXTRINSIC PUMP:       │
    │    → Massage → compresses tissue → squeezes lymph         │
    │    → Movement therapies → muscle pump → lymph flow        │
    │    → Breathing exercises → respiratory pump → thoracic    │
    │      duct drainage                                        │
    └──────────────────────────────────────────────────────────┘

  GLYMPHATIC SYSTEM (brain lymphatic equivalent):
    → Discovered 2012 (Iliff et al., Science Translational Med)
    → CSF flows along perivascular spaces → clears brain waste
    → Most active during SLEEP (60% increase in interstitial space)
    → Clears amyloid-β (Alzheimer's relevance)
    → NOT directly accessible to body therapy (skull barrier)
    → BUT: sleep quality → glymphatic function → brain health
    → Body therapies that improve sleep → indirect benefit

  🟢 Standring 2020. 🟢 Davis 2025. 🟢 Iliff et al. 2012 (glymphatic).
```

### §1.6 — Vascular Innervation: Neural Control of Blood Flow

```
🟢 AUTONOMIC CONTROL OF BLOOD VESSELS (detail in A02):

  SYMPATHETIC INNERVATION — DOMINANT CONTROL:
    → Nearly ALL blood vessels receive sympathetic innervation
    → Postganglionic sympathetic → NE → α1 receptors → VASOCONSTRICTION
    → Exception: skeletal muscle arterioles → β2 → VASODILATION
    → Continuous tonic activity maintains baseline vascular tone
    → Increased sympathetic → ↑ vasoconstriction → ↑ BP
    → Decreased sympathetic → vasodilation (withdrawal of tone)

  PARASYMPATHETIC INNERVATION — LIMITED:
    → Most blood vessels have NO parasympathetic innervation
    → Exceptions: erectile tissue, salivary glands, some cerebral vessels
    → Vasodilation is primarily achieved by:
      ① Sympathetic WITHDRAWAL (releasing tonic constriction)
      ② LOCAL mediators (NO, adenosine, CGRP, prostaglandins)
      ③ Axon reflex (antidromic CGRP/SP release — A01 §3.4)

  ⭐ THIS ASYMMETRY IS KEY FOR THERAPY:
    → Body therapies cannot directly activate parasympathetic
      vasodilation (it barely exists for most vessels)
    → Instead, therapy causes vasodilation via:
      • ↓ sympathetic tone (relaxation → sympathetic withdrawal)
      • LOCAL mediators (CGRP from axon reflex, NO from endothelium)
      • Purinergic (adenosine from ATP breakdown → A1 receptor)
    → = Therapy-induced vasodilation is predominantly LOCAL,
      not systemic parasympathetic

  SENSORY INNERVATION OF BLOOD VESSELS:
    → C fiber nociceptors innervate vascular adventitia
    → These same fibers release CGRP and SP (axon reflex)
    → CGRP → potent arteriolar vasodilation
    → SP → venular plasma extravasation (increased permeability)
    → = Triple response of Lewis (1927):
      ① Local redness (CGRP → arteriolar dilation)
      ② Flare (axon reflex spreading → wider vasodilation)
      ③ Wheal (SP → plasma extravasation → local edema)
    → = The redness around an acupuncture needle = THIS response

  🟢 Jänig 2006 (Integrative Action of the ANS)
  🟢 Lewis 1927 (triple response — foundational)
```

### §1.7 — Endothelial Glycocalyx: The Vascular Mechanosensor

```
🟢 GLYCOCALYX — THE SENSING LAYER:

  WHAT IT IS:
    → Hair-like coating on the luminal surface of ALL endothelial cells
    → Composed of: proteoglycans, glycoproteins, glycosaminoglycans
      (heparan sulfate most abundant), hyaluronic acid
    → Thickness: 0.5-5 μm depending on vessel type
    → Continuous with intracellular cytoskeleton via transmembrane
      proteoglycans (syndecans, glypicans)

  FUNCTIONS:
    ┌──────────────────────────────────────────────────────────┐
    │  ① MECHANOTRANSDUCTION — senses blood flow shear stress  │
    │    → Shear → glycocalyx deformation → cytoskeletal       │
    │      reorganization → intracellular signaling             │
    │    → Activates eNOS → NO production → vasodilation        │
    │    → Heparan sulfate = major mechanotransduction component│
    │    🟢 2024 PLOS ONE: basal glycocalyx also responds       │
    │                                                           │
    │  ② PERMEABILITY BARRIER                                   │
    │    → Regulates what crosses vessel wall                   │
    │    → Revised Starling principle: the glycocalyx is the    │
    │      semipermeable barrier, not the cell membrane itself  │
    │    → Relevant osmotic gradient = plasma ↔ SUBglycocalyx  │
    │      space (not plasma ↔ bulk interstitium)              │
    │    🟢 Levick & Michel 2010 (Cardiovasc Res)               │
    │                                                           │
    │  ③ ANTI-INFLAMMATORY SHIELD                               │
    │    → Prevents leukocyte and platelet adhesion             │
    │    → Glycocalyx degradation → inflammation, edema         │
    │    → Damaged by: hyperglycemia, sepsis, ischemia-         │
    │      reperfusion, oxidative stress                         │
    │                                                           │
    │  ④ GRADED RESPONSE across capillary bed:                  │
    │    → Arteriolar capillaries: no shear response             │
    │    → True capillaries: moderate response                   │
    │    → Venular capillaries: 5-fold strong response           │
    │    → = Vascular mechanosensitivity varies by location     │
    └──────────────────────────────────────────────────────────┘

  🟢 Levick & Michel 2010 (revised Starling principle)
  🟢 Weinbaum et al. 2007 (glycocalyx mechanotransduction)
  🟢 2024 (fluid shear stress-dependent glycocalyx modulation)
```

## §2 — FUNCTION

### §2.1 — Oxygen and Nutrient Delivery / Waste Removal

```
🟢 THE EXCHANGE FUNCTION:

  AT THE CAPILLARY:
    → Oxygen diffuses from blood (high pO₂) to tissue (low pO₂)
    → CO₂ diffuses from tissue → blood (reverse gradient)
    → Glucose, amino acids, fatty acids → tissue via transporters
    → Metabolic waste (urea, lactate) → blood → kidneys/liver

  OXYGEN DELIVERY DEPENDS ON:
    ① Blood flow rate (cardiac output × regional distribution)
    ② Hemoglobin saturation (oxygen-carrying capacity)
    ③ Capillary density (exchange surface area)
    ④ Capillary transit time (~1-2 seconds — must be enough)

  ⭐ THERAPY RELEVANCE:
    → Ischemic trigger points: excessive sarcomere contraction →
      compresses capillaries → ↓ O₂ delivery → energy crisis →
      more contraction → VICIOUS CYCLE (A08 §3.5, Simons hypothesis)
    → Therapy (needling, pressure) → local vasodilation →
      ↑ O₂ delivery → breaks energy crisis
    → Cupping → negative pressure → ↑ capillary perfusion →
      oxyhemoglobin ↑ 6.75 μM at -300 mmHg
      🟢 Li et al. 2023 (J Biophotonics: NIRS cupping)
```

### §2.2 — Thermoregulation: Cutaneous Blood Flow Control

```
🟢 SKIN BLOOD FLOW — THE BODY'S RADIATOR:

  Skin receives ~5-10% of cardiac output at rest
  BUT can increase to 60% during heat stress (up to 8 L/min)

  2 MECHANISMS OF CUTANEOUS VASOMOTOR CONTROL:
    ┌──────────────────────────────────────────────────────────┐
    │  ① VASOCONSTRICTION (cold response):                     │
    │    → Sympathetic → NE → α1/α2 on vascular smooth muscle │
    │    → Reduces skin blood flow → conserves heat             │
    │    → Arteriovenous anastomoses (AVAs) close               │
    │    → AVAs = direct arteriole-venule connections in        │
    │      fingertips, toes, ears, nose (NO capillary exchange) │
    │                                                           │
    │  ② ACTIVE VASODILATION (heat response):                   │
    │    → NOT simple sympathetic withdrawal                    │
    │    → Active vasodilator system (mechanism debated):       │
    │      involves ACh, NO, VIP, substance P, CGRP            │
    │    → CGRP = most potent cutaneous vasodilator             │
    │    → Links directly to axon reflex (A01 §3.4)             │
    │    → AVAs open → blood bypasses capillaries → radiates    │
    │      heat from skin surface                               │
    └──────────────────────────────────────────────────────────┘

  THERAPY RELEVANCE:
    → Moxibustion: local heat → TRPV1 activation at >42°C →
      C fiber → CGRP release → local vasodilation
      + Systemic cardiovascular reflex via sympathetic modulation
    → Acupuncture: needle → axon reflex → CGRP → local warmth
      ("de qi" warmth sensation = partly vascular)
    → Cupping: suction → capillary distension → visible redness
    → Infrared thermography can visualize these temperature changes

  🟢 Johnson & Kellogg 2010 (cutaneous vasomotor control)
  🟢 Charkoudian 2010 (skin blood flow thermoregulation)
```

### §2.3 — Fluid Homeostasis: The Revised Starling Principle

```
🟢 CAPILLARY FLUID EXCHANGE — REVISED MODEL:

  CLASSICAL STARLING (1896):
    Fluid movement across capillary wall = balance of:
    → Capillary hydrostatic pressure (pushes OUT) ~35 mmHg art, ~15 mmHg ven
    → Interstitial hydrostatic pressure (pushes IN) ~0 mmHg
    → Plasma oncotic pressure (pulls IN) ~25 mmHg
    → Interstitial oncotic pressure (pulls OUT) ~5 mmHg
    → Net: filtration at arteriolar end, absorption at venular end

  ⭐ REVISED STARLING (Levick & Michel 2010):
    → The semipermeable barrier is the GLYCOCALYX, not the endothelium
    → Relevant oncotic gradient = plasma vs SUBGLYCOCALYX space
      (NOT plasma vs bulk interstitial fluid)
    → In most tissues: SLIGHT NET FILTRATION throughout capillary
      (even at venular end — not the textbook "absorption")
    → Steady-state absorption is transient, not sustained
    → Filtered fluid → returned via LYMPHATIC system, not venular
    → = Lymphatic system is MORE IMPORTANT for fluid balance
      than previously thought

  IMPLICATIONS FOR THERAPY:
    → Edema = imbalance: filtration > lymphatic drainage
    → Therapy addressing edema must target LYMPHATIC drainage
      (not just venous return)
    → Massage centripetal strokes → assist lymphatic + venous return
    → Compression → reduces filtration + assists drainage
    → Movement → muscle pump → both venous and lymphatic return

  🟢 Levick & Michel 2010 (Cardiovasc Res — revised Starling)
  🟢 Starling 1896 (original principle)
```

### §2.4 — Immune Surveillance: The Lymphatic Highway

```
🟢 LYMPHATIC IMMUNE FUNCTION:

  LYMPH = IMMUNE TRANSPORT MEDIUM:
    → Pathogens entering tissue → captured by lymph capillaries
    → Transported to nearest lymph node → filtered
    → Dendritic cells in tissue → capture antigen → migrate via
      lymphatics to lymph node → present to T cells
    → Activated immune cells exit node → enter blood → reach infection

  LYMPH NODE AS IMMUNE CHECKPOINT:
    → Cortex: B cell follicles → antibody production
    → Paracortex: T cells → cell-mediated immunity
    → Macrophages: phagocytose debris, pathogens
    → If threat detected → node swells (lymphadenopathy)
    → Each region drains to specific nodes (sentinel nodes in cancer)

  THERAPY RELEVANCE:
    → Body therapies that ↑ lymph flow → ↑ immune surveillance
    → Exercise: 2-3x increase in lymph flow during activity
    → Manual lymphatic drainage (MLD): assists compromised system
    → Breathing exercises: respiratory pump moves thoracic duct lymph
    → 🟡 Whether therapy-enhanced lymph flow measurably improves
      immune function in healthy individuals = under-studied

  🟢 Randolph et al. 2017 (lymphatic system in immunity)
```

## §3 — PATHWAYS

### §3.1 — Vascular Tone Regulation: Neural, Humoral, and Local

```
🟢 3-LEVEL VASCULAR REGULATION:

  ┌───────────────────────────────────────────────────────────────────┐
  │  LEVEL 1 — NEURAL (fastest, seconds)                              │
  │                                                                   │
  │    SYMPATHETIC (dominant):                                         │
  │      → Tonic vasoconstrictor activity at rest                     │
  │      → NE → α1 → vasoconstriction (most vascular beds)           │
  │      → NE → β2 → vasodilation (skeletal muscle arterioles)        │
  │      → Epinephrine (adrenal) → β2 → skeletal muscle dilation     │
  │      → Detail: A02 §3.1                                           │
  │                                                                   │
  │    SENSORY (axon reflex):                                          │
  │      → C fiber antidromic activation → CGRP + SP release          │
  │      → CGRP → arteriolar vasodilation (potent, local)             │
  │      → SP → venular permeability ↑ (plasma extravasation)         │
  │      → = Neurogenic inflammation = THE local vascular response    │
  │        to acupuncture/needling                                     │
  │      → Detail: A01 §3.4, A05 §2.1                                 │
  │                                                                   │
  ├───────────────────────────────────────────────────────────────────┤
  │  LEVEL 2 — HUMORAL (slower, minutes)                               │
  │                                                                   │
  │    CIRCULATING VASOCONSTRICTORS:                                    │
  │      → Angiotensin II (RAS system) → powerful constriction         │
  │      → ADH/vasopressin → constriction + water retention            │
  │      → Endothelin-1 (from endothelium) → constriction              │
  │                                                                   │
  │    CIRCULATING VASODILATORS:                                        │
  │      → ANP/BNP (from heart) → vasodilation + natriuresis          │
  │      → Epinephrine (low dose, β2) → skeletal muscle dilation      │
  │      → Histamine (from mast cells) → arteriolar dilation          │
  │                                                                   │
  ├───────────────────────────────────────────────────────────────────┤
  │  LEVEL 3 — LOCAL / METABOLIC (continuous, autoregulation)          │
  │                                                                   │
  │    METABOLIC VASODILATORS:                                         │
  │      → ↓ O₂ → vasodilation (active hyperemia)                    │
  │      → ↑ CO₂ → vasodilation                                      │

### §3.4 — Lymphatic Pumping: Intrinsic and Extrinsic Mechanisms

```
🟢 LYMPHATIC FLOW — HOW LYMPH MOVES WITHOUT A HEART:

  INTRINSIC PUMP (lymphangion contractions):
    → Lymphatic smooth muscle generates spontaneous contractions
    → Pacemaker cells initiate action potentials
    → Propagation: ~10 mm/s along vessel wall

      Ca²⁺ rise → contraction → lymph propulsion (systole)

      (Frank-Starling-like mechanism for lymphatics)

      frequency (prevents overwork when extrinsic pump active)

    ┌──────────────────────────────────────────────────────────┐

    │ Intestinal peristalsis    │ Abdominal massage              │

    → Sedentary: fewer capillaries, stiffer arteries, slower
      vascular response to therapy
    → = Aerobic fitness modulates therapy vascular effectiveness

    → Arterial stiffness ↑ with age (collagen ↑, elastin ↓)
    → Endothelial function ↓ (reduced NO bioavailability)
    → Capillary rarefaction (fewer capillaries per tissue volume)
    → Lymphatic pump weakens with age
    → Glycocalyx thins (less mechanosensitive)
    → = Older adults: vascular component of therapy may be reduced

  ④ SEX DIFFERENCES:
    → Premenopausal women: estrogen → ↑ eNOS → better vasodilation
    → Post-menopause: rapid decline in endothelial function

    → Diabetes: glycocalyx degradation, endothelial dysfunction,

    → Obesity: chronic low-grade inflammation → impaired NO
