## §1 — PHYSICAL ARCHITECTURE

### §1.1 — Overview: The Body Is Organized in Segments

```
🟢 SEGMENTAL ORGANIZATION — THE FUNDAMENTAL ARCHITECTURE:

  The human body is NOT a uniform mass — it is organized in SEGMENTS
  (metameres), each segment served by ONE spinal nerve.

  Each segment contains 4 PARALLEL MAPS of the same territory:

  ┌───────────────────────────────────────────────────────────────────┐
  │                                                                   │
  │  SOMITE (embryological origin — one per segment)                  │
  │    ↓ splits into:                                                │
  │                                                                   │
  │  ┌─ DERMATOME ─┐  ┌─ MYOTOME ──┐  ┌─ SCLEROTOME ┐  ┌─ VISCEROTOME ┐
  │  │ skin area    │  │ muscle     │  │ bone/joint   │  │ internal    │
  │  │ innervated   │  │ group      │  │ innervated   │  │ organ       │
  │  │ by ONE       │  │ innervated │  │ by ONE       │  │ innervated  │
  │  │ spinal nerve │  │ by ONE     │  │ spinal nerve │  │ by ONE      │
  │  │              │  │ spinal     │  │              │  │ spinal      │
  │  │              │  │ nerve      │  │              │  │ segment     │
  │  └──────┬───────┘  └─────┬──────┘  └──────┬───────┘  └──────┬──────┘
  │         │                │               │                │
  │         └────────────────┴───────────────┴────────────────┘
  │                                   │
  │                    ALL CONVERGE at the SAME
  │                    SPINAL CORD SEGMENT (dorsal horn)
  │                                   │
  │                    ⭐ = WHY stimulating SKIN (dermatome)
  │                        can affect ORGAN (viscerotome)
  │                        through the SAME spinal level
  │                                                                   │
  └───────────────────────────────────────────────────────────────────┘

  THIS IS THE NEUROANATOMICAL BASIS FOR ACUPOINT-ORGAN EFFECTS.
  Not meridian energy flow — segmental nerve convergence.

  🟢 Standring 2020 (Gray's Anatomy 42nd ed.)
  🟢 Sadler 2018 (Langman's Medical Embryology 14th ed.)
```

### §1.2 — Dermatome Maps: 31 Segments of Skin

```
🟢 DERMATOMES — SKIN AREAS MAPPED TO SPINAL NERVES:

  30 dermatomes (C2-S5; C1 has minimal/no cutaneous territory):

  ┌──────────────┬──────────────────────────────────────────────────┐
  │ Segment      │ Skin Territory (key landmarks)                   │
  ├──────────────┼──────────────────────────────────────────────────┤
  │ C2           │ Posterior scalp, upper neck                      │
  │ C3           │ Lower posterior neck, upper trapezius area        │
  │ C4           │ Shoulder cap, lower neck                         │
  │ C5           │ Lateral arm (deltoid area)                       │
  │ C6           │ Lateral forearm, thumb, index finger             │
  │ C7           │ Middle finger, posterior forearm                 │
  │ C8           │ Medial forearm, ring + little finger             │
  ├──────────────┼──────────────────────────────────────────────────┤
  │ T1           │ Medial arm (above elbow)                        │
  │ T2           │ Medial arm, axilla                              │
  │ T3           │ Axilla to 3rd intercostal space                 │
  │ T4           │ Nipple line ⭐ (clinical landmark)               │
  │ T5           │ Between nipple and xiphoid                      │
  │ T6           │ Xiphoid process level                           │
  │ T7-T9       │ Upper abdomen (epigastric)                       │
  │ T10          │ Umbilicus ⭐ (clinical landmark)                 │
  │ T11-T12      │ Lower abdomen                                   │
  ├──────────────┼──────────────────────────────────────────────────┤
  │ L1           │ Inguinal region, upper anterior thigh            │
  │ L2           │ Anterior thigh (upper medial)                   │
  │ L3           │ Anterior thigh (lower medial), medial knee      │
  │ L4           │ Medial leg, medial ankle                        │
  │ L5           │ Lateral leg, dorsum of foot, great toe          │
  ├──────────────┼──────────────────────────────────────────────────┤
  │ S1           │ Lateral foot, sole, small toe, posterior leg    │
  │ S2           │ Posterior thigh                                 │
  │ S3           │ Upper medial thigh, perineal region             │
  │ S4-S5       │ Perianal region (saddle area)                    │
  └──────────────┴──────────────────────────────────────────────────┘

  KEY PRINCIPLE — OVERLAP:
    → Adjacent dermatomes overlap ~50% (more for touch, less for pain)
    → Loss of ONE spinal nerve → only PARTIAL sensory loss
      (neighbors cover the overlap zone)
    → Loss of THREE consecutive nerves needed for complete anesthesia
    → Overlap is GREATER in trunk, LESS in limbs
    → = Dermatome maps are AVERAGES, not individual blueprints

  🟢 Foerster 1933 (surgical mapping — foundational)
  🟢 Keegan & Garrett 1948 (clinical mapping — widely used)
  🟢 Lee et al. 2008 (composite map, review of 14 dermatome maps)
```

### §1.3 — Dermatome Map Discrepancies: A Critical Caveat

```
🟢 THREE MAJOR MAPS — THEY DISAGREE:

  ┌──────────────┬───────────────────────┬─────────────────────────┐
  │ Map          │ Method                │ Characteristics         │
  ├──────────────┼───────────────────────┼─────────────────────────┤
  │ Foerster     │ Surgical nerve root   │ Shows MAXIMAL extent    │
  │ (1933)       │ stimulation + section │ + overlap. Foundational.│
  ├──────────────┼───────────────────────┼─────────────────────────┤
  │ Keegan &     │ Clinical nerve root   │ Shows "primitive"       │
  │ Garrett      │ compression patients  │ dermatomes. Continuous  │
  │ (1948)       │                       │ band pattern. Widely    │
  │              │                       │ reproduced BUT flawed.  │
  ├──────────────┼───────────────────────┼─────────────────────────┤
  │ Lee et al.   │ Composite of 14 maps  │ Most evidence-based.    │
  │ (2008)       │ + critical review     │ Excludes Keegan-Garrett │
  │              │                       │ data due to methodology.│
  └──────────────┴───────────────────────┴─────────────────────────┘

  SPECIFIC DISCREPANCIES (examples):
    → C4/T2 boundary: does C4 extend to upper chest? (Foerster yes,
      Keegan-Garrett no)
    → L4/L5/S1 foot mapping: varies significantly between maps
    → Axial lines (where non-adjacent dermatomes meet): poorly defined

  WHY THIS MATTERS FOR THERAPY:
    → "Acupoint X is in dermatome T4" — which map?
    → Individual variation > map differences
    → Must think in SEGMENTS with OVERLAP, not sharp boundaries
    → Clinical testing (pin-prick) = more reliable than any drawn map

  🟢 Lee et al. 2008 (critical review of 14 maps)
  🟢 Downs & Laporte 2011 (conflicting maps — educational implications)
```

  Most muscles receive innervation from 2+ segments (unlike dermatomes).

  │ Segment      │ Key Muscles / Movement               │
  ├──────────────┼──────────────────────────────────────┤

  │ C7           │ Elbow extension (triceps), wrist fl.  │
  │ C8           │ Finger flexion, hand grip             │
  │ T1           │ Finger abduction (interossei)         │
  │ T2-T12      │ Intercostals, trunk muscles            │
  │ L1-L2       │ Hip flexion (iliopsoas)                │
  │ L3           │ Knee extension (quadriceps)            │
  │ L4           │ Ankle dorsiflexion (tibialis anterior) │
  │ L5           │ Great toe extension (ext. hallucis)    │
  │ S1           │ Ankle plantarflexion (gastrocnemius)   │
  │ S2           │ Knee flexion (hamstrings)              │

  └──────────────┴──────────────────────────────────────┘

  THERAPY RELEVANCE:
    → Trigger points (A08) often occur in muscles of the SAME
      myotome as a symptomatic dermatome
    → Muscle tension/spasm → myotomal pattern → diagnostic clue
      for which spinal segment is involved
    → Segmental massage targeting specific myotomes →
      can modulate the entire segment (dermatome + viscerotome)

  🟢 Kendall et al. 2005 (Muscles: Testing and Function)
  🟢 Medical Research Council 1943 (myotome testing scale)
```

### §1.5 — Sclerotomes: Bone/Joint Mapped to Spinal Segments

```
🟢🟡 SCLEROTOMES — BONE/JOINT INNERVATION BY SEGMENT:

  A sclerotome = region of bone and periosteum innervated by
  a single spinal segment.

  Less well-established than dermatomes/myotomes.
  Mapped primarily via bone pain referral patterns.

  KEY PATTERNS:
    → Vertebral body → innervated by recurrent meningeal nerve
      of the SAME segment
    → Rib periosteum → follows thoracic segmental pattern
    → Upper limb bones → C5-T1 pattern
    → Lower limb bones → L2-S2 pattern

  CLINICAL RELEVANCE:
    → Deep aching bone pain → sclerotomal distribution
    → Often confused with myotomal or dermatomal pain
    → Bone metastases → pain follows sclerotome pattern
    → Sclerotomal pain is MORE DIFFUSE than dermatomal pain
      (less precise segmental organization in bone innervation)

  THERAPY RELEVANCE:
    → Deep tissue techniques reaching periosteum (acupuncture,
      deep pressure) → activate sclerotomal afferents
    → Sclerotomal pain referral → different pattern from
      dermatome → different acupoints may be relevant

  🟢 Inman & Saunders 1944 (referred pain from skeletal structures)
  🟡 Ivanusic 2007 (evidence for spinal segmental innervation of bone)
  ⚠️ Note: sclerotome evidence is weaker than dermatome evidence.
     Clinically used but not as precisely mapped.
```

### §1.6 — Viscerotomes: Organs Mapped to Spinal Segments

```
🟢 VISCEROTOMES — THE CRITICAL MAP FOR THERAPY:

  A viscerotome = internal organ innervated by a specific spinal segment.
  THIS is the map that links skin stimulation to organ effects.

  ┌──────────────────┬────────────────┬──────────────────────┐
  │ Organ            │ Spinal Segment │ Shared Dermatome     │
  ├──────────────────┼────────────────┼──────────────────────┤
  │ Heart            │ T1-T5          │ Left arm, chest wall │
  │ Lungs            │ T3-T5          │ Upper chest, back    │
  │ Diaphragm        │ C3-C5          │ Shoulder tip         │
  │                  │ (phrenic nerve)│                      │
  │ Esophagus        │ T4-T6          │ Retrosternal, back   │
  │ Stomach          │ T6-T9          │ Epigastric region    │
  │ Liver/Gallbladder│ T7-T9, C3-C5  │ Right shoulder, RUQ  │
  │ Spleen           │ T6-T8          │ Left upper quadrant  │
  │ Pancreas         │ T6-T9          │ Epigastric, back     │
  │ Small intestine  │ T9-T10         │ Periumbilical        │
  │ Appendix         │ T10            │ Periumbilical → RLQ  │
  │ Large intestine  │ T10-L1         │ Lower abdomen        │
  │ Kidney           │ T10-L1         │ Flank, groin         │
  │ Ureter           │ T11-L2         │ Flank → groin        │
  │ Bladder          │ T11-L2, S2-S4  │ Suprapubic, perineal │
  │ Uterus           │ T10-L1, S2-S4  │ Lower back, groin    │
  │ Ovaries/Testes   │ T10-T11        │ Lower abdomen        │
  │ Prostate         │ S2-S4          │ Perineal, sacral     │
  │ Rectum           │ S2-S4          │ Perineal, sacral     │
  └──────────────────┴────────────────┴──────────────────────┘

  ⭐ THE CONVERGENCE PRINCIPLE:
    Organ (viscerotome) + Skin (dermatome) + Muscle (myotome)
    → ALL converge at the SAME dorsal horn neurons
    → Brain cannot distinguish source → "referred pain"

    Direction 1: VISCEROSOMATIC (organ → skin)
      Disease organ → afferent → dorsal horn → perceived as skin pain
      = Referred pain, Head zones
      Example: heart attack → left arm pain

    Direction 2: SOMATOVISCERAL (skin → organ) ⭐⭐
      Skin stimulation → afferent → dorsal horn → autonomic outflow → organ
      = Therapeutic mechanism for acupuncture, acupressure
      Example: ST36 (leg point) → gastrointestinal modulation

  🟢 Head 1893 (original viscero-cutaneous mapping)
  🟢 Sato et al. 1997 (somatovisceral reflexes)
  🟢 Ness & Gebhart 1990 (visceral pain mechanisms)
```

### §1.7 — Facial Somatotopy: Trigeminal Territory

```
🟢 TRIGEMINAL NERVE — THE FACE IS NOT A DERMATOME, IT'S SPECIAL:

  The face is innervated by CN V (trigeminal), NOT spinal nerves.
  Different organizational principle: 3 divisions, NOT segmental.

  ┌───────────────────────────────────────────────────────────────┐
  │                                                               │
  │  V1 (Ophthalmic)                                             │
  │    Territory: forehead, upper eyelid, bridge of nose,         │
  │               conjunctiva, cornea                             │
  │    Exits: superior orbital fissure                            │
  │    Key branches: frontal, lacrimal, nasociliary               │
  │                                                               │
  │  V2 (Maxillary)                                              │
  │    Territory: cheek, upper lip, upper teeth, nasal cavity,    │
  │               lower eyelid, lateral nose                      │
  │    Exits: foramen rotundum → infraorbital foramen             │
  │    Key branches: infraorbital, superior alveolar, zygomatic   │
  │                                                               │
  │  V3 (Mandibular)                                             │
  │    Territory: lower jaw, lower lip, lower teeth, chin,        │
  │               anterior 2/3 tongue (sensory), temporal area    │
  │    Exits: foramen ovale                                       │
  │    ONLY division with MOTOR fibers (muscles of mastication)   │
  │    Key branches: inferior alveolar, lingual, auriculotemporal │
  │                                                               │
  │  PLUS: "onion-skin" pattern in trigeminal nucleus caudalis    │
  │    (concentric rings from nose outward — different from       │
  │     V1/V2/V3 divisional pattern)                              │
  │                                                               │
  └───────────────────────────────────────────────────────────────┘

  UNIQUE BRAINSTEM SOMATOTOPY:
    → Trigeminal sensory nuclei span ENTIRE brainstem length
    → Spinal trigeminal nucleus caudalis = continuous with
      spinal dorsal horn (functionally equivalent)
    → V3 represented most dorsally/rostrally
    → V1 represented most ventrally/caudally
    → V2 intermediate position

  ⭐ TRIGEMINAL → VAGAL CONNECTION:
    → Trigeminal spinal nucleus sends projections to
      dorsal motor nucleus of vagus (DMX)
    → = Facial stimulation → parasympathetic activation
    → = Neuroanatomical basis for facial stimulation therapies
    → Diver's reflex: cold water on face (V1) → vagal response
      → bradycardia + peripheral vasoconstriction

  🟢 Borsook et al. 2004 (trigeminal nociceptive pathways)
  🟢 Sessle 2000 (trigeminal brainstem complex review)
  🟢 McCorry 2007 (diver's reflex physiology)
```

### §1.8 — Auricular Somatotopy: The Ear as a Body Map

```
🟢🟡 EAR SOMATOTOPY — INVERTED FETUS MAP:

  The external ear (auricle) has a unique somatotopic organization:
  the body is represented as an INVERTED FETUS.

  DISCOVERY:
    → Paul Nogier (1956, Lyon, France)
    → Observed: patients from Corsica had cautery scars on ears
      for sciatica treatment → noticed consistent pattern
    → Proposed: the entire body is represented on the ear surface

  MAP LAYOUT:
  ┌───────────────────────────────────────────────────────────────┐
  │                                                               │
  │  SUPERIOR (top of ear — helix/antihelix)                     │
  │    → Lower body: feet, legs, hips                             │
  │                                                               │
  │  MIDDLE (antihelix body, concha ridge)                       │
  │    → Trunk: spine, chest, abdomen                             │
  │                                                               │
  │  INFERIOR (lobule)                                            │
  │    → Head: face, eyes, jaw, brain                             │
  │                                                               │
  │  CONCHA (concave bowl) ⭐                                     │
  │    → Internal organs: heart, lungs, stomach, liver            │
  │    → ALSO: vagus nerve territory (Arnold's nerve)             │
  │    → = Stimulating concha → vagal activation → organ effects  │
  │                                                               │
  └───────────────────────────────────────────────────────────────┘

  INNERVATION OF THE AURICLE:
    → Auriculotemporal nerve (V3 branch) → most of anterior ear
    → Great auricular nerve (C2-C3) → lobule, posterior ear
    → Lesser occipital nerve (C2) → superior posterior
    → Arnold's nerve (CN X auricular branch) → concha, ear canal ⭐
    → Facial nerve (CN VII) → small contribution

  3 REFLEX ZONES (modern classification):
    ① SARZ (Somatic Auricular Reflex Zone) — musculoskeletal
    ② VARZ (Visceral Auricular Reflex Zone) — internal organs
    ③ CARZ (Central Auricular Reflex Zone) — CNS/brain regions

  NEUROANATOMICAL BASIS:
    → Arnold's nerve → NTS (Nucleus Tractus Solitarius) →
      autonomic/visceral processing
    → Trigeminal input → trigeminal nucleus → brainstem integration
    → C2-C3 input → cervical spinal cord → neck/head connection
    → = CONVERGENCE of 4 nerve sources at brainstem level
    → = Multiple pathways for auricular therapy effects

  🟢 Peuker & Filler 2002 (auricular innervation anatomy)
  🟢 He et al. 2012 (auricular acupuncture and vagal regulation)
  🟡 Nogier 1956 (inverted fetus hypothesis — foundational but
     evidence for complete somatotopy is mixed)
  ⚠️ Evidence for detailed point specificity on the ear is
     WEAKER than for body acupoints. Vagal activation via concha
     is well-established; organ-specific mapping is less certain.
```

## §2 — FUNCTION

### §2.1 — Embryological Basis: Why the Body Is Segmental

```
🟢 SOMITE DEVELOPMENT — THE ORIGIN OF SEGMENTATION:

  TIMELINE:
    Week 3 of embryo: paraxial mesoderm segments into SOMITES
    → 42-44 somites form in craniocaudal sequence
    → Each somite = a developmental unit → one body segment

  SOMITE → 4 DERIVATIVES:
  ┌────────────────────────────────────────────────────────────┐
  │  Somite                                                    │
  │    ├── Sclerotome (ventromedial) → vertebra, rib           │
  │    ├── Dermomyotome (dorsolateral)                         │
  │    │     ├── Dermatome → dermis of skin in that segment    │
  │    │     └── Myotome → skeletal muscle of that segment     │
  │    └── Syndetome → tendons, cartilage                      │
  │                                                            │
  │  NEURAL CREST CELLS (from neural tube):                    │
  │    → Migrate through somites (ventromedial route)          │
  │    → Form: Dorsal Root Ganglia (DRG) at each segment       │
  │    → Form: Sympathetic chain ganglia                       │
  │    → Somites GUIDE neural crest migration paths             │
  │    → = Somites determine WHERE sensory neurons end up      │
  └────────────────────────────────────────────────────────────┘

  WHY INNERVATION FOLLOWS SEGMENT:
    → Each spinal nerve forms AT the level of its somite
    → As the embryo grows, the somite derivatives MIGRATE
      but CARRY their nerve supply with them
    → Example: C5 somite → deltoid muscle migrates to shoulder
      → but keeps C5 nerve innervation
    → = Dermatome patterns reflect EMBRYOLOGICAL position,
      not adult anatomical proximity

  CRITICAL CONSEQUENCE:
    → Diaphragm originates from C3-C5 somites
    → Migrates DOWN to thorax-abdomen border during development
    → BUT keeps C3-C5 innervation (phrenic nerve)
    → = WHY liver/gallbladder irritation → shoulder pain
      (C3-C5 convergence — NOT anatomical proximity)
    → = Embryology explains "illogical" referred pain patterns

  🟢 Sadler 2018 (Langman's Medical Embryology 14th ed.)
  🟢 Gilbert 2014 (Developmental Biology 10th ed.)
  🟢 Christ et al. 2007 (somite derivatives — review)
```

### §2.2 — The Segmental Unit: One Spinal Nerve, Four Territories

```
🟡 THE SEGMENTAL UNIT — CONCEPTUAL FRAMEWORK:

  Each spinal segment = a FUNCTIONAL UNIT containing:

  ┌──────────────────────────────────────────────────────────────┐
  │  SPINAL SEGMENT [e.g., T4]                                   │
  │                                                              │
  │  INPUTS (afferent):                                          │
  │    Dermatome (T4) → skin at nipple line                      │
  │    Myotome (T4) → intercostal muscles                        │
  │    Sclerotome (T4) → T4 vertebra, 4th rib                   │
  │    Viscerotome (T4) → heart, esophagus                       │
  │                                                              │
  │  ALL → converge at T4 dorsal horn neurons                    │
  │                                                              │
  │  OUTPUTS (efferent):                                         │
  │    Somatic motor → intercostal muscles                       │
  │    Sympathetic → T4 sympathetic ganglion → heart rate, etc.  │
  │    Vasomotor → blood vessels in T4 territory                 │
  │                                                              │
  │  = Stimulating T4 dermatome (skin) →                         │
  │    SAME dorsal horn → sympathetic output → cardiac modulation│
  │                                                              │
  │  = THIS is the somatovisceral reflex in anatomical detail    │
  └──────────────────────────────────────────────────────────────┘

  WHY "UNIT" MATTERS:
    → The segment does NOT distinguish where the input came from
    → Skin pain, muscle pain, bone pain, organ pain — all arrive
      at the SAME dorsal horn neurons
    → = Convergence-projection: brain misattributes source
    → = Bidirectional access: input at ANY territory can
      modulate ALL territories in the same segment

  🟡 This "segmental unit" concept is our framework synthesis.
     Each component (convergence, somatovisceral reflex) has
     🟢 individual research support.
     The integration into a single "unit" model is 🟡 synthesis.
```

### §2.3 — Clinical Diagnostic Function

```
🟢 DERMATOME TESTING — DIAGNOSTIC APPLICATIONS:

  SENSORY TESTING:
    → Light touch (cotton wisp) → tests Aβ fibers / DCML pathway
    → Pin-prick (sharp/dull) → tests Aδ fibers / spinothalamic
    → Temperature (cold tuning fork) → tests thermoreceptors
    → Each test applied segmentally → identifies affected spinal level

  MYOTOME TESTING:
    → Manual muscle testing against resistance
    → Each movement tests specific spinal nerve root
    → Weakness → radiculopathy at that segment
    → MRC scale: 0 (no contraction) to 5 (normal strength)

  REFLEX TESTING:
    → Deep tendon reflexes → tests specific reflex arcs
    → Biceps reflex → C5-C6
    → Brachioradialis → C5-C6
    → Triceps reflex → C7-C8
    → Patellar (knee-jerk) → L3-L4
    → Achilles (ankle-jerk) → S1-S2
    → Diminished reflex → lower motor neuron lesion at that level

  DIAGNOSTIC VALUE:
    → Dermatomal sensory loss + myotomal weakness +
      absent reflex = localizes lesion to specific spinal level
    → Disc herniation → affects ONE nerve root → ONE segment
    → Spinal cord lesion → affects ALL segments BELOW the level

  🟢 Hoppenfeld 1977 (Physical Examination of the Spine — standard)
```

## §3 — PATHWAYS

### §3.1 — Level 1: Peripheral Somatotopy (Body Surface → Spinal Nerve)

```
🟢 PERIPHERAL ORGANIZATION — BODY TO NERVE:

  SPINAL NERVES (body):
    31 pairs of spinal nerves, each carrying information from
    a specific body segment → segmental, dermatomal organization

  PLEXUS FORMATION:
    Spinal nerves RECOMBINE into plexuses before reaching periphery:
    → Cervical plexus (C1-C4) → neck, diaphragm
    → Brachial plexus (C5-T1) → upper limb
    → Lumbar plexus (L1-L4) → anterior thigh
    → Sacral plexus (L4-S3) → posterior thigh, leg

    ⭐ PLEXUS RECOMBINATION = WHY peripheral nerve territories
       (e.g., median nerve = C6-T1) do NOT match single dermatomes
    → Peripheral nerve injury → NOT dermatomal pattern
    → Root compression → dermatomal pattern
    → = Key diagnostic distinction

  CRANIAL NERVES (head):
    → CN V (trigeminal) → face (V1/V2/V3 divisions)
    → CN VII (facial) → taste (anterior 2/3 tongue)
    → CN IX (glossopharyngeal) → pharynx, posterior tongue
    → CN X (vagus) → ear (Arnold's nerve), viscera
    → = Head/face follows CRANIAL organization, not segmental

  TRANSITION ZONE:
    → C2-C3 (cervical) meets CN V (trigeminal) at posterior head
    → C2 dermatome overlaps with V1/V3 territory
    → = "Cervico-trigeminal convergence" — relevant for
      headache referral patterns

  🟢 Standring 2020 (Gray's Anatomy — plexus anatomy)
```

### §3.2 — Level 2: Spinal Cord Somatotopy (Dorsal Horn Organization)

```
🟢 SPINAL CORD — LAMINAR + SOMATOTOPIC ORGANIZATION:

  REXED LAMINAE (dorsal horn layers):
  ┌──────────────────────────────────────────────────────────────┐
  │  LAMINA I (Marginal Zone)                                    │
  │    → Nociceptive-specific neurons + wide dynamic range (WDR) │
  │    → Receives: Aδ + C fibers (pain, temperature)             │
  │    → Projects: spinothalamic tract → thalamus (pain pathway) │
  │                                                              │
  │  LAMINA II (Substantia Gelatinosa) ⭐                         │
  │    → GATE CONTROL occurs HERE (Melzack & Wall 1965)          │
  │    → Dense interneuron network (excitatory + inhibitory)     │
  │    → Receives: C fibers (slow pain), Aδ fibers              │
  │    → Integration site: where Aβ input can inhibit pain       │
  │                                                              │
  │  LAMINA III-IV (Nucleus Proprius)                             │
  │    → Low-threshold mechanoreceptive neurons                  │
  │    → Receives: Aβ fibers (touch, pressure)                   │
  │    → DCML pathway origin for detailed touch processing       │
  │                                                              │
  │  LAMINA V ⭐⭐                                                │
  │    → WIDE DYNAMIC RANGE (WDR) neurons                        │
  │    → CONVERGENCE ZONE: receives BOTH                         │
  │      somatic (Aβ, Aδ, C) AND visceral afferents              │
  │    → = WHERE dermatome meets viscerotome                     │
  │    → = THE anatomical site of referred pain                  │
  │    → = THE anatomical site of somatovisceral reflex          │
  │                                                              │
  │  LAMINA VI-VII                                               │
  │    → Intermediate zone, interneurons                         │
  │    → Motor integration, proprioceptive processing            │
  │                                                              │
  │  LAMINA VIII-IX                                              │
  │    → Ventral horn, motor neurons                             │
  │    → Somatic motor output                                    │
  │                                                              │
  │  LAMINA X                                                    │
  │    → Central canal surroundings                              │
  │    → Visceral afferent processing                            │
  └──────────────────────────────────────────────────────────────┘

  SOMATOTOPIC COLUMNS:
    → Within each lamina, neurons are organized in sagittal columns
    → Each column = one somatotopic unit (body region)
    → Columns span 7-20mm rostrocaudally
    → 0.5-1.0mm wide
    → = 3D somatotopic organization within the dorsal horn

  ⭐ LAMINA V = THE KEY FOR THERAPY:
    WDR neurons in lamina V receive convergent input from:
    (a) Skin (somatic afferents) — the dermatome
    (b) Deep tissue (muscle, joint) — the myotome/sclerotome
    (c) Visceral organs — the viscerotome
    → These neurons CANNOT distinguish source
    → = "Convergence-projection" mechanism of referred pain
    → = SAME mechanism allows skin → organ therapeutic access

  🟢 Rexed 1952 (laminar organization — original description)
  🟢 Willis & Coggeshall 2004 (Sensory Mechanisms of the Spinal Cord)
  🟢 Sugiura et al. 1986 (viscerosomatic convergence in lamina V)
```

### §3.3 — Level 3: Thalamic Somatotopy (VPL + VPM)

```
🟢 THALAMUS — BODY MAP RELAY STATION:

  The thalamus maintains a somatotopic body map as it relays
  sensory information from spinal cord to cortex.

  TWO KEY NUCLEI:
  ┌───────────────────────────────────────────────────────────────┐
  │                                                               │
  │  VPL (Ventral Posterolateral Nucleus)                        │
  │    Receives: BODY sensory input (DCML + spinothalamic)       │
  │    From: spinal cord and brainstem (medial lemniscus)         │
  │    Somatotopy: leg = dorsolateral, arm = ventromedial         │
  │    Projects to: S1 cortex (postcentral gyrus)                │
  │                                                               │
  │  VPM (Ventral Posteromedial Nucleus)                         │
  │    Receives: FACE sensory input (trigeminal)                  │
  │    From: trigeminal nucleus → trigeminothalamic tract         │
  │    Somatotopy: preserves V1/V2/V3 organization               │
  │    Projects to: S1 cortex (lateral, near sylvian fissure)    │
  │                                                               │
  │  OVERALL MEDIOLATERAL MAP:                                    │
  │    MEDIAL ← Face (VPM) | Arm | Leg → LATERAL (VPL)          │
  │                                                               │
  │  MODALITY SEGREGATION:                                       │
  │    → Core of VPL/VPM: DCML input (fine touch, proprioception)│
  │    → Shell region: spinothalamic input (pain, temperature)    │
  │    → = Pain and touch take SEPARATE paths through thalamus   │
  │                                                               │
  └───────────────────────────────────────────────────────────────┘

  THALAMIC GATING:
    → TRN (Thalamic Reticular Nucleus) = inhibitory shell
    → PFC can modulate TRN → selective attention to body regions
    → = PFC attention to pain at body location X →
      TRN modulates thalamic relay for that somatotopic region
    → = "Attentional spotlight" has somatotopic specificity

  THERAPY RELEVANCE:
    → Thalamic somatotopy = why localized therapy feels localized
    → Thalamic relay = potential site for chronic pain distortion
    → Deep brain stimulation for pain targets VPL/VPM
      somatotopically (face pain → VPM, limb pain → VPL)

  🟢 Kaas et al. 1984 (VPL somatotopy)
  🟢 Jones 2007 (The Thalamus — comprehensive reference)
  🟢 Leplus et al. 2024 (thalamic somatotopy via DBS in pain patients)
```

### §3.4 — Level 4: Cortical Somatotopy (The Homunculus)

```
🟢 CORTEX — THE DISTORTED BODY MAP:

  PENFIELD'S HOMUNCULUS (1950):
    → Wilder Penfield, Montreal Neurological Institute
    → Electrical stimulation of exposed cortex during neurosurgery
    → Mapped sensation (S1) and movement (M1) point-by-point
    → Result: the "little man" — cortical representation of the body

  S1 (Primary Somatosensory Cortex — Postcentral Gyrus):
  ┌───────────────────────────────────────────────────────────────┐
  │                                                               │
  │  MEDIAL (interhemispheric fissure)                           │
  │    → Genitalia, foot, leg                                     │
  │                                                               │
  │  SUPERIOR LATERAL                                             │
  │    → Hip, trunk, shoulder                                     │
  │                                                               │
  │  MIDDLE LATERAL                                               │
  │    → Arm, hand, FINGERS ⭐ (disproportionately LARGE)         │
  │                                                               │
  │  INFERIOR LATERAL (near sylvian fissure)                      │
  │    → FACE, LIPS, TONGUE ⭐ (disproportionately LARGE)         │
  │    → Intra-abdominal sensation                               │
  │                                                               │
  │  = INVERTED body map (feet top, face bottom)                  │
  │  = DISTORTED: hands + face > 50% of cortical territory       │
  │    while trunk < 10%                                         │
  │                                                               │
  └───────────────────────────────────────────────────────────────┘

  S1 SUBDIVISIONS (Brodmann Areas):
    → BA 3a: proprioception (deep)
    → BA 3b: cutaneous touch (primary processing) ⭐
    → BA 1: texture processing
    → BA 2: size, shape (complex tactile)
    → Each has its OWN somatotopic map → 4 parallel body maps

  S2 (Secondary Somatosensory Cortex):
    → Bilateral body representation (BOTH sides of body)
    → Pain integration, tactile memory, object recognition by touch
    → Receives from S1 + direct thalamic input
    → Less precise somatotopy than S1

  POSTERIOR INSULA ⭐:
    → CT afferent destination (affective touch, §A01 §4.3)
    → Interoceptive processing
    → NOT somatotopically organized like S1
    → = "How the body FEELS" rather than "where is the touch"

  KEY PRINCIPLES:
    ① DISPROPORTIONATE REPRESENTATION:
       → Cortical area ∝ receptor density + functional importance
       → NOT ∝ physical body area size
       → Hands/face: high receptor density → large cortical territory
       → Trunk: low receptor density → small cortical territory
       → = "Cortical magnification"

    ② CORTICAL PLASTICITY ⭐:
       → Body map is NOT fixed — changes with experience
       → Amputation → neighboring regions EXPAND into deprived area
       → Intense practice → EXPANSION of trained body part's map
       → String musicians: left hand representation > right hand
       → Braille readers: reading finger representation enlarged
       → = Somatotopic maps are DYNAMIC, not hardwired

    ③ CONTRALATERAL ORGANIZATION:
       → Left body → right S1; right body → left S1
       → (S2 = bilateral)
       → Corpus callosum integrates two sides

  🟢 Penfield & Boldrey 1937 (original mapping)
  🟢 Penfield & Rasmussen 1950 (The Cerebral Cortex of Man)
  🟢 Elbert et al. 1995 (cortical reorganization in string players)
  🟢 Makin et al. 2013 (phantom limb — preserved vs reorganized)
```

### §3.5 — The Complete Somatotopic Pipeline

```
🟡 4-LEVEL SOMATOTOPIC MAP — FROM SKIN TO CONSCIOUSNESS:

  Level 1: PERIPHERAL (Body → Nerve)
    Skin receptor → dermatome → spinal nerve → DRG
    Organized: SEGMENTALLY (31 spinal + 12 cranial)

  Level 2: SPINAL CORD (Nerve → Dorsal Horn)
    DRG → dorsal horn laminae → somatotopic columns
    Organized: SEGMENTALLY + LAMINAR (by modality)
    ⭐ CONVERGENCE occurs here (dermatome + viscerotome)

  Level 3: THALAMUS (Dorsal Horn → Relay)
    Ascending tracts → VPL (body) + VPM (face)
    Organized: SOMATOTOPICALLY (medial-lateral gradient)
    Attention-gated (TRN)

  Level 4: CORTEX (Relay → Conscious Experience)
    VPL/VPM → S1 (postcentral gyrus)
    Organized: SOMATOTOPICALLY but DISTORTED (homunculus)
    Plastic — changes with experience

  ┌─────────────────────────────────────────────────────────┐
  │  Skin stimulus at T4 dermatome                          │
  │    ↓                                                    │
  │  T4 spinal nerve → T4 DRG → T4 dorsal horn             │
  │    ↓ (convergence with cardiac viscerotome at T4)       │

  │    ↓                                                    │
  │  S1 cortex (trunk area)                                 │
  │    ↓                                                    │
  │  Conscious perception: "touch on chest"                 │
  │                                                         │
  │  SIMULTANEOUSLY:                                        │
  │  T4 dorsal horn → T4 sympathetic outflow → cardiac      │
  │    = Somatovisceral reflex (below consciousness)        │
  └─────────────────────────────────────────────────────────┘

  AT EACH LEVEL, the map can be MODULATED:
    Level 2: Gate control (Aβ inhibits C at dorsal horn)

## §4 — RELEVANCE TO BODY-BASED THERAPY

### §4.1 — Head Zones: The Western Discovery of Acupoints

```
🟢 HEAD ZONES — HENRY HEAD'S MAPPING (1893-1896):

  WHAT HE FOUND:
    → Patients with visceral disease develop SPECIFIC areas of skin
      tenderness (hyperalgesia / allodynia)
    → These areas correspond to the spinal segments innervating
      the diseased organ
    → He called them "zones of referred visceral pain"

  HEAD'S EXTENDED FINDINGS (mostly forgotten today):
    Within each zone, Head identified:
    ① Diffuse hyperalgesia — the broader zone
    ② MAXIMUM POINTS ⭐ — specific points of GREATEST tenderness
    ③ Deep hyperalgesia — muscle tenderness in same segment
    ④ Vasomotor changes — skin temperature, sweating differences
    ⑤ Muscular defense — increased resistance/guarding
    ⑥ Piloerection — "goosebumps" in the zone

  ⭐ MAXIMUM POINTS = REMARKABLY SIMILAR TO ACUPOINTS:
    → Head found that within each zone, tenderness is NOT uniform
    → Specific points show MAXIMAL sensitivity
    → These points are consistent between patients
    → = The Western equivalent of discovering "acupoints"
    → = 2000+ years after Chinese medicine documented the same phenomenon

  HEAD ZONE MAP (selected):
  ┌──────────────────┬────────────┬──────────────────────────┐
  │ Organ            │ Head Zone  │ Maximum Point Area       │
  ├──────────────────┼────────────┼──────────────────────────┤
  │ Heart            │ T1-T5 left │ Left parasternal T3-T4   │
  │ Stomach          │ T6-T9     │ Epigastric midline       │
  │ Liver            │ T7-T9 right│ Right subcostal          │
  │ Kidney           │ T10-L1    │ Flank paravertebral      │
  │ Bladder          │ T11-L1    │ Suprapubic               │
  │ Appendix         │ T10 right │ McBurney's point         │
  └──────────────────┴────────────┴──────────────────────────┘

  🟢 Head 1893 (On disturbances of sensation — Brain)
  🟢 Head 1896 (On disturbances of sensation, Part II — Brain)
  🟢 Beissner & Henke 2011 (forgotten features of Head zones)

### §4.2 — Beissner's Discovery: Head Zones = Acupoints

```
🟢 HEAD ZONES ↔ ACUPOINTS — THE CONVERGENCE OF EAST AND WEST:

  Beissner & Henke 2011 compared:
    → Head's maximum points (1893-1896)
    → Traditional Chinese Mu and Shu acupoints

  MU POINTS (Front-Mu, 募穴):
    → Located on chest/abdomen
    → Each corresponds to one Zang-Fu organ
    → Used diagnostically: tender Mu point = organ dysfunction
    → = FRONT-body points for organ assessment

  SHU POINTS (Back-Shu, 俞穴):
    → Located paravertebral on the back
    → Each corresponds to one organ

  BEISSNER'S FINDINGS:
    ① Spatial overlap: Mu/Shu points fall WITHIN Head zones
       for the corresponding organ
    ② Functional match: same organ → same zone → same point
    ③ Head's maximum points ≈ Mu/Shu point locations
    ④ Both traditions independently discovered the same
       viscero-cutaneous reflex phenomenon

  EXAMPLE — HEART:
    Head: maximum point at left T3-T4 parasternal
    TCM: CV17 (Shanzhong, Mu point of Pericardium) = sternum T4 level

  EXAMPLE — STOMACH:
    Head: maximum point at epigastric T7-T9

         BL21 (Weishu, Back-Shu of Stomach) = T12 paravertebral
    Overlap: SAME segmental territory

  SIGNIFICANCE:
    → Chinese medicine discovered viscero-cutaneous reflexes
      ~2000 years before Western medicine
    → Different conceptual frameworks (meridians vs reflexes)
      → SAME empirical observations
    → = The phenomenon is REAL — the mechanism explanation differs
    → = Both systems identified points where organ dysfunction
      manifests on the skin surface

  🟢 Beissner & Henke 2011 (Evidence-Based CAM)
  🟢 Beltrán Molano et al. 2014 (anatomo-functional correlation,

### §4.3 — Neurogenic Inflammatory Spots = Acupoints (Kim 2017)

```
🟢 NEUROGENIC SPOTS — PHYSICAL PROOF THAT ACUPOINTS ARE REAL:

  Kim et al. 2017 (Scientific Reports, Nature):

  EXPERIMENT:
    → Rats with induced hypertension or colitis
    → Injected Evans blue dye intravenously
    → Dye leaks through blood vessels WHERE neurogenic inflammation
      occurs (increased vascular permeability)
    → Examined: WHERE on the skin does dye accumulate?

  RESULTS:
    ① Neurogenic inflammatory spots appeared on the skin
       in the DERMATOME of the diseased organ
    ② Hypertensive rats: spots concentrated in C8-T2 dermatome
       (= spinal segments innervating the heart)
    ③ 67% of these spots matched locations of acupoints:
       PC6, PC7, HT7 (wrist points used for cardiac conditions)
    ④ Colitis rats: spots in T10-L1 dermatome
       (= spinal segments innervating large intestine)
    ⑤ Spots matched acupoints used for GI disorders

  MECHANISM:
  ┌───────────────────────────────────────────────────────────────┐
  │  Organ disease → visceral afferent activation                │
  │    ↓                                                         │
  │  Dorsal horn (convergent WDR neurons, lamina V)              │
  │    ↓                                                         │
  │  Antidromic activation of somatic C fibers                   │
  │  (in the SAME segment's dermatome)                           │
  │    ↓                                                         │
  │  C fibers release CGRP + Substance P at skin surface         │
  │    ↓                                                         │
  │  Neurogenic inflammation: vasodilation, plasma extravasation  │
  │    ↓                                                         │
  │  = VISIBLE inflammatory spot on the skin                     │
  │  = AT THE LOCATION OF A TRADITIONAL ACUPOINT                 │
  └───────────────────────────────────────────────────────────────┘

  WHY THIS IS CRITICAL:
    → First OBJECTIVE, VISIBLE evidence that acupoints are
      real physiological phenomena
    → Acupoints are NOT arbitrary anatomical locations
    → They are sites where viscero-cutaneous reflexes
      MANIFEST as measurable neurogenic inflammation
    → The body ITSELF creates "acupoints" in response to
      organ dysfunction
    → = Acupoints are EMERGENT from segmental neuroanatomy

  FOLLOW-UP:
    → Kim et al. 2018 (Frontiers in Neuroscience):

### §4.5 — Cortical Body Matrix and Pain Therapy

```
🟢 CORTICAL BODY MATRIX — WHEN THE BODY MAP BREAKS:

  CONCEPT (Moseley & Gallace 2012):
    → The brain maintains a "body matrix" — integrated
      representation of the body in space
    → Involves: S1, S2, posterior parietal, posterior insula, M1
    → When this matrix is DISRUPTED → pathological pain states

  DISRUPTION IN CHRONIC PAIN:
    → Complex Regional Pain Syndrome (CRPS):
      S1 somatotopy becomes BLURRED — hand area shrinks
    → Phantom limb pain:
      Deafferented cortical area → neighboring regions INVADE
      → Correlation: MORE invasion = MORE pain
    → Chronic low back pain:
      Trunk representation in S1 becomes LESS DISTINCT
    → = Somatotopic disruption CORRELATES with pain intensity

  THERAPEUTIC IMPLICATIONS ⭐:
    → If cortical body map disruption → pain
    → Then RESTORING the map → pain relief?
    → Evidence:

    ① GRADED MOTOR IMAGERY (Moseley 2006):
       → Step 1: laterality recognition (which hand?)
       → Step 2: imagined movement of painful limb
       → Step 3: mirror therapy (visual remapping)
       → Result: significant pain reduction in CRPS + phantom limb

    ② MIRROR THERAPY (Ramachandran 1996):
       → Visual input of intact limb reflected → brain "sees"
         the missing/painful limb moving normally
       → Cortical remapping → pain reduction

    ③ BODY-BASED THERAPY:
       → Massage, acupuncture = REPEATED sensory input to body area
       → Repeated input → cortical map SHARPENS for that area
       → Sharper map → potentially reduced pain
       → 🟡 This mechanism is hypothesized but not directly tested
         for body therapies specifically

  🟢 Moseley & Gallace 2012 (cortical body matrix)
  🟢 Moseley 2006 (graded motor imagery for CRPS)
  🟢 Ramachandran & Rogers-Ramachandran 1996 (mirror therapy)
  🟢 Makin et al. 2013 (phantom limb cortical representation)
  🟡 Body therapy → cortical remapping hypothesis is framework synthesis
```

### §4.6 — Auricular Therapy: Ear Somatotopy in Practice

```
🟢🟡 AURICULAR THERAPY — EAR AS THERAPEUTIC ACCESS POINT:

  WHY THE EAR IS UNIQUE:
    → 4 different nerve sources converge on one small structure
    → Arnold's nerve (CN X) → ONLY place vagus reaches the skin surface
    → = External access to the vagal system WITHOUT invasive procedure

  ESTABLISHED EFFECTS (vagal activation via concha):
    → Stimulation of cymba conchae (superior concha) →
      Arnold's nerve → NTS → vagal efferent activation
    → Measured: decreased heart rate, increased HRV
    → fMRI: activation of NTS, locus coeruleus, hypothalamus
    → = "Transcutaneous Auricular Vagus Nerve Stimulation" (taVNS)
    → 🟢 Well-established mechanism and effects

  LESS ESTABLISHED (organ-specific mapping):
    → Nogier's detailed body map on the ear:
      specific points for liver, kidney, shoulder, knee...
    → Some clinical evidence for point-specific effects
    → But: many acupoints on the ear lack the convergent
      neuroanatomical basis that body acupoints have
    → Ear does NOT have 31 spinal segments → no segmental logic
    → = DIFFERENT mechanism than body segmental therapy

  PROPOSED MECHANISMS FOR EAR SOMATOTOPY:
    → Brainstem convergence: multiple nerve inputs → NTS →
      widespread autonomic modulation (non-specific)
    → Somatotopic organization within NTS (🟡 proposed, limited evidence)
    → Reflex zones reflecting body via brainstem integration
    → Placebo/expectation effects (cannot be excluded for
      detailed organ-specific claims)

  THERAPY APPLICATIONS:
    → Pain management (auricular electroacupuncture)
    → Addiction treatment (NADA protocol — 5 ear points)
    → Anxiety/depression (taVNS devices)
    → Weight management

🟢🟡 INDIVIDUAL VARIATION IN SOMATOTOPIC MAPS:

    → Adjacent dermatome overlap ranges from ~30% to ~70%

    → = "Same acupoint" may fall in DIFFERENT dermatomes

    → Clinical: why sensory testing > drawn maps for diagnosis

    → S1 hand area varies ~2x between individuals
    → Correlates with tactile acuity (2-point discrimination)

    → Disuse → contraction
    → = Body therapy practitioners may develop enhanced

    → Same organ disease → slightly different referral area
      between individuals
    → Heart: most refer to left arm — some refer to right arm,
      jaw, or back exclusively
    → = Standard "heart → left arm" is AVERAGE, not universal
    → Implications: acupoint selection may need individual adaptation
    🟢 Giamberardino 2005 (individual variation in referral)

    → Some organs have DENSE segmental innervation (heart, kidney)
    → Some have SPARSE innervation (liver parenchyma)
    → Dense → clear referred pain patterns, clear Head zones
    → Sparse → vague, poorly localized visceral pain
    → = WHY some organs respond well to segmental acupuncture
      and others show less consistent effects
    🟡 Density-response correlation is framework synthesis

    → Cortical somatotopy SHARPENS during childhood development

    → Aging → potential degradation of cortical body maps
    → Peripheral nerve degeneration → less precise input
    → = Older patients may show less precise dermatome patterns

## §8 — OPEN QUESTIONS

```
🔴 WHAT IS NOT YET UNDERSTOOD:

  Q1: NON-SEGMENTAL ACUPOINT EFFECTS
    Segmental model explains: skin at T4 → heart via T4 convergence.
    DOES NOT explain: ST36 (leg, L4-L5) → gastric motility (T6-T9).
    ST36 is one of the most effective and well-studied acupoints,
    yet its mechanism CANNOT be explained by simple segmental convergence.
    → Candidates: long propriospinal pathways, supraspinal integration,
      fascial connectivity (A03), vagal pathways, endorphin system
    → Status: MAJOR gap. Segmental model covers ~60-70% of
      acupoint effects; the rest needs other mechanisms.

  Q2: PRECISION OF VISCEROTOME MAPPING
    Dermatomes (skin) are mapped with reasonable precision.
    Viscerotomes (organs) are LESS precisely mapped.
    Some organs have overlapping segmental innervation (liver:
    T7-T9 + C3-C5 via phrenic) — which segment matters more?
    → Clinical implications: optimal acupoint selection for
      each organ condition
    → Status: Head's maps remain the gold standard 130 years later.
      Modern imaging could refine but has not systematically done so.

  Q3: CORTICAL MAP → PAIN DIRECTIONALITY
    Cortical body map disruption CORRELATES with chronic pain.
    But: does disruption CAUSE pain, or does pain CAUSE disruption?
    → If disruption → pain: then cortical remapping therapy
      should consistently work (evidence is mixed)
    → If pain → disruption: then treat peripheral cause first
    → Likely bidirectional, but relative contribution unknown.
    → Status: active research area, no consensus.

  Q4: AURICULAR SOMATOTOPY — MECHANISM
    Vagal activation via ear concha = well-established.
    But detailed body mapping on the ear (Nogier's map):
    → What neuroanatomical mechanism maps the ENTIRE body
      onto the ear surface?
    → The ear does NOT have 31 spinal segments.
    → Possible: brainstem convergence zones, but detailed
      mechanism is unknown.
    → Status: auricular somatotopy is clinically used but
      mechanistically poorly understood.

  Q5: DYNAMIC ACUPOINTS
    Kim 2017 showed neurogenic inflammatory spots APPEAR
    only when the organ is diseased — they are not always present.
    → Are acupoints FIXED anatomical locations or DYNAMIC
      physiological phenomena?
    → If dynamic: this would explain why "sham" acupuncture
      sometimes works (hitting an active neurogenic spot that
      happens to be off-standard-map)
    → Status: emerging concept, limited data.

  Q6: INDIVIDUAL DERMATOME MAPPING FOR THERAPY
    Given significant individual variation in dermatome boundaries:
    → Could personalized dermatome mapping (via functional testing)
      improve acupuncture point selection?
    → Modern neuroimaging could map individual S1 somatotopy
    → Would personalized maps → better therapy outcomes?
    → Status: technically feasible, not yet attempted systematically.

  Q7: SPINAL CORD SOMATOTOPIC PLASTICITY
    Cortical plasticity is well-documented.
    Does the SPINAL CORD (Level 2) also show plasticity in its
    somatotopic organization?
    → Central sensitization (A01 §3.6) involves dorsal horn changes
    → But does somatotopic REMAPPING occur at spinal level?
    → If yes: chronic pain may involve spinal-level map distortion
      (not just cortical)
    → Status: limited data. Spinal cord imaging is difficult.
```
