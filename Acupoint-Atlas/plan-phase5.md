## 4. Edit Conventions

### Update format
Each BSA file update follows this pattern:
1. Read current section (verify line numbers)
2. Draft update text (minimal changes, preserve style)
3. Add Atlas cross-reference: `→ Atlas: AP-Mechanism-Summary §X.X`
4. Apply edit
5. Verify no collateral damage

### Principles
- **Minimal edits**: Add/modify only what the evidence requires
- **Preserve existing text**: Don't rewrite sections, annotate them
- **Cross-reference both directions**: BSA → Atlas and later Atlas → BSA
- **English originals only**: Vietnamese translations are separate project scope
- **No style changes**: Match existing formatting of each file
